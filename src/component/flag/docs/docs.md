# Флаг

Картинка страны для телефонного поля, переключателя языка, списка стран и
любого места, где страну надо показать, а не назвать.

```html
<span class="sf-flag sf-flag--rect" data-country="ru"></span>
<span class="sf-flag sf-flag--circle" data-country="ru"></span>
```

## Две формы, а не одна с обрезкой

Набор поставляется дважды: прямоугольный 28×20 и круглый 24×24. Круглый — не
обрезанный прямоугольник, а перерисованный флаг: у Непала сохраняется форма
полотнища, у Сингапура полумесяц со звёздами, у Аргентины солнце в центре.
Поэтому форма выбирается классом, а не `border-radius` поверх одной картинки.

| Класс | Размер | Когда |
|:---|:---|:---|
| `sf-flag--rect` | 28×20 | по умолчанию: поля, списки, таблицы |
| `sf-flag--circle` | 24×24 | рядом с аватарами и там, где форма важнее узнаваемости |

Состав наборов не совпадает: ЕС и континенты есть только прямоугольными, два
десятка территорий — только круглыми. Если запрошенной формы нет, компонент
отдаёт вторую, а не пустое место.

## Размер и вид

Высота задаётся одной переменной, ширина считается сама:

```html
<span class="sf-flag sf-flag--rect" data-country="de" style="--sf-flag--size: var(--sf-c0)"></span>
```

Скругление и тонкая рамка живут в CSS, а не в файлах: `--sf-flag--radius`
по умолчанию `--sf-radius--ui`, `--sf-flag--outline-color` — `--sf-outline-variant`.
Рамка нужна белым флагам, чтобы они не сливались со страницей, и следует теме.

## Загрузка

Файл подгружается, когда элемент подходит к экрану: список из двухсот стран не
тянет двести файлов ради восьми видимых. Отключается атрибутом
`data-lazy="false"`. Свой набор задаётся `data-flag-base` на элементе или любом
предке; по умолчанию путь берётся из рантайма.

## Доступность

Флаг декоративен: без `data-alt` он получает `aria-hidden`. Если картинка несёт
смысл — название страны рядом не написано, — передайте `data-alt`.

Флаг не заменяет язык: страна и язык не одно и то же, и для выбора языка рядом с
флагом должно стоять название на этом языке.
