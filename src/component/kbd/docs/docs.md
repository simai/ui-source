# Kbd

`kbd` обозначает ввод пользователя, обычно одну физическую клавишу. Компонент
только показывает подсказку: он не регистрирует сочетание, не выполняет действие
и не получает фокус.

Вид клавиш задаёт только этот компонент (решение владельца 2026-11-07,
замечание R030, правило C04). Продукты и страницы не пишут своих стилей для
`kbd` и `.sf-kbd`: автор пишет клавишу или сочетание, а компонент сам выбирает
вид по месту. Проверка `tools/lint-kbd-styles.mjs` находит такие стили в
продукте.

## Вид по месту

| Где стоит клавиша | Вид | Как выглядит |
|:---|:---|:---|
| в тексте документации (просто `<kbd>`) | `key` | клавиша с тонкой рамкой `outline-variant` и нижним краем |
| в кнопке и в поле (`button`, `[role=button]`, `[role=combobox]`, `[role=searchbox]`, `.sf-button`, `.sf-input`) | `cap` | мягкая плашка без рамки: обычный шрифт текста, вес 500, размер от текста вокруг, цвет и заливка — от цвета текста, поэтому плашка читается и на залитой кнопке |
| в меню, списке выбора и подсказке (`[role=menu]`, `[role=menubar]`, `[role=listbox]`, `[role=tooltip]`, `.sf-tooltip`, `.sf-context-menu`) | `plain` | значки без плашек, на ступень мельче, приглушённым цветом `on-surface-variant`; в подсказке — цветом подсказки, тише |

Если место не подходит, вид указывают явно атрибутом `appearance` на
клавише или на группе: `appearance="cap"`, `appearance="plain"`,
`appearance="key"`. Явный вид важнее места.

Размеры идут от текста вокруг: буквы плашки и клавиши — 0,8125 em (13 из 16
px), высота и наименьшая ширина — 1,6 em своих букв (около 21 px), поля по
бокам — 0,4 em, между клавишами сочетания — 0,25 em. Клавиша из одного знака
(P, ⌘, ⇧, ↵) — квадрат: класс `sf-kbd--square`.

## Одна клавиша

Используйте нативный `<kbd>Enter</kbd>`. Класс `sf-kbd` сохраняется как
визуальный fallback для среды, которая не может вывести элемент `kbd`, но сам
класс не добавляет семантику.

## Сочетание

Для одновременного нажатия оберните отдельные клавиши в
`<kbd class="sf-kbd--group">`. Каждая физическая клавиша остаётся отдельным
вложенным `kbd`. В актуальных браузерах нативный внешний `kbd` с прямыми
дочерними `kbd` также распознаётся как группа.

Плашки и клавиши стоят отдельно, без знака «+». Значки без плашек на Mac стоят
подряд (⇧⌘P), на других системах слова соединяются «+» (Ctrl+Shift+P): знак
пишут как `<span class="sf-kbd-join">+</span>` между клавишами, и компонент
показывает его только в виде `plain`.

## Сочетание из настройки

У компонентов Framework сочетание — одна настройка `shortcut`
(`sf-button`, пункт `sf-menu-context`, действие `sf-search`): слова через
`+`, сначала модификаторы, последней клавиша — `mod+k`, `shift+mod+p`,
`escape`, `F2`. `mod` — Cmd на Apple и Ctrl на остальных системах. Компонент
сам выводит значки на Mac (⇧⌘P, порядок Apple) и слова на остальных системах
(Ctrl+Shift+P, сначала Ctrl). Текст, который не похож на такую запись
(например, уже готовое «⇧⌘L»), выводится как есть.

## Последовательность

Если клавиши нажимают по очереди, не объединяйте их в одно обозначение:
оставьте между отдельными `kbd` обычные слова «затем», «потом» или стрелку с
доступной текстовой расшифровкой.

## Настройка

Публичные переменные (ставятся на клавишу или любого предка):

| Переменная | По умолчанию | Что меняет |
|:---|:---|:---|
| `--sf-kbd-size` | `1.6em` | высота и наименьшая ширина плашки и клавиши |
| `--sf-kbd-padding-inline` | `0.4em` | поля по бокам |
| `--sf-kbd-gap` | `0.25em` | расстояние между клавишами сочетания |
| `--sf-kbd-font-size` | `0.8125em` | размер букв плашки и клавиши |
| `--sf-kbd-font-family` | `var(--sf-text--family)` | шрифт плашки и клавиши |
| `--sf-kbd-radius` | `var(--sf-radius--ui)` | скругление |
| `--sf-kbd-background-color` | `color-mix(in srgb, currentColor 8%, transparent)` | заливка плашки |
| `--sf-kbd-color` | `currentColor` | цвет букв плашки: цвет текста вокруг, контраст с плашкой не ниже 4,5:1 на каждом виде кнопки |
| `--sf-kbd-border-color` | `var(--sf-outline-variant)` | рамка и нижний край клавиши |
| `--sf-kbd-plain-color` | `var(--sf-on-surface-variant)` | цвет значков без плашек |

Остальные переменные `--sf-kbd--*` внутренние и могут меняться в любом
выпуске.
