# Link

`sf-link` оформляет нативную ссылку на страницу, фрагмент или скачиваемый
ресурс. Для действия без перехода используйте Button.

Достаточно `<a class="sf-link" href="...">Подпись</a>`. Для композиции с
иконкой доступны `sf-link__content` и `sf-link__icon`; старые
`sf-link-content` и `sf-link-icon` остаются совместимыми aliases.

Ссылка — часть текста, в котором стоит (1.2.0): она берёт его размер, строку,
семейство и начертание (C103: одна строка — одна ступень) и течёт в предложении,
переносясь по словам, как обычный текст (C147 (1)). Свой размер задают ступенью
текста на ссылке или вокруг неё (`text-1/2`, `text-1`). Ссылка с иконкой
(`sf-link__icon`) — один элемент строки: иконка высотой в строку текста (24 при
16/24, 20 при 14/20) через 4 от подписи.

## Состояния

Ссылка всегда подчёркнута (решение C186 (1)): линия цвета ссылки на 48 %,
при наведении и нажатии — полным цветом. В навигации, меню и таблице линии нет
до наведения. Hover и active используют роли темы `--sf-link-hover` и
`--sf-link-active`. Keyboard focus показывается через `:focus-visible` вокруг
всей ссылки: 2 px `--sf-focus`, отступ 2, угол 4; клик мышью не оставляет
focus-ring.

Цвет посещённой ссылки по умолчанию выключен (C186 (2)): посещённая
остаётся цветом ссылки. Сайт или документация включает `--sf-link-visited`
атрибутом `data-sf-visited="on"` на области или на `<html>`.

На сильном месте (`bg-primary` и другие цвета, стекло) ссылка берёт чернила
места и остаётся подчёркнутой (C186 (5)).

## Иконка

Иконка может стоять до или после подписи. Если подпись уже объясняет назначение,
иконка декоративна и получает `aria-hidden="true"`.

## Навигационная форма

`sf-link--navigation` — ссылка, которая называет, куда ведёт, в ряду
элементов управления вне `nav`, меню и таблицы (C186 (1), C381): подпись в
чернилах места (`on-surface`, если место не задаёт свои), иконка — в цвете
иконок места, без подчёркивания в покое; линия появляется только под
подписью при наведении, нажатии, фокусе с клавиатуры и пока открыто меню
ссылки (`aria-expanded="true"`). Цвет в состояниях не меняется. Ссылкой может
быть и нативная кнопка (`button.sf-link`), если она открывает меню, а не
ведёт на страницу: рамка, поля и заливка кнопки убираются. Так нарисован
триггер `sf-language trigger="name"`.

```html
<button type="button" class="sf-link sf-link--navigation" aria-haspopup="menu" aria-expanded="false">
  <sf-icon class="sf-link__icon" icon="translate" aria-hidden="true"></sf-icon>
  <span class="sf-link__content">Русский</span>
</button>
```

## Новая вкладка

Ссылка с `target="_blank"` сама получает значок `arrow_outward` размера текста
через 4 после последнего слова (значок не отрывается от слова) и слова
«(откроется в новой вкладке)» для диктора на языке страницы (C186 (3)). Если в
ссылке уже есть значок новой вкладки, второй не ставится.

## Недоступный переход

Удалите `href`, добавьте `disabled` и `aria-disabled="true"`. Объясните причину
рядом; CSS не должен изображать отключение, оставляя рабочую навигацию.

## Длинная подпись

Ссылка без иконки переносится вместе с предложением. В ссылке с иконкой текст
внутри `sf-link__content` переносится, а иконка сохраняет размер. Root работает
без обязательных flex-утилит и не расширяет контейнер.
