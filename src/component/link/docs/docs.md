# Link

`sf-link` оформляет нативную ссылку на страницу, фрагмент или скачиваемый
ресурс. Для действия без перехода используйте Button.

Достаточно `<a class="sf-link" href="...">Подпись</a>`. Для композиции с
иконкой доступны `sf-link__content` и `sf-link__icon`; старые
`sf-link-content` и `sf-link-icon` остаются совместимыми aliases.

## Состояния

Default, visited, hover и active используют соответствующие семантические роли
темы. Keyboard focus показывается через `:focus-visible` вокруг всей ссылки;
клик мышью не оставляет focus-ring.

## Иконка

Иконка может стоять до или после подписи. Если подпись уже объясняет назначение,
иконка декоративна и получает `aria-hidden="true"`. Framework не добавляет
автоматически значок внешней ссылки.

## Недоступный переход

Удалите `href`, добавьте `disabled` и `aria-disabled="true"`. Объясните причину
рядом; CSS не должен изображать отключение, оставляя рабочую навигацию.

## Длинная подпись

Текст внутри `sf-link__content` переносится, а иконка сохраняет размер. Root
работает без обязательных flex-утилит и не расширяет контейнер.
