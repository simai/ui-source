# sf-wizard-step

Один шаг мастера `sf-wizard`. Атрибуты говорят, что это за шаг и где он стоит;
дети — тело шага: форма из полей Framework, картинка, состояние, план
изменений.

```html
<sf-wizard-step name="address" label="Адрес панели" type="form"
  description="По этому адресу вы будете открывать панель.">
  <form>
    <sf-input name="host" label="Адрес" required></sf-input>
  </form>
</sf-wizard-step>
```

Шаг сам ничего не рисует: его дети остаются живыми там, где их поставила
страница, а мастер рисует вокруг них заголовок, пояснение, индикатор, итог и
кнопки. Изменение атрибута шага мастер рисует сразу. Вне мастера шаг просто
показывает своих детей.

| Атрибут | |
|---|---|
| `name` | Ключ шага. |
| `label` | Короткое имя в ходе по шагам. |
| `heading` | Заголовок над телом; пусто — `label`. |
| `description` | Зачем этот шаг. |
| `type` | `info` (по умолчанию), `form`, `action`, `review`, `result`. |
| `optional` | Шаг можно пропустить. |
| `href` | Место `pages`: адрес шага. |
| `action-text` | Подпись главной кнопки вместо слова типа. |
| `message` | Итог действия; во время выполнения — строка у индикатора. |
| `state` | Значение: пусто (не начат), `done`, `skipped`, `running`, `error`. |

Подробно — в описании `sf-wizard`.
