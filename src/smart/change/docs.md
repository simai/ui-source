# sf-change

Изменение поля текстом: «Собран → Передан в доставку». Старое значение —
тихим цветом, новое — цветом текста и полужирным. Без бейджей и без
зачёркивания: две «коробки» в строке — шум, а зачёркнутое читается как ошибка
или удаление. Пустое значение — слово «пусто».

```html
<p>Анна Котова изменила статус
  <sf-change label="Статус" before="Собран" after="Передан в доставку"></sf-change></p>

<sf-change layout="list"
  changes='[{"label":"Вес","before":"4,2 кг","after":"4,6 кг"},
            {"label":"Склад","before":"Москва-Север","after":"Москва-Юг"}]'></sf-change>
```

Где нужен: событие хронологии, колонка «Изменение» в журнале аудита,
уведомление «Статус: Собран → В пути», подтверждение правки
(`sf-confirm-change` рисует свой список им), история версий страницы.

## Виды

- **В строке** (`layout="inline"`, по умолчанию) — внутри предложения. Стрелка и
  новое значение не разрываются: строка переносится только перед стрелкой.
  Название поля печатается только с `show-label` («Статус: Собран → …») — в
  таблице и уведомлении; в предложении, где поле уже названо, оно лишнее.
- **Списком** (`layout="list"`) — несколько полей одного обновления: колонка
  названий шириной в самое длинное и пары рядом. Уже 24rem название стоит над
  своей парой.
- **Длинный текст** — значение длиннее 80 знаков в строку не ставится: кнопка
  «Показать изменения» раскрывает на месте два блока, «Было» и «Стало».
  `reveal="none"` — всегда парой.

## Настройки

- `before`, `after` — значения, текст. Пустое — «пусто».
- `label` — название поля.
- `show-label` — печатать «Название: » перед парой.
- `changes` — список `{label, before, after}` для `layout="list"`: свойство,
  JSON-остров `data-sf-settings` или атрибут `changes` в JSON. Число
  показывается текстом, `null` и пустая строка — «пусто».
- `layout` — `inline` или `list`.
- `reveal` — `auto` (длинное раскрывается) или `none`.

Состояния хоста: `data-empty` (сказать нечего — элемент ничего не рисует),
`data-block` (список или раскрытие — элемент блочный), `data-revealed`.

## Шрифт

`sf-change` берёт шрифт и строку места: в предложении любого размера он
читается как часть предложения. Кнопка раскрытия и подписи блоков — ступенью
ниже.

## Публичные переменные

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `--sf-change-before-color` | `--sf-on-surface-variant` | старое значение и «пусто» |
| `--sf-change-after-color` | `--sf-on-surface` | новое значение |
| `--sf-change-after-weight` | `--sf-font-weight-medium` | насыщенность нового |
| `--sf-change-arrow-color` | `--sf-on-surface-variant` | стрелка |
| `--sf-change-label-color` | `--sf-on-surface-variant` | названия полей |
| `--sf-change-column-gap` | `--sf-space-1` | между названиями и парами в списке |

SIMAI Framework сам их не задаёт.

## Доступность

Стрелка — картинка (`aria-hidden`); между значениями — скрытое слово, диктор
слышит «Собран на Передан в доставку». Список — `dl`: название — термин, пара —
описание. Кнопка раскрытия — `aria-expanded` и `aria-controls`; блоки
подписаны словами «Было» и «Стало».

Цвет стадии (CRM) у значения пока не делаем: позже — настройкой тона.
