# Tree

`sf-tree` представляет иерархию как единый составной элемент. Используйте его
для файловых структур, таксономий и многоуровневой навигации. Для короткого
набора независимых раскрытий используйте Accordion.

## Когда дерево

| Задача | Что взять |
|:---|:---|
| Работа с иерархией: раскрыть, выбрать, отметить, перенести, бросить файл; много уровней, тысячи записей | `sf-tree` |
| Показать структуру текстом (файлы проекта в документации), нажимать нечего | `sf-tree static` или разметка `.sf-tree--static` |
| Перейти по сайту или админке: ссылки, текущая страница | меню-колонка `sf-menu` |
| Перейти внутри одной страницы | `sf-contents` |
| Плоские записи с колонками (размер, дата, владелец) | `sf-list`, `sf-view` |
| Один уровень разделов одной записи | вертикальные вкладки, не дерево |

Сцены: файлы и файловый менеджер (папки в дереве, файлы списком рядом), дерево
страниц сайта, категории каталога со счётчиками, права и оргструктура с
флажками, структура проекта в документации.

Корню обязательно задают `aria-label`. В страницу входит одна точка Tab;
стрелки, `Home`, `End` и поиск по первым буквам перемещают фокус между видимыми
узлами. Вправо раскрывает ветвь или переходит к первому ребёнку, влево сворачивает
ветвь или возвращает к родителю. `Enter` раскрывает ветвь или открывает лист,
пробел выбирает.

## Пункты

Пункты — дочерние `<sf-tree-item>` (читаются один раз и убираются) или свойство
`items`: массив записей `{id, label, value, href, target, rel, kind, open,
selected, active, disabled, has-children, icon, open-icon, closed-icon,
chevron-open-icon, chevron-closed-icon, open-label, close-label, note, mark,
more, hidden, error, revision, children}`. Поля в
camelCase (`openIcon`, …) и `type` тоже читаются. Идентификатор записи — `id`,
иначе `value`, иначе место записи.

Дерево рисует записи само, плоско: строки классовой разметки (та же, что у
`sf-tree-item`: `.sf-tree-item[role=treeitem][data-value]`,
`.sf-tree-item-container`, `.sf-tree-item-name`), с `aria-level`,
`aria-setsize` и `aria-posinset`, по ключу `id` (стандарт 1.3.8 §18.4). Новый
`items` с одной изменённой записью переписывает только её строку, на месте.
Раскрытость записи — состояние дерева по `id`: она переживает новый `items`.
Больше 300 видимых записей — рисуются только строки в поле зрения ближайшей
прокрутки с запасом, остальные заменяют два пустых блока; событие
`sf-tree-window {first, last}` говорит, какие нарисованы. Дерево из 2 000
узлов рисуется за кадр (было 14 с на этой машине и 33 с в замере стенда 20,
simai/ui-source#43).

## Значки

Стрелка раскрывает ветвь, значок говорит, что это. У ветви — папка
(`folder`, раскрытая — `folder_open`), у листа — его тип, `draft`, если тип
неизвестен. Запись без детей — лист; пустая папка — `kind: "folder"`.

Кто выбирает значок, первое слово выигрывает:

1. `icon` — имя значка (`"delete"`, `"home"`), `false` — без значка;
2. `kind` — одно из двенадцати слов: `folder`, `file`, `page`, `document`,
   `image`, `code`, `data`, `table`, `archive`, `video`, `audio`, `link`;
   у ветви свой `kind` сохраняется (`page` — страница с подстраницами);
3. расширение имени (`file-types="name"`, по умолчанию): «Смета.xlsx» —
   таблица, «Договор.pdf» — документ; `file-types="none"` отключает;
4. место: ветвь — папка, лист — файл.

Карта слов, расширений и значков одна во Framework (`src/core/js/file-types`),
её же читают Docara, Larena и ui-mail.

`icons`: `all` (по умолчанию) — значки у всех строк, `branches` — только у
папок, `none` — без значков, остаётся одна стрелка.

```html
<sf-tree aria-label="Файлы">
  <sf-tree-item label="Документы" open>
    <sf-tree-item label="Договор.pdf"></sf-tree-item>
    <sf-tree-item label="Смета.xlsx"></sf-tree-item>
    <sf-tree-item label="Пустая папка" kind="folder"></sf-tree-item>
  </sf-tree-item>
  <sf-tree-item label="Корзина" icon="delete"></sf-tree-item>
</sf-tree>
```

## Второй текст строки

`note` — текст после имени приглушённым цветом: комментарий, число,
размер (`{label: "Ноутбуки", note: "128"}`). `mark` выделяет строку
полужирным, `more` — строка «…» (остальное не показано).

## Статичное дерево

`static` показывает структуру текстом, для документации: вложенный список
(`ul`/`li`, не `role="tree"`), все уровни раскрыты, без стрелок, без точки
Tab и наведения, строка высотой строки текста, имена моноширинным шрифтом,
`note` после имени (на телефоне переносится под него). Та же классовая
разметка — `.sf-tree.sf-tree--static`: её пишет и Docara.

```html
<sf-tree static aria-label="Структура проекта"></sf-tree>
<script>
  tree.items = [
    {label: 'docara.json', mark: true},
    {label: 'content', children: [{label: 'index.md', note: 'главная страница'}]},
    {label: 'assets', kind: 'folder'},
    {label: '…', more: true},
  ];
</script>
```

## Подгрузка ветвей

Ветвь, дети которой ещё не загружены, помечают `has-children: true` (у
`<sf-tree-item>` — атрибут `has-children`). У неё есть стрелка, она
раскрывается, и приходит `sf-tree-toggle` с `open: true` — по нему приложение
загружает детей и задаёт новый `items`; ветвь остаётся раскрытой.

```js
tree.addEventListener('sf-tree-toggle', async ({detail}) => {
  if (!detail.open) return;
  const children = await loadChildren(detail.id);
  tree.items = withChildren(tree.items, detail.id, children);
});
```

Пока детей нет, под раскрытой ветвью стоит строка «Загрузка…» со спиннером
Framework. Если загрузка не удалась, приложение задаёт записи `error: true` —
вместо «Загрузка…» строка «Не удалось загрузить» с кнопкой «Повторить»;
нажатие (или `Enter` на строке) снова показывает «Загрузка…» и присылает
`sf-tree-retry {id, value}`.

## Длинные имена

Имя — одна строка, не поместившееся обрезается многоточием. У строки с
обрезанным именем полное имя — её `aria-label` и подсказка Framework при
наведении и фокусе с клавиатуры.

## Выбор

`selection`: `none` (по умолчанию) — нажатие открывает пункт; `one` — выбирает
один; `many` — переключает каждый; `check` — флажок в каждой строке (права,
категории): ветвь отмечает всё под собой, а если отмечена часть — флажок
частичный; строка говорит `aria-checked` `true`, `false` или `mixed`. Прежние
`single` и `multiple` — псевдонимы до 2026-12-01. Значение `selected` — id
текущего пункта, `selectedIds` — все выбранные при `many` и отмеченные при
`check`; оба можно задать. `items`, в котором записи говорят `selected: true`,
задаёт выбор.

## Дерево страниц

Раздел сайта — страница с подстраницами: `kind: "page"` у ветви оставляет
значок страницы. Главная — `icon: "home"`, внешняя ссылка — `kind: "link"`,
скрытая страница — `hidden: true`: имя приглушено, после него слово «скрыта»;
её по-прежнему можно выбрать.

## Порядок

`reorder` разрешает перетащить запись внутри дерева: перед строкой или после
неё (верхняя и нижняя четверть), или внутрь папки или страницы (середина).
Дерево ничего не переносит само: приходит `sf-tree-move {ids, parent,
before}` — `parent: null` верхний уровень, `before: null` в конец; приложение
переносит запись и задаёт новый `items`. В саму себя и в своих потомков
запись не переносится.

## События

| Событие | Когда | `event.detail` | Прежнее имя (до 2026-12-01) |
|:---|:---|:---|:---|
| `sf-tree-open` | нажата подпись или `Enter` на листе | `id`, `value` | `sf-tree-item-click` |
| `sf-tree-select` | выбор изменён | `ids`, `id`, `selected` | `sf-tree-selection-change` |
| `sf-tree-toggle` | ветвь раскрыта или свёрнута | `id`, `open`, `value` | `sf-tree-item-toggle` |
| `sf-tree-retry` | «Повторить» под ветвью, которая не загрузилась | `id`, `value` | — |
| `sf-tree-move` | на пункт перетащены записи списка (`accept-records`) или запись перенесена внутри дерева (`reorder`) | `ids`, `parent`, `before`, `source` | `sf-tree-records-drop` |
| `sf-tree-attach` | на пункт перетащены файлы (`accept-files`) | `files`, `parent` | `sf-tree-files-drop` |
| `sf-tree-window` | изменилось окно длинного дерева | `first`, `last` | — |

Прежние имена приходят следом со старым `detail`; `item` в нём — элемент
строки. `onToggle(handler)` передаёт обработчику строку первым аргументом.
Классовое дерево (`.sf-tree` без `sf-tree`) шлёт те же новые имена и после них
прежние `sf-tree:toggle`, `sf-tree:activate`, `sf-tree:selection-change`.

Действия: `expand({id})`, `collapse({id})`, `expandAll()`, `collapseAll()`,
`focusEntry({id})` — отвечают исходом; `focusEntry` сначала рисует запись,
если окно её не держит. Клавиша `*` раскрывает все соседние ветви строки.

Публичные переменные: `--sf-tree-gap`, `--sf-tree-padding-inline`,
`--sf-tree-indent`, `--sf-tree-radius`, `--sf-tree-color`,
`--sf-tree-selected-background-color`.

Компонент не загружает данные, не хранит выбор и не решает, какие маршруты или
узлы доступны пользователю. Интерфейс — `component.json`, примеры —
`examples.json`.
