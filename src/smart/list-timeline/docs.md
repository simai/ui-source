# sf-list-timeline

Хронология: короткая история, которую читают сверху. Последние действия на
сервере, журнал аудита, история записи, страница уведомлений, история
заданий. Вариант блока `list` SIMAI Framework: `sf-list-feed` — лента, которую
читают от новой записи внизу (переписка, журнал вывода), `sf-list-timeline` —
события на вертикальной линии с отметками и заголовками дней.

```html
<sf-list-timeline has-more>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"id": "backup", "time": "2026-10-27T11:58:00+03:00", "status": "success",
       "title": "Копия demo-owned.test создана", "actor": "Планировщик",
       "text": "1,2 ГБ, хранится 30 дней"},
      {"id": "update", "time": "2026-10-27T09:05:00+03:00", "icon": "system_update_alt",
       "title": "Панель обновлена до 0.3.1", "href": "/updates/0.3.1/"},
      {"id": "cert", "time": "2026-10-26T18:40:00+03:00", "status": "warning",
       "title": "Сертификат demo-static.test истекает через 6 дней"}
    ]}
  </script>
</sf-list-timeline>
```

Порядок — хоста: список не сортирует. Новые сверху (история) и старые сверху
(журнал) группируются одинаково правильно: подряд идущие события одного дня
стоят под одним заголовком.

## Событие

Каждый элемент `items` — `{id, title, time?, text?, actor?, status?, icon?, href?}`:

- `id`, `title` — обязательны; событие без них или с уже встреченным `id` не
  показывается.
- `time` — момент в ISO 8601 со смещением (`2026-10-27T11:58:00+03:00`) или в
  миллисекундах. Событие без времени входит в день предыдущего.
- `status` — `success`, `warning`, `error`, `info`, по умолчанию `neutral`:
  цвет отметки; слово состояния произносится перед заголовком для диктора.
- `icon` — глиф на отметке вместо точки (`add_circle`, `system_update_alt`).
- `actor` — кто это сделал; стоит рядом со временем.
- `text` — строка под заголовком, ступенью меньше.
- `href` — заголовок становится ссылкой. Нажатие спрашивает
  `sf-list-timeline-navigate` `{id, href}`, событие можно отменить (роутер).

## Настройки

- `group` `day|none` — `day`: заголовок на каждый календарный день в часовом
  поясе читателя («Сегодня», «Вчера», день недели в пределах недели, дальше
  дата, «24 октября»); `none` — один список.
- `time-format` `relative|exact` — «2 минуты назад» или точное время («11:58»;
  без групп — с датой). Точные дата и время всегда есть во всплывающей
  подсказке и в `datetime` элемента `time`.
- `now` — момент, от которого считаются относительное время и дни (ISO 8601).
  Пусто — часы читателя; тогда список сам перерисовывает время раз в минуту и
  дни в полночь, а уйдя со страницы, останавливается.
- `density` `normal|compact` — `normal`: текст переносится целиком, между
  событиями зазор; `compact`: однострочное событие высотой с контрол ступени,
  текст в одну строку с многоточием.
- `size` `1|1/2|2` — ступень линейки; `1/2` — для боковой панели.
- `heading-level` 2–6 (3) — уровень заголовков дней.
- `has-more` — после последнего события кнопка «Показать ещё»; её нажатие —
  событие `sf-list-timeline-load-more` `{direction: 'after', after: <id
  последнего>}`. Хост ставит `loading`, дописывает следующую страницу в
  `items` и снимает `has-more`, когда страниц больше нет.
- `loading` — следующая страница в пути: кнопка показывает загрузку и больше
  ничего не спрашивает.
- `empty-text` — тихая строка без событий, «Событий пока нет».
- `label` — имя списка для диктора без групп.

Состояния хоста: `data-empty`, `data-loading`.

## Геометрия

Одна ступень S: заголовок события — строка ступени L; время, автор, текст и
заголовки дней — ступенью ниже (время и автор стоят на строке заголовка).
Отметка — квадрат L на строке заголовка: точка в треть L или значок L, цвет
по состоянию. Линия — толщиной в пиксель по оси отметок, от низа одной
отметки до верха следующей; у последнего события дня линии нет. В плотном
виде однострочное событие — высота контрола ступени H, в обычном к ней
добавляется зазор (`text-space-x` ступени). Строка заголовка дня и строка
кнопки «Показать ещё» — тоже H.

## Публичные переменные

`--sf-list-timeline-line-color` (линия), `--sf-list-timeline-marker-color`
(отметка без состояния), `--sf-list-timeline-time-color`,
`--sf-list-timeline-day-color`, `--sf-list-timeline-gap` (между событиями в
обычном виде), `--sf-list-timeline-padding-inline`. SIMAI Framework сам их не
задаёт.

## Доступность

Заголовки дней — `role="heading"` уровня `heading-level`, события дня —
упорядоченный список с именем по заголовку. Состояние произносится словами,
отметка — только картинка. Время — элемент `time` с точным моментом. Живой
области нет: хост, которому нужно озвучить новое событие, делает это сам.
Фокус список не берёт; Tab проходит по ссылкам и кнопке «Показать ещё».
