# sf-list-timeline

Хронология: короткая история, которую читают сверху. История заказа или
записи, последние действия на сервере, журнал аудита, страница уведомлений,
этапы доставки. Вариант блока `list` SIMAI Framework: `sf-list-feed` — лента,
которую читают от новой записи внизу (переписка, журнал вывода),
`sf-list-timeline` — события на вертикальной линии со значками и заголовками
дней.

Событие собрано из общих частей SIMAI Framework: значок на линии —
`.sf-featured-icon`, автор — `sf-avatar` и имя полужирным, изменение поля —
`sf-change`, время — `sf-time`, заголовок дня — общий заголовок группы
`.sf-group-heading`.

```html
<sf-list-timeline has-more>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"id": "comment", "kind": "comment", "time": "2026-11-09T14:32:00+03:00",
       "actor": {"name": "Анна Котова", "hue": "teal"}, "title": "оставила комментарий",
       "text": "Клиент просит доставку после 18:00."},
      {"id": "status", "icon": "swap_horiz", "time": "2026-11-09T14:30:00+03:00",
       "actor": {"name": "Анна Котова", "hue": "teal"}, "title": "изменила статус",
       "change": {"label": "Статус", "before": "Собран", "after": "Передан в доставку"}},
      {"id": "charge", "icon": "error", "status": "error", "time": "2026-11-09T09:12:00+03:00",
       "actor": {"name": "Робот", "system": true}, "title": "не смог списать доплату",
       "text": "Карта •• 4417: недостаточно средств."}
    ]}
  </script>
</sf-list-timeline>
```

Порядок — хоста: список не сортирует. Новые сверху (история) и старые сверху
(журнал) группируются одинаково правильно: подряд идущие события одного дня
стоят под одним заголовком.

## Событие

Каждый элемент `items` — `{id, title, time?, text?, actor?, status?, icon?,
href?, kind?, state?, change?, changes?}`:

- `id`, `title` — обязательны; событие без них или с уже встреченным `id` не
  показывается. С автором `title` — продолжение предложения («изменила
  статус») и читается тихим цветом; без автора — само предложение.
- `actor` — `{name, avatar?, hue?, system?}`: аватар строкой и имя полужирным
  в начале предложения; `system: true` — только имя (робот, планировщик).
  Строка по-прежнему читается как имя.
- `time` — момент в ISO 8601 со смещением или в миллисекундах; рисует
  `sf-time`. Событие без времени входит в день предыдущего.
- `status` — `success`, `warning`, `error`, `info`, по умолчанию `neutral`.
  Цвет значка дают только `error` (розовый круг), `warning` и `success`;
  `info` говорится словами, значок нейтральный. Слово состояния произносится
  перед предложением для диктора.
- `icon` — глиф значка (`swap_horiz`, `payments`). Без него — глиф вида
  (`comment` — `chat_bubble`, `sms` — `phone_iphone`), иначе точка.
- `kind` — `event` (по умолчанию), `comment`, `sms`. У комментария текст стоит
  в обводке под строкой времени, без заливки.
- `change` — `{label, before, after}`, одно поле — в предложении через
  `sf-change` («Собран → Передан в доставку»); `changes` — список полей,
  списком под предложением. Пустое значение — «пусто».
- `text` — тихая строка под предложением, после времени: «14:30 · текст».
- `state` — `done`, `current`, `upcoming`: этапы. Одна логика у этапа со
  значком и у точки без значка: пройденный — сплошной круг основного цвета,
  текущий — такой же круг с кольцом через зазор и `aria-current="step"`,
  будущий — пустой круг с тихим контуром; линия после текущего — пунктиром.
  Статус (`success`, `warning`, `error`) важнее состояния. В режиме высокой
  контрастности форма сохраняется в системных цветах.
- `href` — заголовок становится ссылкой. Нажатие спрашивает
  `sf-list-timeline-navigate` `{id, href}`, событие можно отменить (роутер).

## Свёрнутые серии

Подряд идущие события одного автора и одного вида в пределах дня, если их
больше `collapse` (5), показываются первыми пятью, а остальные сворачиваются в
одну строку «Ещё 12 изменений»; одно оставшееся событие показывается само.
События без автора (системный журнал) и этапы (`state`) серий не образуют,
поэтому список никогда не сворачивается целиком. Нажатие раскрывает серию на
месте, переводит фокус на первое раскрытое событие и сообщает
`sf-list-timeline-expand` `{run, ids, count}` — хосту, который подгружает серию
по запросу. `collapse="0"` ничего не сворачивает.

## Настройки

- `group` `day|none` — `day`: заголовок на каждый календарный день в часовом
  поясе читателя («Сегодня» и «Вчера» с датой рядом, день недели в пределах
  недели, дальше дата); `none` — один список.
- `time-format` `auto|relative|exact` — `auto` (по умолчанию): под
  заголовком дня всегда время по часам («14:32»), и в первый час тоже — день
  уже назван заголовком; без групп — как `sf-time` в `auto` (в первый час
  «5 минут назад», дальше «09:12», «вчера, 19:40», «5 ноября»). `relative` — всегда
  относительно, `exact` — точное время, без групп с датой. Полный момент —
  в подсказке `sf-time` при наведении и фокусе.
- `now` — момент, от которого считаются время и дни (ISO 8601). Пусто — часы
  читателя: `sf-time` перерисовывается сам, список — заголовки дней в полночь.
- `collapse` — сколько событий серии видно до «Ещё N»; длиннее — остальные
  сворачиваются (5).
- `sticky-headings` — заголовки дней остаются на виду при прокрутке.
- `size` `1|1/2|2` — ступень линейки; `1/2` — для боковой панели.
- `heading-level` 2–6 (3) — уровень заголовков дней.
- `has-more` — после последнего события кнопка «Показать ещё»; её нажатие —
  событие `sf-list-timeline-load-more` `{direction: 'after', after: <id
  последнего>}`. Хост ставит `loading`, дописывает следующую страницу в
  `items` и снимает `has-more`, когда страниц больше нет.
- `loading` — следующая страница в пути: кнопка показывает загрузку и больше
  ничего не спрашивает.
- `empty-text` — тихая строка без событий, «Событий пока нет».
- `label` — имя списка для диктора без групп.
- `density` — устарело (до 2027-01-01): плотность задаёт страница,
  `data-sf-density="compact"` на списке или на области. `density="compact"`
  пока пишет это же на корень списка.

Состояния хоста: `data-empty`, `data-loading`.

## Геометрия

Одна ступень S: предложение — строка ступени L; строка времени и подпись
комментария — ступенью ниже. Значок — `.sf-featured-icon` ступени ниже, по
центру первой строки, на сплошном фоне места, чтобы линия не просвечивала.
Линия — толщиной в пиксель по оси значков, от середины первой строки одного
события до середины первой строки следующего; у последнего события дня линии
нет. Между событиями — `--sf-space-3`, внутри события — 0: видно, где одно
кончается. Заголовок дня — размера событий, полужирный, `--sf-space-3` сверху
и `--sf-space-1/2` снизу. Список свой фон не красит; плотность — от
страницы.

## Публичные переменные

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `--sf-list-timeline-line-color` | `--sf-outline-variant` | линия |
| `--sf-list-timeline-marker-color` | `--sf-on-surface-variant` | глиф нейтрального значка и точка |
| `--sf-list-timeline-time-color` | `--sf-on-surface-variant` | строка времени |
| `--sf-list-timeline-day-color` | `--sf-on-surface` | заголовки дней |
| `--sf-list-timeline-gap` | `--sf-space-3` | между событиями |
| `--sf-list-timeline-padding-inline` | 0 | отступ по краям |

SIMAI Framework сам их не задаёт.

## Доступность

Заголовки дней — `role="heading"` уровня `heading-level`, события дня —
упорядоченный список с именем по заголовку. Состояние или этап произносится
словами; значок и аватар — картинки, имя автора — текст. Время — `sf-time`:
элемент `time` с точным моментом, подсказка доступна с клавиатуры, Esc её
скрывает. «Ещё N» — кнопка; после нажатия фокус на первом раскрытом событии.
Живой области нет: хост, которому нужно озвучить новое событие, делает это
сам.
