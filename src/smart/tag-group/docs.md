# sf-tag-group

Ряд тегов: выбранные значения, фильтры над списком, теги в ячейке таблицы,
теги статьи. Группа держит то, что каждая страница раньше писала сама:
промежуток 4 между тегами, смысл «список» для экранного диктора, одну
остановку Tab на весь ряд, одну строку с «+N» и выбор одного или нескольких
фильтров.

```html
<sf-tag-group aria-label="Города">
  <sf-tag kind="default" closable text="Москва"></sf-tag>
  <sf-tag kind="default" closable text="Казань"></sf-tag>
  <sf-tag kind="default" closable text="Тверь"></sf-tag>
</sf-tag-group>

<sf-tag-group aria-label="Показать" selection="one">
  <sf-tag key="all" text="Все"></sf-tag>
  <sf-tag key="new" text="Новые" active></sf-tag>
  <sf-tag key="mine" text="Мои"></sf-tag>
</sf-tag-group>
```

Теги — обычные `sf-tag` страницы: группа их не рисует и не переносит. Тег
убирает страница: крестик и `Delete` присылают `sf-tag-close`, страница
удаляет элемент.

```js
group.addEventListener('sf-tag-close', (event) => event.target.remove());
```

## Ряд

- **В одну строку** (`layout="row"`, по умолчанию) — фильтры, ячейка таблицы,
  карточка. Теги не сжимаются; те, что не поместились, уходят из строки, а
  после последнего видимого стоит «+N». Первый тег стоит всегда, длинное имя
  заканчивается многоточием. Строка не меняет высоту.
- **С переносом** (`layout="wrap"`) — в форме: все теги на виду, на
  нескольких строках.

Между тегами 4 px (`gap-1/4`) по горизонтали и вертикали.

## «+N»

«+N» — тег-кнопка размера первого тега. Он открывает панель (`sf-popover`) со
скрытыми тегами и их крестиками и галочками. Нажатие в панели действует на
тег страницы: крестик присылает `sf-tag-close` от него, выбор — `change` от
него. Ряд раскладывается заново, панель следует за ним. `Escape` закрывает
панель и возвращает фокус на «+N».

## Клавиатура

Ряд — одна остановка Tab:

| Клавиша | Что делает |
| --- | --- |
| `←` / `→` | Предыдущий / следующий тег и «+N» (справа налево — наоборот) |
| `Home` / `End` | Первый / последний |
| `Delete`, `Backspace` | Убирает тег, на котором стоит фокус, если его можно убрать; фокус переходит к соседу |
| `Enter`, `Space` | Нажимает тег: выбирает фильтр, открывает «+N» |

Каждый шаг диктор слышит: «Москва, 1 из 3, Delete — убрать». Мышью крестик
работает как прежде.

## Выбор фильтров

`selection` — для тегов-фильтров (`kind="checkbox"`, вид по умолчанию):

- `none` (по умолчанию) — каждый тег сам по себе;
- `one` — выбран один: выбор тега снимает выбор с остальных, выбранный можно
  снять;
- `many` — выбирается любой набор.

Тег узнаётся по `key`, без него — по тексту. Значения группы: `selected` —
ключ выбранного (при `many` — первого), `selected-ids` — ключи всех выбранных
по порядку. Оба можно записать. Выбор человека группа сообщает событием
`sf-tag-group-select` с `detail` `{ids, id, selected}`.

## Настройки

- `layout` — `row` или `wrap`.
- `selection` — `none`, `one` или `many`.
- `aria-label` — имя ряда для диктора (атрибут хоста).

Не для кнопок: ряд кнопок — `sf-button-group`, переключатель из 2–5
вариантов — `sf-segmented`.
