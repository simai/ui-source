# Smart Help Mark

`<sf-help-mark>` — знак «?» рядом с подписью, который открывает короткое
пояснение. Открывается только нажатием (мышью, пальцем, Enter или пробелом),
наведение его не открывает. Второе нажатие, Escape или щелчок мимо закрывают
пояснение, фокус остаётся на кнопке. При открытии текст пояснения вежливо
объявляется для чтения с экрана.

```html
<label>Код решения <sf-help-mark label="Подробнее: код решения"
  heading="Код решения" text="Уникальное имя модуля латиницей, например simai.billing."></sf-help-mark></label>

<sf-help-mark label="Подробнее: уровни доступа">
  <div slot="content">Подробнее — в <a href="/docs/access">руководстве по доступу</a>.</div>
</sf-help-mark>
```

- `text` — пояснение. Вместо него можно передать слот `content` со ссылками или
  списком.
- `heading` — короткая строка заголовка над пояснением. Прежнее имя `title`
  работает до 2026-12-01: `title` — свойство любого элемента (стандарт 1.3.8 §3.1).
- `label` — доступное имя кнопки. По умолчанию «Подробнее». Лучше называть,
  о чём пояснение: «Подробнее: код решения».
- `size` — `1/3`, `1/2` (по умолчанию) или `1`, чтобы знак стоял на строке
  подписи.
- `placement` — `auto` (по умолчанию, снизу с переворотом), `top`, `bottom`,
  `start`, `end`.

Если в пояснении есть ссылка или другой элемент управления, Tab с кнопки
переходит в пояснение. Пояснение закрывается, когда фокус уходит и с кнопки, и
из пояснения. Без таких элементов Tab просто идёт дальше, а пояснение остаётся
открытым до Escape, повторного нажатия или щелчка мимо.

Ширина — не больше 20rem.

События — факты: `sf-help-mark-opened` (пояснение открыто) и
`sf-help-mark-closed` (закрыто). Прежние имена `sf-help-mark-open` и
`sf-help-mark-close` приходят следом до 2026-12-01 (`aliases.json`). Пока
пояснение открыто, на хосте стоит `data-open`.

Действия `open()` и `close()` открывают и закрывают пояснение из кода и
отвечают исходом (стандарт 1.3.8 §4.4): `{outcome: 'applied'}`, а `open()` —
`cancelled`, если пояснение закрыли, пока оно рисовалось.

Публичные переменные пояснения: `--sf-help-mark-background-color`,
`-color`, `-border-color`, `-radius`, `-max-width`, `-padding-inline`,
`-padding-block`, `-gap`.

Интерфейс — `component.json`, примеры — `examples.json`.
