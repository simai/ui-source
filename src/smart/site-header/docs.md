# Smart Site Header

`<sf-site-header>` — верхняя полоса сайта SIMAI: бренд, разделы, ссылки и
инструменты в одну строку по ширине контейнера. На узком экране разделы и
ссылки уходят в боковую панель, которую открывает кнопка меню. Одна шапка для
всех сайтов SIMAI: каталога эффектов, сайтов документации на Docara и
портала simai.io.

Шапка — рамка. Логотип, разделы, поиск, язык, тему и цвет передаёт сайт: это
его разметка в слотах, нарисованная компонентами SIMAI Framework.

```html
<sf-site-header>
  <a slot="brand" href="/"><svg …></svg><span>SIMAI</span></a>
  <nav aria-label="Разделы">
    <a href="/framework/">Framework</a>
    <a href="/docara/">Docara</a>
  </nav>
  <a slot="actions" href="https://github.com/simai">GitHub</a>
  <sf-button-group slot="tools" appearance="segmented" theme-switch size="1/2"></sf-button-group>
</sf-site-header>
```

## Слоты

| Слот | В широкой строке | На узком экране |
| --- | --- | --- |
| `brand` | в начале | остаётся в полосе |
| без имени (`nav`) | после бренда, занимает свободное место | в панели, колонкой |
| `actions` | в конце, перед инструментами | в панели, под разделами |
| `tools` | в конце | остаётся в полосе |
| `sheet` | не показан | в панели, последним |

Содержимое слотов — разметка страницы. Шапка ставит его на место один раз и
не копирует: в странице одна навигация, её обработчики и состояние
сохраняются. Навигация — `<nav aria-label>` страницы или
`<sf-menu orientation="horizontal" collapse="none">`; на узком экране шапка
переводит такое меню в колонку через его настройку `orientation`.

В `tools` кладут то, что нужно всегда: поиск, язык, тему
(`<sf-button-group appearance="segmented" theme-switch>`), цвет
(`<sf-color>`). Менее важное — в `actions`: на узком экране оно уйдёт в
панель. Слот `sheet` — то, что бывает только в панели, например дерево
документации; сайт может заполнить его по событию `sf-site-header-opened`.

## Узкий экран

`collapse` — ступень сетки Framework, ниже которой полоса сворачивается:
`sm` (32rem), `md` (44rem), `lg` (60rem, по умолчанию), `xl` (72rem). `always`
— панель при любой ширине, `none` — никогда. Переход — правило `@media` в
стилях компонента, поэтому первая отрисовка верна и без скрипта.

Панель открывается у начального края поверх затемнения. Она — слой общего
стека слоёв Framework, как `sf-drawer` и `sf-modal`: Escape и Tab получает
только верхний слой, страница не прокручивается, пока панель открыта.

## Размер и место

- `size` — ступень элементов полосы: `1` (по умолчанию) или `1/2`. Высота
  полосы — высота элемента этой ступени, отступ `--sf-space-1` сверху и снизу
  и граница в 1px. Кнопкам в слотах сайт ставит тот же `size`.
- `sticky` — полоса остаётся вверху окна при прокрутке. По умолчанию выключено.
- Боковые поля — поля `.container`: сайт задаёт `--sf-container-gutter` один
  раз для всей страницы, и полоса берёт их.

## Клавиатура и экранный диктор

Элемент рисует `<header>` — ориентир «баннер» страницы, если шапка стоит вне
`main`, `article`, `aside`, `nav` и `section`. Ориентир навигации — `<nav>`
страницы со своим `aria-label`; вторую обёртку шапка не добавляет. Кнопка
меню — `aria-haspopup="dialog"`, `aria-controls` и `aria-expanded`; открытая
панель — диалог, названный своим заголовком (`label`).

| Клавиша | Результат |
| --- | --- |
| `Tab` | Бренд, разделы, ссылки и инструменты по порядку; в открытой панели — только по ней |
| `Enter` или `Пробел` на кнопке меню | Открывает панель; фокус — на ссылке текущей страницы, иначе на первой ссылке |
| `Escape` | Закрывает панель и возвращает фокус на кнопку меню |

Нажатие на затемнение, кнопка закрытия и выбор ссылки в панели тоже её
закрывают; панель закрывается и тогда, когда окно стало шире `collapse`.

## Методы и события

| Метод | Что делает |
| --- | --- |
| `open()` | Открывает панель; отказ, если полоса не свёрнута или страница отменила `sf-site-header-open` |
| `close({reason})` | Закрывает панель |
| `toggle()` | Открывает или закрывает |

| Событие | Когда |
| --- | --- |
| `sf-site-header-open` | Панель вот-вот откроется; можно отменить |
| `sf-site-header-opened` | Панель открылась |
| `sf-site-header-close` | Панель вот-вот закроется, `detail.reason`: `close`, `escape`, `outside` или `api`; можно отменить |
| `sf-site-header-closed` | Панель закрылась, `detail.reason` |

## Настройка

| Переменная | Что меняет |
| --- | --- |
| `--sf-site-header-background` | Фон полосы |
| `--sf-site-header-color` | Цвет текста полосы |
| `--sf-site-header-border-color` | Нижняя граница полосы и заголовка панели |
| `--sf-site-header-block-size` | Высота полосы |
| `--sf-site-header-gap` | Расстояние между группами строки |
| `--sf-site-header-brand-size` | Высота картинки бренда |
| `--sf-site-header-sheet-inline-size` | Ширина открытой панели |
| `--sf-site-header-z-index` | Слой прилипшей полосы |

Сайты SIMAI не переопределяют значения Framework своими: переменные — для
уровней самого Framework (тема, область), а не для оформления отдельного
сайта.
