# Smart Code Input

`<sf-input-code>` — поле одноразового кода из сообщения, приложения или письма:
поле формы со своим значением, вставкой и ошибками. Элемент рисует разметку
классового кода подтверждения (`.sf-verification-form`), поэтому выглядит так
же, как он: те же ячейки, размеры, виды, ошибка и недоступность.

```html
<form>
  <sf-input-code label="Код из сообщения" name="code" required
                 hint="Мы отправили шесть цифр на +7 900 000-00-00"></sf-input-code>
</form>
```

## Одно поле под ячейками

Весь код хранит одно нативное поле, как в каноническом контракте класса: оно —
значение формы, фокус, то, во что пишут автозаполнение кода из сообщения
(`autocomplete="one-time-code"`), WebOTP и вставка, и то, что редактирует
экранный диктор. Ячейки — картинка этого поля. Поле на каждую ячейку разбило бы
вставку, автозаполнение и цель редактирования (класс убрал такую разметку из
новых примеров), поэтому одно поле ведёт себя как ячейки:

- символ, набранный в заполненную ячейку, заменяет её, а не сдвигает код;
  набранный после полного кода — заменяет последний символ;
- Backspace очищает ячейку перед курсором и переходит в неё, Delete — ячейку
  после курсора; пропусков в коде нет, следующие символы сдвигаются;
- стрелки, Home и End переходят между ячейками, щелчок ставит курсор в ячейку,
  по которой щёлкнули;
- вставленный полный код заполняет все ячейки, где бы ни стоял курсор, часть
  кода встаёт на место курсора; всё, чего нет в `mode` (или в `charset`),
  отбрасывается;
- курсор нарисован в ячейке, куда встанет следующий символ; курсор внутри
  кода отмечает одну ячейку — её заменит ввод и очистит Backspace;
- выделение видно на ячейках: мышью — протянуть по ячейкам, двойной щелчок
  выделяет весь код, Shift со стрелками — по ячейке; копирование даёт
  выделенный код (скрытый `mask` не копируется);
- кольцо фокуса — только у активной ячейки и только при переходе с
  клавиатуры; наведение отмечает одну ячейку.

```html
<sf-input-code label="Код Steam Guard" length="5" uppercase
               charset="23456789BCDFGHJKMNPQRTVWXY"></sf-input-code>
<sf-input-code label="Код из приложения" groups="3"></sf-input-code>
```

Код, пришедший через WebOTP (`navigator.credentials.get({otp: …})`),
записывайте в `value` — или дайте браузеру подставить его сам через
автозаполнение.

## Атрибуты

| Атрибут | Что делает |
| --- | --- |
| `length` | Число символов и ячеек, от 1 до 12; по умолчанию 6. |
| `value` | Код. Атрибут следует за вводом. Лишние символы и всё сверх `length` отбрасываются. |
| `default-value` | Код, к которому возвращает сброс формы. |
| `name` | Имя поля в форме: нативное поле и есть значение формы. |
| `mode` | `numeric` (по умолчанию) — цифры и цифровая клавиатура; `alphanumeric` — латинские буквы и цифры. Неполный код форма не примет (`tooShort`, «Введите код целиком»); у внутреннего поля нет `pattern`, поэтому браузер не показывает свою английскую подсказку. |
| `charset` | Свой алфавит: остаются только эти символы, например `23456789BCDFGHJKMNPQRTVWXY` (как в Steam Guard, без 0, O, 1, I). Заданный, он заменяет `mode`; клавиатура цифровая, если в алфавите одни цифры. |
| `uppercase` | Буквы при вводе и вставке становятся заглавными: вставленный `ab12cd` — это `AB12CD`; клавиатура предлагает заглавные. С алфавитом из заглавных букв ставьте и его, иначе строчная буква не примется. |
| `groups` | Сколько ячеек в группе, между группами — разделитель: `3` — «3 + 3», `4` — «4 + 4»; от 2 до 6 и меньше длины кода. По умолчанию `0` — без разделителя. Разделитель — только рисунок: его нет в значении, при копировании и для экранного диктора. |
| `size` | Ступень полей формы: `1/2`, `1` (по умолчанию), `2` — как у `sf-input`. |
| `appearance` | `bordered` (по умолчанию) — ячейки с границей; `filled` — ячейки на тональной заливке, пока поле не в фокусе. |
| `label`, `hint` | Подпись и подсказка под ячейками. Подпись называет группу и поле. |
| `required`, `disabled`, `readonly` | Как у нативного поля. |
| `invalid` (`error`), `error-message` | Код не принят: ячейки и подсказка цветом ошибки, у поля `aria-invalid`, текст ошибки вместо подсказки. Ставит и снимает их приложение. |
| `mask` | Символы показываются точками; поле становится полем пароля, и экранный диктор не читает код вслух. |
| `aria-label` | Имя группы и поля, когда видимой подписи нет. |

Подпись, подсказку и ошибку можно передать и разметкой — слоты `label`,
`hint`, `error`.

## События и методы

- `input` и `change` — нативные события внутреннего поля, как у `sf-input`.
  `input` приходит уже с очищенным значением; `change` — один раз, когда поле
  теряет фокус с другим кодом.
- `sf-code-input:complete` — `detail: {value}`, когда заполнены все ячейки
  после правки человека: один раз на каждый полный код, после его `input`.
  Форму компонент не отправляет и код не проверяет — это решает приложение.
- `value` — свойство: прочитать или записать код; записанный из кода — не
  правка человека, событий нет (`value = ''` очищает поле).
  `complete` — заполнены ли все ячейки.
- `focus()` и `getInputElement()` — фокус и нативное поле.

```js
document.addEventListener('sf-code-input:complete', async (event) => {
  const field = event.target;
  const ok = await checkCode(event.detail.value);
  field.toggleAttribute('invalid', !ok);
  field.setAttribute('error-message', ok ? '' : 'Неверный код');
});
```

## Клавиатура и экранный диктор

Группа (`role="group"`) и поле названы подписью. Поле описано строкой, которая
говорит, в какой ячейке курсор, — «цифра 3 из 6» (для `alphanumeric` —
«символ 3 из 6»; по-английски «digit 3 of 6») на языке страницы; строка
вежливо озвучивается каждый раз, когда курсор переходит в другую ячейку. Затем
поле описывает подсказка или текст ошибки. Ячейки скрыты от вспомогательных
технологий. Символы кода всегда идут слева направо, и на странице, которая
пишет справа налево.

Слова на других языках добавляются через `SF.language` для компонента
`sf-input-code`: ключи `digit`, `character` (`{n}` — ячейка, `{m}` — длина) и
`group` — имя группы без подписи и `aria-label`.

## Настройка

Переменные классового кода подтверждения — их можно задать на элементе или на
любом предке:

| Переменная | Что меняет | По умолчанию |
| --- | --- | --- |
| `--sf-verification-background-color` | Заливка ячейки в покое: у `bordered` прозрачная, у `filled` тональная | `var(--sf-transparent)`; у `filled` — `var(--sf-surface-container)` |
| `--sf-verification-border-color` | Граница ячейки в покое | `var(--sf-outline)` |
| `--sf-verification-border-width` | Толщина границы ячейки | `var(--sf-px)` |
| `--sf-verification-radius` | Скругление ячейки и кольца фокуса | `var(--sf-radius--ui)` |
| `--sf-verification-color` | Цвет символов в ячейках | `var(--sf-on-surface)` |
| `--sf-verification-cell-size` | Ширина и высота ячейки — одна на всех размерах, если задана | `var(--sf-title-height-6)` |
| `--sf-verification-gap` | Расстояние между ячейками | `var(--sf-space-1/3)` |
| `--sf-verification-invalid-border-color` | Рамка ячеек в состоянии ошибки. | `var(--sf-error)` |

Наведение, текущая ячейка, фокус, ошибка и недоступность рисуются своими
цветами и поверх настроенных.
