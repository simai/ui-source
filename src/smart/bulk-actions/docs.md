# sf-bulk-actions

Полоса групповых действий: появляется у списка, пока в нём что-то выбрано, —
«Выбрано N», действия над выбранными и крестик «Снять выбор». Одна полоса для
таблицы, карточек, галереи, дерева и простого списка.

```html
<sf-bulk-actions count="2" page-count="12" total="240"></sf-bulk-actions>
<script>
  const bar = document.querySelector('sf-bulk-actions');
  bar.actions = [
    {id: 'publish', text: 'Опубликовать', icon: 'public'},
    {id: 'move', text: 'Переместить', icon: 'drive_file_move'},
    {id: 'export', text: 'Экспорт', icon: 'download'},
    {id: 'archive', text: 'В архив', icon: 'archive', undo: true},
    {id: 'delete', text: 'Удалить', icon: 'delete'},
  ];
  bar.addEventListener('sf-bulk-actions-action', (event) => {
    const {id, scope, count} = event.detail; // scope: selection или all
    // список выполняет действие над выбранными или над всеми по фильтру
  });
</script>
```

Где нужна: списки админки, письма и чаты, медиатека, таблицы ui-admin, дерево
файлов — везде, где человек отмечает несколько записей и делает с ними одно
действие.

## Что показывает

- **Сколько выбрано** — «Выбрано 2». Пока `count` равен 0, полосы нет.
  Свою строку счёта список задаёт в `count-text` («Выбрано 3 · с вложенными 48»).
- **Действия** — до трёх кнопок с подписью, сколько помещается по ширине,
  остальные в «⋯» (общее меню страницы). Подпись кнопки никогда не
  переносится на вторую строку, и кнопка остаётся высотой своего размера:
  если ряд не помещается (полоса рядом с открытой записью, узкое окно),
  последнее действие уходит в «⋯», за ним следующее; когда места снова
  хватает, они возвращаются. «Выбрано N» всегда остаётся в той же строке.
  На телефоне — одна кнопка-значок с подсказкой и «⋯»; действие без значка
  (`icon`) на телефоне всегда в «⋯», со своей подписью.
- **Опасное действие** («Удалить») — всегда последним в «⋯», после линии,
  красным. Перед ним открывается окно-вопрос: «Удалить 2 элемента?»,
  «Вернуть будет нельзя». Своё окно-вопрос странице не нужно.
- **Обратимое действие** (`undo: true`, «В архив») выполняется сразу, а в
  уведомлении есть «Отменить» — нажатие приходит событием `undo`.
- **Недоступное действие** («Сделать обложкой» при двух картинках) — бледное,
  но Tab на нём останавливается, причина — в подсказке (`max`, `min`, `reason`).
- **Все по фильтру.** Когда выбрана вся страница (`count` равен
  `page-count`, а `total` больше), появляется кнопка «Выбрать все 240». После
  нажатия полоса говорит «Выбраны все 240», а следующее действие придёт с
  `scope: all`. «Только эта страница (12)» возвращает обратно. Любое другое
  изменение выбора тоже возвращает к странице. На телефоне полоса остаётся
  в одну строку: если «Выбрать все 240» не помещается рядом со счётом и
  кнопками, предложение уходит первым пунктом в «⋯» и возвращается, когда
  места хватает (решение C309 (1)).
- **Крестик и Escape** снимают выбор: событие `clear`. Escape работает, пока
  фокус в списке или в полосе и не занят меню, окном или полем ввода.

## Итог действия

Список выполняет действие по событию `sf-bulk-actions-action` и сообщает итог
методом `result()`. Куда полоса его выведет, решает длина действия (решение
C387):

- **Быстрое действие** — итог прямо в полосе, на месте «Выбрано N»:
  «Удалено: 5» четыре секунды, потом полоса возвращается к счёту (или
  прячется, если выбор снят). Слово итога действие задаёт в `done-text`
  («Удалено»); без него — «Готово: 5».
- **Долгое действие** идёт в фоне: полоса на миг говорит «Экспорт: идёт в
  фоне», а по окончании приходит всплывающее сообщение — «Экспортировано: 500»
  или ошибка, которая ждёт, пока её закроют, с кнопкой «Подробнее».
- **Неудача** любого действия записывается в «Уведомления».

Долгим действие считается, когда оно идёт больше чем на 100 записей, или
когда автор пишет `long: true`; `long: false` оставляет большое действие в
полосе. Событие `action` приносит `long`, чтобы список знал, что запускать
работу в фоне.

```js
bar.actions = [
  {id: 'delete', text: 'Удалить', icon: 'delete', 'done-text': 'Удалено'},
  {id: 'export', text: 'Экспорт', icon: 'download', long: true, 'done-text': 'Экспортировано'},
];
bar.addEventListener('sf-bulk-actions-action', async (event) => {
  const {id, scope, count, long} = event.detail;
  const answer = await list.run(id, scope);          // работа списка
  bar.result({id, ok: answer.ok, failed: answer.failed});
});
```

С отказами быстрое действие показывает в полосе, что не вышло:

```js
bar.progress({done: 4, total: 12});          // «Выполняем: 4 из 12»
bar.result({id: 'publish', ok: 10, failed: [
  {id: 's3', text: 'Склад', reason: 'Нет главной страницы'},
  {id: 's5', text: 'Блог', reason: 'Нет прав на раздел'},
]});                                         // «Готово 10 из 12 · 2 не удалось»
```

«Подробнее» показывает, что и почему не получилось, «Повторить для 2»
отправляет действие ещё раз. Не получившиеся записи список оставляет
выбранными. У долгого действия «Подробнее» стоит в сообщении об ошибке.
Ход долгой работы показывает `sf-progress-run`: `progress()` больше чем для
100 записей отвечает отказом `long`.

Обратимое действие (`undo: true`) сообщает об успехе один раз — сообщением с
«Отменить» сразу после нажатия; полоса его не повторяет.

**«Уведомления».** Отдельной части «Уведомления» в SIMAI Framework пока нет.
Неудача уходит через `SF.notify`: каждое сообщение объявляется на документе
событием `sf-notification` (`source: 'sf-bulk-actions'`), и центр уведомлений
продукта записывает его. Неудача быстрого действия записывается без
всплывающего сообщения — её уже видно в полосе.

## Где стоит

| `place` | Где |
|:---|:---|
| `dock` (по умолчанию) | под списком, во всю его ширину, прилипает к низу экрана при прокрутке |
| `top` | на месте панели инструментов, на основном контейнере |
| `float` | плашка посередине нижнего края окна |
| `inline` | обычная строка в потоке |

Список ставит элемент сам: после списка для `dock` и `inline`, перед ним для
`top`. Размер (`size`: `1/2`, `1`, `2`) берётся у ближайшего элемента с
размером вокруг — у списка; высота полосы — высота кнопки этого размера и по
4 px сверху и снизу.

## Кто за что отвечает

- **Полоса**: счёт, предложение «Выбрать все N», кнопки и «⋯», вопрос перед
  опасным действием, «Отменить» в уведомлении, короткий прогон, куда выводить
  итог (полоса, сообщение, «Уведомления»), объявления для экранного диктора.
- **Список**: что выбрано (флажки строк, флажок «все», Shift), что значит «все
  по фильтру», само действие, его отмена и работа в фоне, какие записи не
  получились (`result()`).

## Доступность

Полоса — область с названием «Действия с выбранными». Кнопки стоят обычным
рядом в порядке Tab, через 8 px. Фокус в полосу не переносится, когда человек
отмечает строку; после окна-вопроса возвращается туда, откуда его открыли.
Экранный диктор слышит «Выбрано 3», «Выбраны все 240», «Выбор снят», ход и
итог — спокойно, после того как выбор устоялся.

## Настройка вида

Открытые CSS-переменные: `--sf-bulk-actions-background`,
`--sf-bulk-actions-border-color`, `--sf-bulk-actions-color`,
`--sf-bulk-actions-gap`, `--sf-bulk-actions-padding-block`,
`--sf-bulk-actions-padding-inline`, `--sf-bulk-actions-radius`.

Отступы полосы — как у окна настроек вида: сверху, снизу и в конце
`--sf-space-1/3`, в начале `--sf-space-1` (8 / 16 / 8 на компьютере; на
телефоне `--sf-space-1/3` с обеих сторон). Высота полосы — высота кнопок её
размера, два отступа и рамка: 58 при размере 1 на компьютере. Свои отступы
задаются переменными: `--sf-bulk-actions-padding-inline` принимает одно
значение (обе стороны) или два (начало и конец).

```css
.my-list sf-bulk-actions {
  --sf-bulk-actions-padding-block: var(--sf-space-1\/4);
  --sf-bulk-actions-padding-inline: var(--sf-space-1\/2) var(--sf-space-1\/4);
}
```

## Старые полосы

`sf-pagination` с `actions` теперь рисует эту полосу; его настройки и события
(`sf-pagination-apply`, `sf-pagination-selection-clear`) работают до
2027-01-01. Полоса в `sf-view`, кнопки `setBulkActions` у `sf-view-table` и
слот `actions` у `sf-gallery` переходят на `sf-bulk-actions` в их следующих
выпусках; старые имена работают до 2027-01-01.
