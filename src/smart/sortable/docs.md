# sf-sortable

Smart Sortable — примитив перетаскивания для списков: переставить элементы
внутри списка, перенести между списками одной группы или скопировать из
библиотеки. Работает мышью, пером, касанием и клавиатурой. Компонент только
сообщает намерение событием `sf-sortable-intent`; DOM и данные меняет хост.

Код загружается по требованию: загрузчик Framework подключает
`smart/sortable` только на страницах с тегом `sf-sortable`.

## Базовое использование

```html
<sf-sortable id="sections" group="sections" label="Секции">
  <div data-sf-sortable-item="s1"><span data-sf-sortable-handle aria-hidden="true">⠿</span>Секция 1</div>
  <div data-sf-sortable-item="s2"><span data-sf-sortable-handle aria-hidden="true">⠿</span>Секция 2</div>
</sf-sortable>
```

```js
document.addEventListener('sf-sortable-intent', (event) => {
  const {item, from, to, index, mode} = event.detail; // index — итоговая позиция
  // Применить к своей модели с ожидаемой ревизией; при отказе ничего не менять.
});
```

## Атрибуты

- `group` — имя группы (`^[a-z][a-z0-9-]{0,31}$`);
- `accepts` — дополнительные группы, которые список принимает;
- `mode` — `move` или `copy` (источник-библиотека сохраняет элемент и ничего не принимает);
- `orientation` — `vertical` или `horizontal`;
- `label` — имя списка для объявлений.
- `inserter-items` — виды элементов для вставщика (JSON или свойство `inserterItems`); см. «Точка вставки и вставщик».
- `preview` — как видно место при перетаскивании мышью или касанием: `silhouette` (по умолчанию) убирает элемент из списка и раскрывает на месте, куда он встанет, контур его размера — список раздвигается; `line` рисует там тонкую линию. Клавиатура, внешние цели и списки-сетки всегда показывают линию.

## Элементы

Элементы — потомки с `data-sf-sortable-item="<id>"`. Ручка
`data-sf-sortable-handle` ограничивает перетаскивание и служит целью касания;
без ручки перетаскивается весь элемент.

## Клавиатура и доступность

Пробел или Enter — взять, стрелки вверх/вниз — позиция в списке, влево/вправо —
соседний список или внешняя цель, Пробел или Enter — положить, Escape или Tab —
отменить. Каждый шаг объявляется на языке страницы. При перетаскивании мышью
у краёв прокручиваемой области включается автопрокрутка.

## Применение намерения в редакторе

Компонент сообщает намерение, список перерисовывает хост. Четыре правила —
из первого редактора на этом компоненте (ui-mail, 21.10.2026):

1. **У каждого списка свой `id`.** `from` и `to` в `sf-sortable-intent` — это
   `id` элемента списка (имя группы — только если `id` нет), поэтому хост,
   который ищет по `to` нужный список, без `id` его не найдёт.
2. **Перерисовывать элементы, а не список.** `list.replaceChildren(…)` удаляет
   и два узла, которые компонент держит среди своих детей: область объявлений
   `aria-live` и подсказку, на которую элементы ссылаются через
   `aria-describedby`. Заменяйте только детей с `data-sf-sortable-item`.
   Если их всё же удалили, компонент возвращает оба узла с тем же `id`
   подсказки, и объявления продолжают работать — но перерисовка одних
   элементов их вообще не трогает.
3. **Фокус после клавиатуры возвращается сам.** После клавиатурного «положить»
   компонент через два кадра (хост к этому времени перерисовал список) ставит
   фокус на элемент с тем же id в том списке, куда он попал. Если хост
   восстановил фокус сам, компонент его не трогает: он вмешивается только
   когда фокус упал на `body`.
4. **Применять с ожидаемой ревизией.** `index` — итоговая позиция: места после
   источника уже сдвинуты. При отказе ничего не менять — компонент сам ничего
   не переместил.

```js
list.addEventListener('sf-sortable-intent', (event) => {
  const {item, from, to, index, mode} = event.detail;
  if (!model.apply({item, from, to, index, mode})) return; // отказ — без перерисовки
  for (const element of list.querySelectorAll('[data-sf-sortable-item]')) element.remove();
  list.append(...model.items(to).map(renderItem));   // область объявлений на месте
});
```

## Точка вставки и вставщик

Редактору блоков нужен «+» ровно там, куда встанет новый элемент, а не кнопка
«Добавить», которая всегда кладёт в конец. Дайте списку виды элементов, которые
в него можно вставить, и он покажет точку вставки на промежутке между
элементами, перед первым и после последнего; точка открывает список видов с
поиском. Без `inserter-items` список рисуется и работает как раньше,
перетаскивание не меняется в любом случае.

```html
<sf-sortable id="blocks" group="blocks" label="Письмо"
  inserter-items='[{"value":"heading","label":"Заголовок","icon":"title"},{"value":"text","label":"Текст","icon":"notes","keywords":"абзац"}]'>
  <div data-sf-sortable-item="b1">Заголовок</div>
  <div data-sf-sortable-item="b2">Текст</div>
</sf-sortable>
```

```js
blocks.inserterItems = [
  {type: 'heading', label: 'Содержимое'},
  {value: 'heading', label: 'Заголовок', icon: 'title'},
  {value: 'button', label: 'Кнопка', icon: 'smart_button', caption: 'Ссылка в виде кнопки'},
];
blocks.addEventListener('sf-sortable-insert', (event) => {
  const {index, item, to} = event.detail; // index — позиция нового элемента
  if (!model.insert({kind: item, list: to, index})) event.preventDefault(); // отказ — вставщик остаётся открытым
  else redraw(); // элемент создаёт хост, компонент — никогда
});
```

- Вид: `{value, label, icon?, caption?, keywords?, disabled?}`; группы —
  `{type: 'heading', label}` и `{type: 'separator'}`. Поиск ищет по подписи,
  второй строке и `keywords`.
- `sf-sortable-insert` — `{index, item, to}`: `item` — выбранный `value`,
  `to` — `id` списка (без `id` — его группа). Событие всплывает и отменяемо.
  Если его не отменили, вставщик закрывается и фокус возвращается туда, где
  был, — если только хост сам не перевёл его, например на новый элемент.
- Мышь: «+» появляется на промежутке, к которому подведён указатель, и на месте
  после строки в фокусе — так до него достаёт и касание, у которого нет
  наведения. Пока что-то перетаскивают, точки нет.
- Клавиатура: точка — **последняя остановка Tab** в списке: Tab с последней
  строки приходит на неё, Tab с неё уходит из списка, фокус не запирается.
  Стрелки по направлению списка переводят её между местами, Home и End — на
  первое и последнее, каждый шаг объявляется; Enter или Пробел открывают
  вставщик. На строке в фокусе **`+`** открывает вставщик для места после неё;
  это сказано в подсказке строки.
- Вставщик — стандартное меню `sf-context-menu`: ввод сужает список, `↓`
  переходит к пунктам, стрелки и Enter выбирают, Enter в поиске берёт первый
  оставшийся пункт. Escape закрывает только вставщик: выдвижная панель или
  окно вокруг списка остаются открытыми.
- «+» — кнопка-иконка ступени 1/3 на приподнятой поверхности с тенью; линия
  2px цвета `--sf-primary` отмечает промежуток. Пока у списка есть вставщик,
  у него `position: relative`.

## Режим колонок: SF.Sortable.attach

Таблице нельзя обернуть ячейки шапки в `sf-sortable`, а колонка переезжает вместе
с ячейками всех строк. Для этого есть контроллер, который даёт то же
перетаскивание мышью и касанием любому контейнеру:

```js
const detach = SF.Sortable.attach(table.tHead.rows[0], {
  items: 'th[data-key]',                 // что перетаскивается
  extent: table,                         // во что «растягивается» контур
  cellsOf: (th) => [...table.rows].map((tr) => tr.cells[th.cellIndex]),
  groupOf: (th) => th.dataset.pinned ? 'pinned' : 'loose', // двигать внутри группы
  canStart: (event, th) => !event.target.closest('.resizer'),
  label: 'Колонки',
  onIntent: ({item, index, group}) => { /* новый порядок */ },
});
```

Пока колонку тянут, она приглушена во всех строках, а на месте, куда она
встанет, стоит пунктирный контур шириной в колонку и высотой во всю таблицу
(`preview: 'column'`, по умолчанию; `'line'` — тонкая линия). `index` — место
среди колонок той же группы без перетаскиваемой. Клик, которым заканчивается
перетаскивание, до заголовка не доходит, поэтому сортировка по клику не
срабатывает от отпускания. Перестановку с клавиатуры даёт список колонок в
настройках таблицы — обычный `sf-sortable`.

## События

- `sf-sortable-intent` — `{item, from, to, index, mode}`;
- `sf-sortable-state` — `{state: 'picked' | 'dropped' | 'cancelled', item}`: начало и конец сеанса;
- `sf-sortable-insert` — `{index, item, to}`: выбор во вставщике, отменяемое.

Внешние цели (например, `sf-composition-overlay`) подключаются через
`SF.Sortable.registerSortableDropTarget`. Сеанс перетаскивания общий для всех
Smart-бандлов.
