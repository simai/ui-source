# sf-steps

Шаги показывают, где человек находится в упорядоченном процессе, который он
проходит сам: сколько шагов позади и сколько впереди (решение владельца C101).

Когда брать другой компонент:

| Что на экране | Компонент |
|---|---|
| Долгая работа сервера: создать сайт, обновить, перенести, опубликовать — со временем шагов, журналом и повтором | `sf-progress-run` |
| Задачи, которые делают в любом порядке («Настройте магазин: 3 из 5») | список задач (`sf-list` со статусом), не шаги |
| Весь мастер: тело шага, «Назад» и «Далее», правила перехода | `sf-wizard` (он сам рисует шаги через `sf-steps`) |
| То, что уже случилось, по времени | `sf-list-timeline` |

## Сценарии

Оформление заказа — строка, к пройденным шагам можно вернуться:

```html
<sf-steps aria-label="Оформление заказа" current="2" navigation="visited" items='[
  {"label": "Корзина"}, {"label": "Доставка"},
  {"label": "Оплата"}, {"label": "Подтверждение"}
]'></sf-steps>
```

Статус заказа — столбец, вторая строка с датой:

```html
<sf-steps aria-label="Статус заказа" layout="column" current="2" items='[
  {"label": "Заказ принят", "text": "12 ноября, 10:14"},
  {"label": "Собран на складе", "text": "12 ноября, 15:40"},
  {"label": "Передан в службу доставки", "text": "ожидается 13 ноября"},
  {"label": "Получен"}
]'></sf-steps>
```

Заявка в плотной карточке — точки, половинный размер:

```html
<sf-steps aria-label="Заявка" marker="dot" size="1/2" current="1"
  items='[{"label": "Принята"}, {"label": "На рассмотрении"}, {"label": "Решение"}]'></sf-steps>
```

Узкое место — строка «Шаг 3 из 4 · Документы» над полосой хода
(`layout="count"`; при `layout="auto"` так рисуется само уже 20rem).

Всё пройдено — `current` равен числу шагов: текущего шага нет, все отмечены
пройденными, линия хода идёт до конца.

## Вид

Метка + подпись + линия. Линия — 2 px основного цвета до текущего шага и
1 px `outline-variant` после него. Пилюль и знака «›» нет: «›» — язык
хлебных крошек.

`marker="number"` (по умолчанию) — номер шага; `marker="dot"` — точка, для
пассивного статуса и плотных карточек. Метка равна строке текста ступени:
24 px у `size="1"`, 20 px у `size="1/2"` на десктопе (на телефоне и в
компактной плотности — вместе с лестницей текста).

## Состояния

Состояние видно по форме и основному цвету, а не только по цвету (C61, C73):

| Состояние | Метка | Подпись | Слово для программы чтения |
|---|---|---|---|
| `done` — пройден | заливка с галочкой | обычная | «Пройден» / «Completed» |
| текущий (по `current`) | заливка с кольцом через зазор | полужирная | «Текущий» / «Current» и `aria-current="step"` |
| `ahead` — впереди | пустой контур с номером | приглушённая | «Впереди» / «Not started» |
| `error` — ошибка | цвет ошибки, «!» | цвет ошибки | «Ошибка» / «Error» |
| `skipped` — пропущен | пунктирный контур | приглушённая | «Пропущен» / «Skipped» |
| `running` — выполняется | индикатор загрузки Framework размером с метку, по центру | полужирная | «Выполняется» / «In progress» |

Зелёного у шагов нет: зелёный — только настоящий статус всей работы
(«Готово», «Опубликовано»), его показывает хозяин рядом.

Собственное состояние элемента важнее места: без него шаг до `current` —
пройден, на `current` — текущий, после — впереди. `running` и `error` сильнее
места. Шаг до текущего, который не сделали, хозяин отмечает `"ahead"`;
`"done"` и `"skipped"` на месте текущего шага рисуются текущим.

## Раскладка

`layout="auto"` (по умолчанию): строка, пока все шаги помещаются по своей
ширине в одну линию; иначе столбец (подпись и вторая строка `text`); уже 20rem
— строка «Шаг N из M · подпись» над `sf-progress-bar size="1/3"`, как у
`sf-wizard`. `row`, `column` и `count` рисуют свою раскладку всегда; строка,
которая шире своего места, прокручивается внутри себя. Подписи не
разрываются внутри слова ни при какой ширине.

## Поведение

По умолчанию шаги не нажимаются: это список `ol` с `aria-current="step"` у
текущего элемента и словом состояния в каждом.

`navigation="visited"` делает кнопками шаги позади текущего и шаги в
состоянии `done`, `skipped`, `error`; `navigation="free"` — все доступные.
Текущий шаг и шаг с `disabled` кнопкой не бывают. Нажатие переходит к шагу и
отправляет `sf-steps-change` с `{previous, current, item, items}`. Старое имя
`sf-step-change` работает до 2026-12-01.

- `goToStep(index)` — действие `go-to-step`: переходит к шагу и отвечает
  `{outcome: 'applied'}` или `{outcome: 'refused', reason}` (`disabled`,
  `current`, `out-of-range`). Событие при этом не отправляется.
- `onStepChange(handler)` — подписка на `sf-steps-change`.

## Формат списка

Один формат — JSON: `[{label, text?, state?, disabled?}]` в атрибуте `items`
или массив в свойстве `items`.

Старая форма читается до 2027-01-01, и каждое её использование записывается
в `SF.deprecations` с датами:

- строка `items="Корзина::completed|Доставка|Оплата::disabled"`;
- слова состояния `completed` (сейчас `done`) и `default` (сейчас `ahead`);
- `error-step="2"` (сейчас `"state": "error"` у элемента);
- `separator-icon` — больше ничего не рисует.

## Атрибуты

- `size="1|1/2"`, `marker="number|dot"`, `layout="auto|row|column|count"`,
  `navigation="visited|free"` (пусто — пассивный список)
- `items`, `current`
- `aria-label` — имя списка (пусто — «Шаги» / «Steps»)
- `completed-label`, `current-label`, `ahead-label`, `error-label`,
  `skipped-label`, `running-label` — слова состояний; `count-label` —
  «Шаг {n} из {count}»
- `root-class` — классы видимого корня `.sf-steps`; оболочка остаётся
  `display: contents`

## Внешний вид

Публичные переменные:

- `--sf-steps-gap` — промежуток между шагами строки;
- `--sf-steps-completed-icon-color` — цвет хода: пройденные и текущая метки,
  линия до текущего;
- `--sf-steps-current-border-color` — кольцо текущей метки;
- `--sf-steps-step-color` — подпись и номер шагов впереди;
- `--sf-steps-step-border-color` — контур пустой метки;
- `--sf-steps-separator-color` — линия после текущего шага;
- `--sf-steps-step-radius` — скругление метки.
