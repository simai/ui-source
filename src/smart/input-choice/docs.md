# Выбор карточками

Поле формы, в котором человек выбирает один вариант или несколько из
карточек: у каждой название, пояснение, метка, цена со сроком, иконка или
картинка. Подходит, когда вариантов немного и их надо объяснить словами:
доставка, оплата, тариф, модули, шаблон, тип сайта, куда сохранять копии. Все
варианты видны сразу. Нажимается вся карточка; на строке названия стоит
настоящий переключатель или флажок — такой же, как у `sf-radio` и
`sf-checkbox`.

```html
<sf-input-choice label="Тип сайта" name="kind" value="shop" hint="Тип можно сменить позже." items='[
  {"value": "site", "label": "Сайт", "caption": "Страницы, разделы и меню", "icon": "language"},
  {"value": "shop", "label": "Магазин", "caption": "Каталог, корзина и заказы", "icon": "storefront", "badge": "Pro"},
  {"value": "docs", "label": "Документация", "caption": "Статьи с поиском и оглавлением", "icon": "menu_book"}
]'></sf-input-choice>
```

## Варианты

`items` — список вариантов: свойством, JSON-островом
(`<script type="application/json" data-sf-settings>`) или атрибутом с JSON.

| Поле | Что это |
| --- | --- |
| `value` | Значение, которое уходит с формой. Обязательно; повтор пропускается. |
| `label` | Название на карточке (можно `title`). Без него — значение. |
| `caption` | Пояснение под названием. |
| `icon` | Иконка на строке названия, высотой в строку (имя из шрифта иконок). |
| `badge` | Короткая метка `sf-badge` рядом с названием («Pro», «Выгодно»). |
| `price` | Цена: в строках — колонкой в конце строки названия, в плитках — внизу карточки за линией. |
| `term` | Срок или единица цены («2–3 дня», «в месяц»): под ценой в строках, рядом с ценой в плитках. |
| `image` | Адрес картинки для раскладки `picture`: картинка до краёв карточки, подпись под ней. |
| `disabled` | Карточку нельзя выбрать. |

## Раскладка

`layout` • по умолчанию `tile`

| Значение | Как выглядит | Для чего |
| --- | --- | --- |
| `list` | Одна рамка, строки через линию; переключатель в начале строки, цена и срок колонкой в конце строки названия | Доставка, оплата |
| `tile` | Плитки сеткой; переключатель в правом верхнем углу на строке названия; название, пояснение и цена от одного левого края, цена внизу за линией | Тарифы, модули |
| `picture` | Плитки с картинкой до краёв, подпись под ней, переключатель в конце строки подписи; на телефоне (поле уже 30rem) плитка становится строкой: картинка слева, подпись рядом | Шаблоны, темы |

```html
<sf-input-choice label="Способ доставки" name="delivery" layout="list" value="pickup" items='[
  {"value": "courier", "label": "Курьером", "caption": "Привезём в удобный интервал", "price": "350 ₽", "term": "2–3 дня"},
  {"value": "pickup", "label": "Пункт выдачи", "caption": "Больше 2 000 пунктов по стране", "price": "150 ₽", "term": "1–2 дня", "badge": "Выгодно"},
  {"value": "post", "label": "Почта России", "caption": "Временно недоступна", "disabled": true}
]'></sf-input-choice>
```

## Один или несколько

`multiple` • по умолчанию выключено

Без `multiple` выбирается один вариант: карточки — группа переключателей
(`radiogroup`). С `multiple` — несколько: каждая карточка — флажок.

```html
<sf-input-choice label="Куда сохранять копии" name="targets" multiple value="local,s3" items='[
  {"value": "local", "label": "Этот сервер", "caption": "Быстро, но пропадёт вместе с сервером"},
  {"value": "s3", "label": "Хранилище S3", "caption": "Отдельно от сервера"},
  {"value": "ftp", "label": "FTP", "caption": "Устаревший способ", "disabled": true}
]'></sf-input-choice>
```

## Значение

`value` — значение выбранного варианта; при `multiple` — значения через
запятую в порядке вариантов (`local,s3`). Атрибут `value` — то, к чему
возвращает сброс формы. Из кода можно записать строку или список
(`el.value = ['local', 's3']`) — событий при этом нет. Свойство `selected` —
выбранные значения списком.

С формой уходит одно поле `name` с выбранным значением, при `multiple` — по
полю на каждое значение. Ничего не выбрано — поле не уходит; с `required`
форма не отправится (`value-missing`).

## Сетка

`columns` • по умолчанию `auto` • для `tile` и `picture`; `list` — всегда один столбец

`auto` заполняет ширину карточками не уже `--sf-choice-min-inline-size`
(15rem, ступень f5). Число от 1 до 4 — самое большее столько колонок; если карточка
стала бы уже минимума, колонок меньше, и на телефоне карточки встают в
столбик сами.

## Состояния

- Выбранная карточка — отмеченный переключатель или флажок и рамка 2 px
  основного цвета на лёгкой заливке основным (`--sf-primary-container`:
  нижняя ступень семьи заливок, 12 в светлой теме, 24 в тёмной): два
  признака, а не только цвет. Текст остаётся обычного цвета.
- Под указателем — рамка темнее и лёгкая заливка, фокус с клавиатуры — общее
  кольцо фокуса вокруг всей карточки.
- `disabled` — ни одну карточку нельзя выбрать, поле не уходит с формой;
  `disabled` у варианта выключает только его карточку: бледный текст, бледная
  рамка, выключенный переключатель и метка, без наведения.
- `invalid` — невыбранные карточки получают рамку цвета ошибки, их
  переключатели — кольцо ошибки, под карточками — `error-message` вместо
  `hint`.

```html
<sf-input-choice label="Тип сайта" name="kind" required invalid
                 error-message="Выберите тип сайта." items='[...]'></sf-input-choice>
```

## Размеры

Карточка собрана по системам: поле одинаковое со всех сторон — `--sf-space-1`
(16 px на десктопе, 12 на телефоне и в плотном режиме), промежуток между
карточками — половина поля; скругление — `--sf-radius--surface`. Переключатель
или флажок — размер 1 классового `sf-radio`/`sf-checkbox`, ровно в строку
названия (24 px, в плотном режиме и на телефоне 20). Название — текст размера 1,
пояснение и срок — текст размера 1/2, цена в плитке — текст размера 2.
Плотность (`data-sf-density="compact"`) сдвигает всё вместе на ступень вниз.
Подпись над карточками и строка под ними — как у `sf-input`.

## Клавиатура и экранный диктор

Внутри — обычные переключатели и флажки браузера, поэтому клавиатура
привычная.

| Клавиша | Результат |
| --- | --- |
| `Tab` | Один вариант: переходит на выбранную карточку (или первую). Несколько: по каждой карточке |
| Стрелки | Один вариант: переходят к соседней карточке и выбирают её, с конца — на начало |
| `Пробел` | Выбирает карточку; при `multiple` — включает или выключает |

Группа названа `label` (или `aria-label` элемента) и описана подсказкой или
ошибкой. Каждая карточка названа своим названием и описана пояснением.

## События

`input`, затем `change` — когда человек выбрал вариант или снял флажок, по
одному на нажатие. `detail`: `value` (новое значение), `values` (список),
`item` (нажатый вариант), `checked` (выбран ли он теперь). Запись `value` из
кода, сброс и восстановление формы событий не дают.

## Настройка

| Переменная | Что меняет | По умолчанию |
| --- | --- | --- |
| `--sf-choice-gap` | Расстояние между карточками | половина `--sf-choice-padding` |
| `--sf-choice-min-inline-size` | Самая узкая карточка в сетке | `var(--sf-f5)` (15rem) |
| `--sf-choice-padding` | Внутренний отступ карточки | `var(--sf-space-1)` |
| `--sf-choice-radius` | Скругление карточки | `var(--sf-radius--surface)` |
| `--sf-choice-background-color` | Заливка карточки | `var(--sf-transparent)` |
| `--sf-choice-border-color` | Рамка карточки | `var(--sf-outline-variant)` |
| `--sf-choice-selected-background-color` | Заливка выбранной карточки | `var(--sf-primary-container)` |
| `--sf-choice-selected-border-color` | Рамка выбранной карточки | `var(--sf-primary)` |

Наведение, фокус, недоступность и ошибка рисуются своими цветами поверх
настроенных.
