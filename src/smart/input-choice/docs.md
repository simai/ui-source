# Выбор карточками

Поле формы, в котором человек выбирает один вариант или несколько из
карточек: у каждой название, пояснение, иконка и короткая метка. Подходит,
когда вариантов немного и их надо объяснить словами: тип сайта, тип страницы,
шаблон, тип поля, куда сохранять копии, тариф. Все варианты видны сразу,
карточки стоят сеткой и на телефоне встают в столбик.

```html
<sf-input-choice label="Тип сайта" name="kind" value="shop" hint="Тип можно сменить позже." items='[
  {"value": "site", "label": "Сайт", "caption": "Страницы, разделы и меню", "icon": "language"},
  {"value": "shop", "label": "Магазин", "caption": "Каталог, корзина и заказы", "icon": "storefront", "badge": "Pro"},
  {"value": "docs", "label": "Документация", "caption": "Статьи с поиском и оглавлением", "icon": "menu_book"}
]'></sf-input-choice>
```

## Варианты

`items` — список вариантов: свойством, JSON-островом
(`<script type="application/json" data-sf-settings>`) или атрибутом с JSON.

| Поле | Что это |
| --- | --- |
| `value` | Значение, которое уходит с формой. Обязательно; повтор пропускается. |
| `label` | Название на карточке (можно `title`). Без него — значение. |
| `caption` | Пояснение под названием. |
| `icon` | Иконка в квадрате перед названием (имя из шрифта иконок). |
| `badge` | Короткая метка рядом с названием («Pro», «Новое»). |
| `disabled` | Карточку нельзя выбрать. |

## Один или несколько

`multiple` • по умолчанию выключено

Без `multiple` выбирается один вариант: карточки — группа переключателей
(`radiogroup`). С `multiple` — несколько: каждая карточка — флажок.

```html
<sf-input-choice label="Куда сохранять копии" name="targets" multiple value="local,s3" items='[
  {"value": "local", "label": "Этот сервер", "caption": "Быстро, но пропадёт вместе с сервером"},
  {"value": "s3", "label": "Хранилище S3", "caption": "Отдельно от сервера"},
  {"value": "ftp", "label": "FTP", "caption": "Устаревший способ", "disabled": true}
]'></sf-input-choice>
```

## Значение

`value` — значение выбранного варианта; при `multiple` — значения через
запятую в порядке вариантов (`local,s3`). Атрибут `value` — то, к чему
возвращает сброс формы. Из кода можно записать строку или список
(`el.value = ['local', 's3']`) — событий при этом нет. Свойство `selected` —
выбранные значения списком.

С формой уходит одно поле `name` с выбранным значением, при `multiple` — по
полю на каждое значение. Ничего не выбрано — поле не уходит; с `required`
форма не отправится (`value-missing`).

## Сетка

`columns` • по умолчанию `auto`

`auto` заполняет ширину карточками не уже `--sf-choice-min-inline-size`
(15rem). Число от 1 до 4 — самое большее столько колонок; если карточка
стала бы уже минимума, колонок меньше, и на телефоне карточки встают в
столбик сами.

## Состояния

- Выбранная карточка — заполненная отметка (точка в кружке или галочка в
  квадрате) и плотная рамка основного цвета на лёгкой заливке: два признака,
  а не только цвет.
- Под указателем — лёгкая заливка, фокус с клавиатуры — общее кольцо фокуса
  вокруг карточки.
- `disabled` — ни одну карточку нельзя выбрать, поле не уходит с формой;
  `disabled` у варианта выключает только его карточку.
- `invalid` — невыбранные карточки получают рамку цвета ошибки, под ними —
  `error-message` вместо `hint`.

```html
<sf-input-choice label="Тип сайта" name="kind" required invalid
                 error-message="Выберите тип сайта." items='[...]'></sf-input-choice>
```

## Размеры

Карточка собрана по линейке: квадрат иконки — высота контрола размера 1
(40 px), название — текст размера 1, пояснение — текст размера 1/2, отметка —
иконка ступени 1/2. Подпись над карточками и строка под ними — как у
`sf-input`.

## Клавиатура и экранный диктор

Внутри — обычные переключатели и флажки браузера, поэтому клавиатура
привычная.

| Клавиша | Результат |
| --- | --- |
| `Tab` | Один вариант: переходит на выбранную карточку (или первую). Несколько: по каждой карточке |
| Стрелки | Один вариант: переходят к соседней карточке и выбирают её, с конца — на начало |
| `Пробел` | Выбирает карточку; при `multiple` — включает или выключает |

Группа названа `label` (или `aria-label` элемента) и описана подсказкой или
ошибкой. Каждая карточка названа своим названием и описана пояснением.

## События

`input`, затем `change` — когда человек выбрал вариант или снял флажок, по
одному на нажатие. `detail`: `value` (новое значение), `values` (список),
`item` (нажатый вариант), `checked` (выбран ли он теперь). Запись `value` из
кода, сброс и восстановление формы событий не дают.

## Настройка

| Переменная | Что меняет | По умолчанию |
| --- | --- | --- |
| `--sf-choice-gap` | Расстояние между карточками | `var(--sf-space-1/2)` |
| `--sf-choice-min-inline-size` | Самая узкая карточка в сетке | `15rem` |
| `--sf-choice-padding` | Внутренний отступ карточки | `var(--sf-space-1/2)` |
| `--sf-choice-radius` | Скругление карточки | `var(--sf-radius--ui)` |
| `--sf-choice-background-color` | Заливка карточки | `var(--sf-transparent)` |
| `--sf-choice-border-color` | Рамка карточки | `var(--sf-outline-variant)` |
| `--sf-choice-selected-background-color` | Заливка выбранной карточки | `var(--sf-primary-transparent-select)` |
| `--sf-choice-selected-border-color` | Рамка выбранной карточки | `var(--sf-primary)` |

Наведение, фокус, недоступность и ошибка рисуются своими цветами поверх
настроенных.
