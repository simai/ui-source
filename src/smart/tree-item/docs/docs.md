# Tree Item

`sf-tree-item` — узел внутри `sf-tree`. Родительский узел может раскрывать
дочернюю группу, лист — активировать ссылку или сообщать владельцу своё `value`.
Узел не используют отдельно как универсальную строку списка.

Индикатор вправо/вниз сообщает состояние ветви, а иконка папки или файла — тип
узла. `selected` обозначает выбор, `active` — текущий маршрут, `open` — только
раскрытие. Клавиатурный фокус управляется корневым Tree по roving-tabindex.
