# Smart Empty State

`<sf-empty-state>` — то, что список, панель или страница показывает, когда
показать нечего. Одна причина — один вид:

| `kind` | значок | заголовок и текст по умолчанию |
|---|---|---|
| `no-data` (по умолчанию) | inbox | «Записей пока нет» / «Они появятся здесь, когда их добавят» |
| `nothing-found` | search_off | «Ничего не найдено» / «Попробуйте изменить запрос или фильтры» |
| `no-access` | lock | «Нет доступа» / «Обратитесь к администратору» |
| `error` | error | «Не удалось загрузить» / «Попробуйте ещё раз» и кнопка «Повторить» |

`icon`, `heading` и `text` заменяют значения по умолчанию (прежнее имя
`title` читается до 2026-12-01). `heading-level`
(2–6, по умолчанию 3) задаёт уровень заголовка в структуре страницы, чтобы
состояние было видно в оглавлении для чтения с экрана. Вид заголовка от уровня
не зависит. Размер `size`:

- `1/2` — внутри таблицы или панели;
- `1` — по умолчанию;
- `2` — целая страница.

`layout="inline"` (или `size="1/3"`) — одна строка для списка внутри меню,
выпадающего списка или поиска: маленький значок, слова и не больше одного
действия-ссылки, без заголовка. Внутри `listbox` или `menu` ставьте его вне
элемента списка: он не пункт, стрелки его пропускают.

`live`: `auto` (по умолчанию) — «ничего не найдено» и ошибка объявляются
вежливо (`role="status"`), остальные молчат; `alert` — ошибка, которую
вызвал сам человек, например упавший поиск при наборе; `off` — объявляет
хост.

От размера зависят значок, роль заголовка, текст и промежутки.

Действия передаются в слот `actions` (любые `sf-button`) или свойством
`actions` — `[{id, text, appearance}]`. Кнопки из свойства рисуются в размере
компонента и сообщают `sf-empty-state-action {id}`. У `kind="error"` без своих
действий есть «Повторить» (`id: retry`).

«Ничего не найдено» и ошибка объявляются вежливо (`role="status"`), остальные
состояния — нет. Значок декоративный. Ширина — не больше 28rem (переменная
`--sf-empty-state-max-inline-size`). Ещё пять публичных переменных:
`--sf-empty-state-color`, `--sf-empty-state-text-color`, `--sf-empty-state-gap`,
`--sf-empty-state-padding-block`, `--sf-empty-state-actions-gap`.

```html
<sf-empty-state kind="nothing-found" size="1/2" heading-level="4"></sf-empty-state>
<sf-empty-state kind="error" id="failed"></sf-empty-state>
<script>
  failed.addEventListener('sf-empty-state-action', (event) => event.detail.id === 'retry' && reload());
</script>
```
