# Smart Empty State

`<sf-empty-state>` — то, что список, панель или страница показывает, когда
показать нечего. Одна причина — один вид:

| `kind` | значок | заголовок и текст по умолчанию |
|---|---|---|
| `no-data` (по умолчанию) | значок раздела (`icon`), без него inbox; серый | «Записей пока нет» / «Они появятся здесь, когда их добавят» |
| `first-use` | значок раздела, основной цвет | «Здесь пока пусто» / «Создайте первую запись — она появится здесь» и основная кнопка «Создать» (`id: create`) |
| `nothing-found` | search_off (по фильтрам — `icon="filter_alt_off"`) | «Ничего не найдено» / «Попробуйте изменить запрос или фильтры» |
| `no-access` | lock, цвет предупреждения | «Нет доступа» / «Обратитесь к администратору» |
| `error` | error, цвет ошибки | «Не удалось загрузить» / «Попробуйте ещё раз» и кнопка «Повторить» |
| `offline` | cloud_off, цвет предупреждения | «Нет связи» / «Проверьте подключение — повторим сами, когда сеть вернётся» и «Повторить» |
| `processing` | спиннер в том же круге | «Готовится» / «Это может занять несколько минут. Результат появится здесь — страницу можно закрыть» |

Значок говорит о предмете, цвет — только о проблеме (решение C120). Для
`no-data` и `first-use` передайте в `icon` значок раздела — тот же, что у него
в меню. Значок в сером круге — цвета пояснения (`on-surface-variant`).

`processing` — для работы, которая закончится без человека: расшифровка,
отчёт, превью. Не для загрузки на секунды — для неё `sf-skeleton`,
`sf-spinner` или полоса прогресса. Состояние объявляется вежливо один раз;
когда работа закончилась, хост заменяет его результатом или ошибкой.

`offline` сам повторяет, когда сеть вернулась: на событие окна `online` он
отправляет `sf-empty-state-action {id: 'retry', auto: true}`. Загружает хост,
у компонента своих запросов нет.

`icon`, `heading` и `text` заменяют значения по умолчанию (прежнее имя
`title` читается до 2026-12-01). `heading-level`
(2–6, по умолчанию 3) задаёт уровень заголовка в структуре страницы, чтобы
состояние было видно в оглавлении для чтения с экрана. Вид заголовка от уровня
не зависит. Размер `size`:

- `1/2` — внутри таблицы или панели;
- `1` — по умолчанию;
- `2` — целая страница.

`layout="inline"` (или `size="1/3"`) — одна строка для списка внутри меню,
выпадающего списка или поиска: маленький значок, слова и не больше одного
действия-ссылки, без заголовка. Внутри `listbox` или `menu` ставьте его вне
элемента списка: он не пункт, стрелки его пропускают.

`live`: `auto` (по умолчанию) — «ничего не найдено», ошибка, «нет связи» и
«готовится» объявляются вежливо (`role="status"`), остальные молчат; `alert` — ошибка, которую
вызвал сам человек, например упавший поиск при наборе; `off` — объявляет
хост.

От размера зависят значок, роль заголовка, текст и промежутки.

Действия передаются в слот `actions` (любые `sf-button`) или свойством
`actions` — `[{id, text, appearance}]`. Кнопки из свойства рисуются в размере
компонента и сообщают `sf-empty-state-action {id}`. У `kind="error"` и
`kind="offline"` без своих действий есть «Повторить» (`id: retry`), у
`kind="first-use"` — основная «Создать» (`id: create`).

Значок и спиннер декоративные. Ширина — не больше 28rem (переменная
`--sf-empty-state-max-inline-size`). Ещё пять публичных переменных:
`--sf-empty-state-color`, `--sf-empty-state-text-color`, `--sf-empty-state-gap`,
`--sf-empty-state-padding-block`, `--sf-empty-state-actions-gap`.

```html
<sf-empty-state kind="nothing-found" size="1/2" heading-level="4"></sf-empty-state>
<sf-empty-state kind="error" id="failed"></sf-empty-state>
<sf-empty-state kind="first-use" icon="mail" heading="Писем пока нет"></sf-empty-state>
<sf-empty-state kind="processing" heading="Расшифровка готовится"
  text="Пришлём письмо, когда она будет готова — страницу можно закрыть"></sf-empty-state>
<script>
  failed.addEventListener('sf-empty-state-action', (event) => event.detail.id === 'retry' && reload());
</script>
```
