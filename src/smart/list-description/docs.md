# sf-list-description

Список сведений: факты парами «подпись — значение». Сводка сайта, сведения о
сервере, шапка записи, параметры задания, данные лицензии. Вариант блока
`list` SIMAI Framework рядом с `sf-list-attention`: только показывает то, что
у страницы уже есть, ничего не загружает и не сохраняет. Править значения —
дело `sf-view-properties` (набор View, пакет Pro).

```html
<sf-list-description>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"label": "Адрес", "value": "demo-static.test", "href": "https://demo-static.test/"},
      {"label": "Корень сайта", "value": "/var/www/demo-static/public", "mono": true, "copy": true},
      {"label": "Сертификат", "value": "Действует до 12 декабря", "status": "success",
       "hint": "Let's Encrypt, продлевается сам"},
      {"label": "Владелец", "value": "", "action": {"label": "Указать", "event": "owner"}}
    ]}
  </script>
</sf-list-description>
```

## Карточка записи: разделы

Основной вид карточки записи (решение владельца C33): запись делится на
разделы, у каждого — заголовок и одно действие («Изменить»). Подписи всех
разделов стоят в одной колонке — по самой длинной подписи записи, не шире
40 %, — значения всех разделов начинаются с одной линии.

```html
<sf-list-description label="Заказ № 10482" dividers>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"type": "section", "id": "order", "label": "Заказ", "action": {"label": "Изменить", "event": "edit"}},
      {"label": "Номер", "value": "10482", "mono": true, "copy": true},
      {"label": "Статус", "badge": {"text": "Передан в доставку", "status": "info", "icon": "local_shipping"}},
      {"label": "Сумма", "value": "12 480 ₽", "numeric": true},
      {"type": "section", "id": "delivery", "label": "Доставка", "action": {"label": "Изменить", "event": "edit"}},
      {"label": "Способ", "value": "Курьер СДЭК", "help": "Срок и цену считает СДЭК."},
      {"label": "Дата доставки", "value": "", "empty": "Не назначена",
       "action": {"label": "Назначить", "event": "schedule"}}
    ]}
  </script>
</sf-list-description>
```

Раздел — элемент `{type: "section", label, id?, action?}`: `label` — его
заголовок (`role="heading"`, уровень `heading-level`, 3), строки раздела —
свой `dl` с именем раздела. Строки до первого раздела идут без заголовка.

Нажатие действия (раздела или строки) без `href` спрашивает
`sf-list-description-apply` `{action, scope: "entry", ids, id, kind}`:
`action` — `event` действия («edit», если он не задан), `id` — раздела или
строки, `kind` — `section` или `item`. Форму открывает страница и задаёт
список заново. Действие с `href` — ссылка, его нажатие спрашивает
`sf-list-description-navigate`.

## Сводка: `layout="grid"`

Сводка под заголовком записи: подпись над значением, столбцов столько,
сколько входит при ширине не меньше 11rem, но не больше `columns` (1–4, по
умолчанию 4). Значение — в одну строку с многоточием, целиком — во
всплывающей подсказке (и в карточке записи ниже на странице).

Подписи стоят в своей колонке — шириной по самой длинной подписи, но не шире
`--sf-list-description-label-width` (40 %), значения — рядом, все с одной
линии. В колонке уже 24rem (телефон, узкая боковая панель) подпись встаёт над
значением.

## Строка

Каждый элемент `items` — `{label, value, id?, hint?, mono?, numeric?, copy?, href?, status?, badge?, help?, empty?, action?}`:

- `label` — подпись; элемент без неё не показывается.
- `value` — значение, всегда текст, не разметка. Число пишется как есть
  (цифрами одной ширины), список — через запятую. Пустое значение (ни
  текста, ни бейджа) говорит словами: `empty` строки или `empty-text`
  («Не указан»), и тогда ни ссылки, ни кнопки копирования, ни значка
  состояния нет.
- `empty` — свои слова пустого значения, в роде подписи: «Не назначена».
- `numeric` — цифры одной ширины (`tabular-nums`): сумма, телефон, счётчик.
- `badge` — значение-бейдж `{text, status?, scheme?, icon?}`: `sf-badge` на
  линии значения (`line` — размер списка), строка остаётся высотой контрола.
- `help` — знак справки (`sf-help-mark`) через `--sf-space-1/4` после подписи с этим пояснением; его
  имя — «Подробнее: <подпись>».
- `action` — одно действие в строке `{label, event?, href?}`: кнопка
  ступенью меньше, без заливки, после значения; у пустого значения — «Указать».
  Имя для диктора — «<действие>: <подпись>».
- `mono` — моноширинный шрифт: путь, хеш, ключ.
- `copy` — кнопка копирования (`sf-button-copy`) после значения, видна
  всегда (не только при наведении); её имя для экранного диктора —
  «Скопировать: <подпись>».
- `href` — значение становится ссылкой. Нажатие сначала спрашивает
  `sf-list-description-navigate` `{id, href}`: страница с роутером отменяет
  событие и переходит сама; не отменённое — браузер идёт по ссылке. Нажатие
  с клавишей-модификатором или средней кнопкой открывает ссылку, ничего не
  спрашивая.
- `status` — `success`, `warning`, `error`, `info`: значок состояния перед
  значением, а слово состояния произносится перед ним для диктора. `neutral`
  или пусто — без значка; у пустого значения значка нет. У значения с
  бейджем значка тоже нет: бейдж — единственная метка.
- `hint` — строка пояснения под значением, ступенью меньше.

## Настройки

- `items` — строки, свойством или JSON-островом, который печатает сервер.
- `size` `1|1/2|2` — ступень линейки; `1/2` — для боковой панели.
- `layout` `auto|columns|stacked|grid` — `columns` всегда в две колонки,
  `stacked` всегда подпись над значением, `auto` — колонки, а в узкой колонке
  подпись над значением, `grid` — сводка столбцами.
- `columns` `1|2|3|4` — для `grid`: не больше стольких столбцов (4).
- `heading-level` — уровень заголовков разделов (3).
- `dividers` — тонкая линия между строками.
- `overflow` `wrap|truncate` — длинное значение переносится (`wrap`, по
  умолчанию; путь и хеш тоже переносятся, страницу не раздвигают) или
  обрезается многоточием в одну строку (`truncate`). Обрезанное значение
  целиком видно во всплывающей подсказке и, пока оно в фокусе (нажатие или
  Tab), разворачивается на месте.
- `empty-text` — что показывает пустое значение, «Не указан»; «—» —
  тоже допустимое значение (для чисел и таблиц).
- `label` — имя списка для диктора, если над ним нет заголовка.

Без строк список ничего не рисует (`data-empty`).

## Геометрия

Одна ступень S: подпись и значение — строка ступени L, пояснение и подпись
над значением — ступенью ниже, значок состояния — L, от значка до текста —
`text-space-x` ступени, между колонками — `space-x` ступени. Однострочная
строка — высота контрола ступени H (40 px при размере 1 на компьютере), как
у строки списка; линия-разделитель берёт свою толщину из отступа. Кнопка
копирования — ступенью ниже, по центру первой строки значения, высоту строки
не увеличивает; так же — действие строки. Заголовок раздела — строка высотой
контрола, следующий раздел — на `--sf-space-1` ниже. Бейдж — `sf-badge`
ступени 1/3 (1/2 при размере 2) на линии L. Плотность C22
(`data-sf-density="compact"`) опускает всё на ступень: строка 40 → 32.

## Публичные переменные

`--sf-list-description-label-color`, `--sf-list-description-value-color`,
`--sf-list-description-divider-color`, `--sf-list-description-label-width`
(предел колонки подписей, 40 %), `--sf-list-description-gap` (между
колонками), `--sf-list-description-padding-inline` (0: строки стоят по линии
текста страницы). SIMAI Framework сам их не задаёт.

## Доступность

Нативный `dl`: подпись — `dt`, значение — `dd`, диктор называет число пар и
связывает значение с подписью. С `label` список — группа с этим именем.
Состояние произносится словами, значок — только картинка. Фокус сам список не
берёт: Tab проходит в порядке чтения по действию раздела, знакам справки,
ссылкам, кнопкам копирования, действиям строк и обрезанным значениям.
Заголовок раздела — `role="heading"`, строки раздела — `dl` с его именем.
