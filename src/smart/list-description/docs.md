# sf-list-description

Список сведений: факты парами «подпись — значение». Сводка сайта, сведения о
сервере, шапка записи, параметры задания, данные лицензии. Вариант блока
`list` SIMAI Framework рядом с `sf-list-attention`: только показывает то, что
у страницы уже есть, ничего не загружает и не сохраняет. Править значения —
дело `sf-view-properties` (набор View, пакет Pro).

```html
<sf-list-description>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"label": "Адрес", "value": "demo-static.test", "href": "https://demo-static.test/"},
      {"label": "Корень сайта", "value": "/var/www/demo-static/public", "mono": true, "copy": true},
      {"label": "Сертификат", "value": "Действует до 12 декабря", "status": "success",
       "hint": "Let's Encrypt, продлевается сам"},
      {"label": "Владелец", "value": ""}
    ]}
  </script>
</sf-list-description>
```

Подписи стоят в своей колонке — шириной по самой длинной подписи, но не шире
`--sf-list-description-label-width` (40 %), значения — рядом, все с одной
линии. В колонке уже 24rem (телефон, узкая боковая панель) подпись встаёт над
значением.

## Строка

Каждый элемент `items` — `{label, value, id?, hint?, mono?, copy?, href?, status?}`:

- `label` — подпись; элемент без неё не показывается.
- `value` — значение, всегда текст, не разметка. Число пишется как есть,
  список — через запятую. Пустое значение показывает `empty-text` («—»), и
  тогда ни ссылки, ни кнопки копирования нет.
- `mono` — моноширинный шрифт: путь, хеш, ключ.
- `copy` — кнопка копирования (`sf-button-copy`) после значения; её имя для
  экранного диктора — «Скопировать: <подпись>».
- `href` — значение становится ссылкой. Нажатие сначала спрашивает
  `sf-list-description-navigate` `{id, href}`: страница с роутером отменяет
  событие и переходит сама; не отменённое — браузер идёт по ссылке. Нажатие
  с клавишей-модификатором или средней кнопкой открывает ссылку, ничего не
  спрашивая.
- `status` — `success`, `warning`, `error`, `info`: значок состояния перед
  значением, а слово состояния произносится перед ним для диктора. `neutral`
  или пусто — без значка.
- `hint` — строка пояснения под значением, ступенью меньше.

## Настройки

- `items` — строки, свойством или JSON-островом, который печатает сервер.
- `size` `1|1/2|2` — ступень линейки; `1/2` — для боковой панели.
- `layout` `auto|columns|stacked` — `columns` всегда в две колонки,
  `stacked` всегда подпись над значением, `auto` — колонки, а в узкой колонке
  подпись над значением.
- `dividers` — тонкая линия между строками.
- `overflow` `wrap|truncate` — длинное значение переносится (`wrap`, по
  умолчанию; путь и хеш тоже переносятся, страницу не раздвигают) или
  обрезается многоточием в одну строку (`truncate`). Обрезанное значение
  целиком видно во всплывающей подсказке и, пока оно в фокусе (нажатие или
  Tab), разворачивается на месте.
- `empty-text` — что показывает пустое значение, «—».
- `label` — имя списка для диктора, если над ним нет заголовка.

Без строк список ничего не рисует (`data-empty`).

## Геометрия

Одна ступень S: подпись и значение — строка ступени L, пояснение и подпись
над значением — ступенью ниже, значок состояния — L, от значка до текста —
`text-space-x` ступени, между колонками — `space-x` ступени. Однострочная
строка — высота контрола ступени H (40 px при размере 1 на компьютере), как
у строки списка; линия-разделитель берёт свою толщину из отступа. Кнопка
копирования — ступенью ниже, по центру первой строки значения, высоту строки
не увеличивает.

## Публичные переменные

`--sf-list-description-label-color`, `--sf-list-description-value-color`,
`--sf-list-description-divider-color`, `--sf-list-description-label-width`
(предел колонки подписей, 40 %), `--sf-list-description-gap` (между
колонками), `--sf-list-description-padding-inline` (0: строки стоят по линии
текста страницы). SIMAI Framework сам их не задаёт.

## Доступность

Нативный `dl`: подпись — `dt`, значение — `dd`, диктор называет число пар и
связывает значение с подписью. С `label` список — группа с этим именем.
Состояние произносится словами, значок — только картинка. Фокус сам список не
берёт: Tab проходит по ссылкам, кнопкам копирования и обрезанным значениям.
