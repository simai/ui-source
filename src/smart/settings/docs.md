# Smart Settings

`<sf-settings>` — компактные настройки: несколько настроек, которые человек
меняет на месте. Тема и размер текста у читалки, плотность таблицы, звук в
чате. Настройки задаются данными, значение каждой хранится в ней самой;
что значение значит — тёмная тема, плотная таблица, — применяет страница.

Компонент собран из `sf-menu-context` и ничего не рисует сам: строки,
переключатели, варианты, ползунки, плитки и клавиатура — это строки меню.
Для смешанного меню (меню профиля с выбором темы) строки со значением
по-прежнему задаются прямо в `sf-menu-context`.

```html
<sf-settings look="drill" label="Настройки чтения">
  <sf-button-icon icon="tune" appearance="link" scheme="on-surface" size="1/2" aria-label="Настройки чтения"></sf-button-icon>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"id": "theme", "type": "choice", "text": "Тема", "icon": "contrast", "value": "system", "options": [
        {"id": "system", "text": "Как в системе", "icon": "computer"},
        {"id": "light", "text": "Светлая", "icon": "light_mode"},
        {"id": "dark", "text": "Тёмная", "icon": "dark_mode"}]},
      {"id": "font", "type": "choice", "text": "Размер текста", "icon": "format_size", "value": "m", "options": [
        {"id": "s", "text": "Мелкий"}, {"id": "m", "text": "Обычный"}, {"id": "l", "text": "Крупный"}]},
      {"id": "sound", "type": "switch", "text": "Звук", "icon": "volume_up", "value": true}
    ]}
  </script>
</sf-settings>
<script>
  document.querySelector('sf-settings').addEventListener('sf-settings-changed', ({detail}) => {
    if (detail.id === 'theme') applyTheme(detail.value);
  });
</script>
```

## Настройки как данные

`items` — список. Его задают свойством (`settings.items = [...]`) или
JSON-островом `<script type="application/json" data-sf-settings>{"items": [...]}</script>`
внутри элемента — так его печатает сервер.

| `type` | Строка | `value` |
| --- | --- | --- |
| `switch` | Название и переключатель | `true` / `false` |
| `choice` | Название и варианты `options: [{id, text, icon?}]` | `id` выбранного варианта |
| `range` | Название и ползунок с числом; `min`, `max`, `step`, `unit` | число |
| `heading` | Заголовок раздела | — |
| `separator` | Разделитель | — |
| `group` | Блок настроек `items` под заголовком `text` | — |

У настройки есть `id` (по нему её называют события и методы), `text`,
необязательные `icon` и `caption` (вторая строка под названием) и
`disabled`. Недоступным можно сделать и отдельный вариант выбора.
`tile: true` у переключателя ставит его плиткой наверх в виде `tiles`.

Значение живёт в самой настройке, второго места, где оно могло бы
разойтись, нет. Свойство `values` отдаёт все значения картой:
`{theme: 'dark', font: 'm', sound: true}`.

## Три вида

Один атрибут `look` раскладывает те же данные по-разному.

- **`drill`** — переход внутрь (по умолчанию). Под названием мелко стоит
  текущее значение, в конце строки — стрелка. Нажатие открывает варианты в той
  же панели, с возвратом и галочкой у выбранного. Переключатель остаётся в
  своей строке. Подходит, когда вариантов много или они длинные: тема, язык,
  размер текста.
- **`rows`** — строки. Название в начале, управление в конце: короткие
  варианты подряд, переключатель, ползунок. Всё видно сразу, без перехода;
  подходит для вида таблицы или списка.
- **`tiles`** — плитки сверху. Самые частые переключатели стоят плитками по
  три в ряд, остальное — строками ниже, как быстрые настройки телефона.
  Плитками становятся переключатели с `tile: true`, а если таких нет —
  переключатели верхнего уровня.

## Всплывающая панель или в потоке

С кнопкой панель всплывает над страницей. Кнопка — это дети элемента без
атрибута `slot` (слот `trigger`) или элемент страницы, названный в `for`
(id или несколько через пробел):

```html
<sf-button-icon id="reader-settings" icon="tune" aria-label="Настройки чтения"></sf-button-icon>
<sf-settings for="reader-settings" look="drill">…</sf-settings>
```

Панель открывается под кнопкой, в верхнем слое страницы: её не обрезает
прокручиваемый блок. `Escape` и нажатие вне панели закрывают её, фокус
возвращается на кнопку. Кнопка получает `aria-haspopup="menu"` и
`aria-expanded`.

Без кнопки и без `for` панель стоит открытой в потоке страницы — в боковой
колонке или на странице настроек.

## Ширина и размер

Ширина панели постоянная, 280 px, во всех трёх видах — это ширина меню с
переходом внутрь. Длинное название переносится на вторую строку, длинное
значение обрезается многоточием, а целиком видно в подсказке. Ширину меняет
публичная переменная меню `--sf-context-menu-inline-size`.

`size` — ступень лестницы размеров меню: `1/2` (по умолчанию) даёт строки
32 px, `1` — строки 40 px.

## Изменение значения

Изменение, которое делает человек, сначала приходит запросом, а потом фактом:

| Событие | Когда |
| --- | --- |
| `sf-settings-change` | Человек просит изменить настройку; отменяемое, до записи. `{id, value, previous, item}` |
| `sf-settings-changed` | Значение записано в настройку, строка его показывает. `{id, value, previous, item}` |
| `sf-settings-reset` | Просят вернуть объявленные значения; отменяемое |

Страница применяет настройку по `sf-settings-changed`. Если значение нужно
сначала сохранить на сервере, отмените `sf-settings-change` и ответьте
`setValue`, когда сервер согласится:

```js
settings.addEventListener('sf-settings-change', async (event) => {
  event.preventDefault();
  const {id, value} = event.detail;
  if (await save(id, value)) settings.setValue(id, value);
});
```

События самого меню (`sf-menu-context-select`, `-change`, `-changed`,
`-reset`) наружу не выходят.

| Метод | Что делает | Ответ |
| --- | --- | --- |
| `setValue(id, value)` | Записывает значение в настройку; событий не поднимает | `applied`; `refused` с `not-found` (нет такой настройки) или `invalid` (значение ей не подходит) |
| `setAll(values)` | Записывает карту `{id: значение}` сразу — панель, восстановленная из хранилища; событий не поднимает | `{outcome: 'applied', count}`; `refused` с `not-found`, если ни один id не подошёл |
| `show(id)` | Открывает всплывающую панель, в виде `drill` — уровни до нужной настройки, и ставит на неё фокус | `applied`; `refused` с `not-found`; `unavailable` с `no-trigger`; `cancelled`, если открытие отменили |
| `reset()` | Спрашивает `sf-settings-reset`, возвращает объявленные значения и поднимает `sf-settings-changed` для каждой настройки, которая сдвинулась | `{outcome: 'applied', count}` или `cancelled` |

Объявленные значения — те, с которыми страница отдала `items`.

## Запомнить выбор

`remember="<имя>"` хранит значения как предпочтение человека:
`SF.Preferences`, ключ `sf-settings/<имя>`. Браузер держит их в
`localStorage` под `sf-pref:sf-settings/<имя>`, а хост, который хранит
предпочтения пользователя (`SF.Preferences.useHost`), получает их тоже.
Значения записываются после каждого изменения и возвращаются в настройки до
первой отрисовки, поэтому панель не показывает сначала одно, а потом другое.
Событий при этом нет: страница читает `values`, когда элемент определён.

```js
await customElements.whenDefined('sf-settings');
applyTheme(settings.values.theme);
```

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `↓` `↑`, `Home` `End` | Следующая, предыдущая, первая, последняя строка |
| `Enter`, `Space` | Переключает, выбирает вариант, открывает выбор в виде `drill` |
| `→` | Уходит на уровень вниз |
| `←`, `Escape` | Возвращает на уровень выше; на верхнем уровне `Escape` закрывает всплывающую панель |
| `←` `→` на ползунке | Меняют число на шаг |
| `Tab` | Уходит из панели и закрывает всплывающую |

Панель — меню, названное `label` («Настройки» / «Settings» по умолчанию).
Переключатель — `menuitemcheckbox`, варианты — `menuitemradio`, ползунок —
`slider`.

## Справка

| Атрибут | Тип | По умолчанию | |
|---|---|---|---|
| `items` | список (свойство, остров) | `[]` | Настройки. |
| `look` | `drill` `rows` `tiles` | `drill` | Вид. |
| `size` | `1/2` `1` | `1/2` | Ступень меню: строки 32 или 40 px. |
| `for` | строка | `""` | id кнопки на странице. |
| `remember` | строка | `""` | Имя, под которым хранить значения. |
| `label` | строка | «Настройки» / «Settings» | Доступное имя панели. |

Свойство `values` — карта значений, только для чтения; атрибут хоста
`data-look` — вид.

Своих CSS-переменных у компонента нет: он рисует через `sf-menu-context`,
публичные переменные меню доходят до панели.
