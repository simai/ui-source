# Smart Settings

`<sf-settings>` — компактные настройки: несколько настроек, которые человек
меняет на месте. Тема и размер текста у читалки, плотность таблицы, звук в
чате. Настройки задаются данными, значение каждой хранится в ней самой;
что значение значит — тёмная тема, плотная таблица, — применяет страница.

Компонент собран из `sf-menu-context` и ничего не рисует сам: строки,
переключатели, варианты, ползунки и клавиатура — это строки меню.

Где у продукта есть вход, личные настройки человека — тема, язык, размер
текста — стоят строками в меню человека (аватар), а не здесь: см.
«Меню человека» ниже (решение владельца C176). Шестерёнка с `sf-settings` —
для настроек экрана (вид таблицы, чтение) и для сайта без входа. В меню
действий «⋯» настроек нет.

```html
<sf-settings look="drill" label="Настройки чтения">
  <sf-button-icon icon="tune" appearance="ghost" scheme="on-surface" aria-label="Настройки чтения"></sf-button-icon>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"id": "theme", "type": "choice", "text": "Тема", "icon": "contrast", "value": "system", "options": [
        {"id": "system", "text": "Как в системе", "icon": "computer"},
        {"id": "light", "text": "Светлая", "icon": "light_mode"},
        {"id": "dark", "text": "Тёмная", "icon": "dark_mode"}]},
      {"id": "font", "type": "choice", "text": "Размер текста", "icon": "format_size", "value": "m", "options": [
        {"id": "s", "text": "Мелкий"}, {"id": "m", "text": "Обычный"}, {"id": "l", "text": "Крупный"}]},
      {"id": "sound", "type": "switch", "text": "Звук", "icon": "volume_up", "value": true}
    ]}
  </script>
</sf-settings>
<script>
  document.querySelector('sf-settings').addEventListener('sf-settings-changed', ({detail}) => {
    if (detail.id === 'theme') applyTheme(detail.value);
  });
</script>
```

## Настройки как данные

`items` — список. Его задают свойством (`settings.items = [...]`) или
JSON-островом `<script type="application/json" data-sf-settings>{"items": [...]}</script>`
внутри элемента — так его печатает сервер.

| `type` | Строка | `value` |
| --- | --- | --- |
| `switch` | Название и переключатель | `true` / `false` |
| `choice` | Название и варианты `options: [{id, text, icon?}]` | `id` выбранного варианта |
| `range` | Название и ползунок с числом; `min`, `max`, `step`, `unit` | число |
| `color` | Цвет: кружок текущего цвета; уровень палитры и «Свой цвет…» | имя оттенка (`blue`) или код `#rrggbb` |
| `heading` | Заголовок раздела | — |
| `separator` | Разделитель | — |
| `group` | Блок настроек `items` под заголовком `text` | — |

У настройки есть `id` (по нему её называют события и методы), `text`,
необязательные `icon` и `caption` (вторая строка под названием) и
`disabled`. Недоступным можно сделать и отдельный вариант выбора.

Значение живёт в самой настройке, второго места, где оно могло бы
разойтись, нет. Свойство `values` отдаёт все значения картой:
`{theme: 'dark', font: 'm', sound: true}`.

## Строка цвета

`color` — цвет рядом с темой, так же компактно, как «Настройки чтения»
(решение владельца C85). В строке — кружок текущего цвета и его название
под именем настройки; нажатие открывает уровень с оттенками палитры: кружок
и название каждого. Последняя строка — «Свой цвет…»: меню закрывается и
открывается окно `sf-input-color` сразу на «Своё», у той же кнопки.

```json
{"id": "accent", "type": "color", "text": "Цвет оформления", "icon": "palette", "value": "blue"}
```

Значение — как у `sf-input-color`: оттенок палитры по имени (`blue`,
одно на всех языках; на экране — переведённое название, в тёмной теме тон
подбирается сам) или код своего цвета `#rrggbb`. `options` — свой набор
оттенков (имена или `{id, text}`), по умолчанию десять: red, orange, amber,
green, teal, sky, blue, violet, pink, gray. `custom: false` убирает «Свой
цвет…». Строка цвета задумана для вида `drill`.

## Виды

Один атрибут `look` раскладывает те же данные по-разному.

- **`drill`** — переход внутрь (по умолчанию). Под названием мелко стоит
  текущее значение, в конце строки — стрелка. Нажатие открывает варианты в той
  же панели, с возвратом; выбранный вариант отмечен заливкой. Переключатель остаётся в
  своей строке. Подходит, когда вариантов много или они длинные: тема, язык,
  размер текста.
- **`rows`** — строки. Название в начале, управление в конце: короткие
  варианты подряд, переключатель, ползунок. Всё видно сразу, без перехода;
  подходит для вида таблицы или списка. Если варианты не помещаются рядом с
  названием (название не встаёт в одну строку или варианты не влезают),
  строка сама становится строкой «внутрь»: значение под названием, варианты
  уровнем глубже, как в `drill` (решение C176 (3)). Страница ничего для этого
  не задаёт: компонент меряет строки, когда меню нарисовано или открылось,
  до того как кадр показан.
- **`panel`** — панель настроек вида списка (решение C106): поля таблицы,
  их порядок, плотность, полосы. Это не меню действий, а своя панель — ниже.

Вида «плитки» больше нет (решение C176 (5)): `look="tiles"` — старое имя
`drill` до 2027-01-01, переключатели в нём — обычные строки, а `tile` у
настройки не читается. Страница, которая просит уведомления об устаревших
именах (`<html data-sf-deprecations="warn">`), один раз видит предупреждение
в консоли; список — `SF.deprecations.list()`.

После выбора варианта на уровне меню возвращается к списку: фокус на
изменённой строке, под её названием новое значение (C176 (4)). `Escape` на
уровне возвращает к списку, на верхнем уровне закрывает меню.

```html
<sf-settings look="rows" label="Настройки чтения">
  <script type="application/json" data-sf-settings>
    {"items": [
      {"id": "theme", "type": "choice", "text": "Тема", "icon": "contrast", "value": "system", "options": [
        {"id": "system", "text": "Как в системе", "icon": "computer"},
        {"id": "light", "text": "Светлая", "icon": "light_mode"},
        {"id": "dark", "text": "Тёмная", "icon": "dark_mode"}]},
      {"id": "font", "type": "choice", "text": "Размер текста", "icon": "format_size", "value": "m", "options": [
        {"id": "s", "text": "Мелкий"}, {"id": "m", "text": "Обычный"}, {"id": "l", "text": "Крупный"}]},
      {"id": "sound", "type": "switch", "text": "Звук", "icon": "volume_up", "value": true}
    ]}
  </script>
</sf-settings>
```

Здесь три значка темы помещаются рядом с названием, а три слова размера
текста — нет: «Размер текста» становится строкой со значением «Обычный» под
названием и стрелкой.

## Меню человека

Где есть вход, тема, язык и размер текста — строки меню человека (аватар):
обычный `sf-menu-context` с `submenu="drill"`, без нового компонента
(решение C176 (1), (2)). Одна настройка — одна строка выбора
(`type: "choice"`, `view: "drill"`): значение под названием, варианты уровнем
глубже, событие `sf-menu-context-changed` с `{id, value, previous}`. Язык —
строка из `sf-language` (`SfLanguage.menuEntry`, решение C142 (7)): родное
имя и второе название, поиск от восьми языков. Подменю из радиострок остаётся
для действий, не для настроек. «Выйти» — последним после черты, обычного
цвета, со значком выхода (C163 (6)); смена аккаунта и организаций — как в
рецепте `sf-profile-picker` (C163 (5)).

```html
<sf-button-icon id="me" icon="account_circle" appearance="ghost" scheme="on-surface" aria-label="Анна Смирнова"></sf-button-icon>
<sf-menu-context id="person" popup submenu="drill" size="1" aria-label="Меню человека"></sf-menu-context>
<script type="module">
  await customElements.whenDefined('sf-menu-context');
  const person = document.getElementById('person');
  const SfLanguage = await customElements.whenDefined('sf-language');
  person.entries = [
    {type: 'header', text: 'Анна Смирнова', caption: ['anna@example.ru']},
    {type: 'separator'},
    {id: 'profile', text: 'Профиль', icon: 'person', href: '/profile'},
    {type: 'separator'},
    {id: 'theme', type: 'choice', view: 'drill', text: 'Тема', icon: 'contrast', options: [
      {id: 'system', text: 'Как в системе', icon: 'computer', checked: true},
      {id: 'light', text: 'Светлая', icon: 'light_mode'},
      {id: 'dark', text: 'Тёмная', icon: 'dark_mode'}]},
    SfLanguage.menuEntry({languages: 'ru en', value: 'ru', label: 'Язык'}),
    {id: 'font', type: 'choice', view: 'drill', text: 'Размер текста', icon: 'format_size', options: [
      {id: 's', text: 'Мелкий'}, {id: 'm', text: 'Обычный', checked: true}, {id: 'l', text: 'Крупный'}]},
    {type: 'separator'},
    {id: 'logout', text: 'Выйти', icon: 'logout'},
  ];
  const me = document.getElementById('me');
  me.addEventListener('click', () => person.toggleFor(me.querySelector('button')));
  person.addEventListener('sf-menu-context-changed', ({detail}) => applySetting(detail.id, detail.value));
  person.addEventListener('sf-menu-context-select', ({detail}) => {
    const code = SfLanguage.codeOf(detail.id);
    if (code) setLanguage(code);
    else if (detail.id === 'logout') signOut();
  });
</script>
```

Строки те же, что у `sf-settings`: значение под названием, после выбора меню
возвращается к списку, фокус на изменённой строке. Строки языка — строки
`sf-language`: выбор приходит событием `sf-menu-context-select` с `id`
вида `language:en`, код читает `SfLanguage.codeOf(id)`; страница обычно
перезагружается на другом языке, поэтому меню после выбора закрывается.
Элемент `sf-language` должен быть загружен (он есть в шапке сайта или
подключён загрузчиком).

## Телефон

На телефоне (уже 44rem) всплывающее меню настроек и меню человека — одна
шторка снизу (решения C157 (5), (6)): ручка, строки на ступени касания
(строка со значением 60, обычная 44, C49), уровень «Тема» открывается в той же
шторке со стрелкой «Назад» в шапке; смахивание вниз закрывает. Меню в потоке
страницы остаётся в потоке.

## Только на телефоне или только на компьютере: `devices`

Любой пункт — настройка, группа, вариант списка полей или выбора — может
сказать, где он работает: `devices: ["desktop"]` или `devices: ["phone"]`
(исследование S-A). В другой раскладке пункт не показывается (скрыт, а не
выключен), его значение остаётся в `values`, сброс и `remember` его не
теряют. Выключенный пункт с причиной (`disabled` и `caption`) — для настройки,
которая там работает, но сейчас недоступна.

```js
settings.items = [
  {id: 'density', type: 'choice', text: 'Плотность', value: 'normal', options: […]},
  {id: 'nowrap', type: 'switch', text: 'Текст в одну строку', devices: ['desktop']},
  {id: 'grid', type: 'switch', text: 'Линии между столбцами', devices: ['desktop']},
];
```

Раскладка — слово ядра `SF.device`: `phone`, когда место элемента (ближайший
контейнер размеров, иначе страница) уже 600 px, иначе `desktop`; элемент
следит за ним, пока стоит на странице. Хост, который сам знает свою
раскладку, пишет её настройкой `device="phone"` или `device="desktop"`
(по умолчанию `auto`).

Компонент, который сам знает, какие его пункты бывают только в одной
раскладке, ставит свои метки через `SF.device.markDevices(items, {nowrap:
['desktop']})`: пункт, у которого автор уже написал `devices`, остаётся со
своими — метка автора главнее.

## Колонки на телефоне: `phoneSwitch`

Один список полей решает и компьютер, и телефон (S-A (2)): с
`phoneSwitch: true` у каждого поля в конце строки — свой переключатель «На
телефоне», над колонкой переключателей — её название. Флажок — поле на
компьютере, переключатель — на телефоне, порядок общий.

```js
{id: 'columns', type: 'fields', text: 'Колонки', sortable: true, phoneSwitch: true, options: [
  {id: 'title', text: 'Заказ', checked: true, phone: true, sortable: false, phoneSwitch: false},
  {id: 'client', text: 'Клиент', checked: true, phone: true},
  {id: 'status', text: 'Статус', checked: true, phone: false},
]}
```

- Значение списка тогда — `[{id, checked, pinned, phone}]`; нажатие на
  переключатель приходит теми же `sf-settings-change` и
  `sf-settings-changed`, что и флажок.
- Вариант с `phoneSwitch: false` (служебная колонка) — без переключателя,
  его место пустое.
- Переключатель называется «Клиент: на телефоне». С клавиатуры до него
  доходят стрелкой внутрь строки (после булавки), Пробел и Enter его
  переключают. Под пальцем его область — не меньше 44 px.

## Панель: `look="panel"`

Панель — для настроек вида списка, которые открываются по кнопке у таблицы
(шестерёнка) или стоят в потоке страницы. Новый компонент не нужен: это вид
`sf-settings`, и вкладки уходят из меню действий (`sf-menu-context tabs`
работает как прежнее имя до 2027-01-01).

```html
<sf-settings look="panel" size="1" search label="Настройки списка">
  <sf-button-icon icon="tune" appearance="outline" scheme="on-surface" aria-label="Настройки списка"></sf-button-icon>
  <script type="application/json" data-sf-settings>
    {"items": [
      {"type": "group", "text": "Поля", "items": [
        {"id": "columns", "type": "fields", "text": "Поля", "sortable": true, "pinnable": true, "options": [
          {"id": "name", "text": "Название", "checked": true, "pinned": true},
          {"id": "status", "text": "Статус", "checked": true},
          {"id": "due", "text": "Срок"}]}]},
      {"type": "group", "text": "Вид", "items": [
        {"id": "density", "type": "choice", "text": "Плотность", "value": "normal", "options": [
          {"id": "compact", "text": "Плотно"}, {"id": "normal", "text": "Обычно"}, {"id": "spacious", "text": "Свободно"}]},
        {"id": "stripes", "type": "switch", "text": "Полосы", "value": false}]}
    ]}
  </script>
</sf-settings>
```

- **Список полей** — настройка `type: "fields"`: много пунктов, которые
  отмечают. Значение — сами варианты: их порядок, `checked` и `pinned`;
  `values.columns` отдаёт `[{id, checked, pinned}]` по порядку, закреплённые
  первыми. Отмеченное поле — светлая заливка темы и галочка в конце строки,
  в одной колонке у края. Продукт больше не рисует свои строки
  (`sf-table-column-option`, `sf-table-settings-row`), а отдаёт список данными.
- **Порядок** — `sortable: true`: ручка в начале строки видна всегда,
  строку тянут за ручку или двигают Alt+↑/↓; позиция объявляется
  («Срок: 3 из 8»). `pinnable: true` — кнопка-булавка в строке
  (`sf-button-icon`: под указателем и при фокусе с клавиатуры показывает
  подсказку «Закрепить» или «Открепить», имя для экранного диктора —
  «Закрепить: Срок»; с клавиатуры до неё доходят стрелкой внутрь строки);
  закреплённые стоят сверху, ниже них поле не уходит.
- **Один вариант из нескольких** (`choice`) — только заливка, без флажков.
  Переключатель (`switch`) — строка с переключателем.
- **Выбор с порядком** — сохранённые шаблоны фильтра: `choice` с
  `sortable` и `pinnable`, у варианта `pinned`. Выбранный — заливка, ручка в
  начале строки, булавка в конце, закреплённые сверху; двигают так же, как
  поля. Значение — по-прежнему id выбранного варианта, а новый порядок
  приходит событиями `sf-settings-arrange` (отменяемое) и
  `sf-settings-arranged`: `{id, order: [{id, pinned}], previous, value, item}`.
- **Строка, которая не двигается** — у варианта `sortable: false` или
  `pinnable: false` (служебная колонка таблицы): ни ручки, ни булавки, их
  места пустые, текст стоит вровень с соседями; строка остаётся на своём
  месте, остальные двигаются вокруг неё.
- **Разделы или вкладки.** По умолчанию группы — разделы одной прокруткой.
  Вкладками они становятся, когда у панели есть поиск, а у группы — свой
  длинный список полей. Больше трёх групп — это уже `sf-drawer`, не панель.
- **Поиск** — настройка `search`, не по числу строк; ставьте её от десяти
  строк. Фильтрует строки без учёта регистра, «ё» как «е».
- **Применение** — `apply`. `instant` (по умолчанию) — сразу, как в других
  видах; в подвале одна «Сбросить». `button` — для фильтра: изменения ждут
  в панели, в подвале «Применить (N)» и «Сбросить» (главная первой, решение
  C157) через `--sf-space-1/3` (8, в компактной области 4), где N —
  отмеченные поля и включённые переключатели или число из `apply-count`,
  если условия считает страница; закрытие без «Применить» их отбрасывает.
  Кнопки подвала и крестик — размера панели (решение C22); в компактной
  области панель становится на одну ступень меньше: строки 32, текст 14.
  Подписи кнопок всегда в одну строку: каждая кнопка шире по своей подписи,
  а если рядом они не помещаются, вторая встаёт под первую во всю ширину.
- **Где стоит.** С кнопкой — окно над страницей (роль `dialog`): закрывается
  крестиком, Escape, нажатием снаружи и уходом Tab; на телефоне — шторка снизу.
  Без кнопки — в потоке страницы (роль `group`).
- **Свои слова** — `close-label`, `search-placeholder`, `empty-text`,
  `pin-label`, `unpin-label`, `move-label`; без них — слова языка страницы.
- **Клавиатура.** Каждый список — одна остановка Tab, стрелки внутри; в выборе
  одного стрелка сразу выбирает; Пробел и Enter отмечают; стрелка к концу
  строки — к булавке.
- **Размеры** — из систем: ширина — шаг панели (`--sf-popup-panel-width`,
  20rem, плотно 18rem), строка — высота контрола размера, подложка строки на
  `--sf-space-1/4` от края, текст на отступе полей и списков. Полоса
  прокрутки, когда занимает место, — отступ, бегунок, отступ (14), и справа
  от плашек тогда нет второго отступа.

## Всплывающая панель или в потоке

С кнопкой панель всплывает над страницей. Кнопка — это дети элемента без
атрибута `slot` (слот `trigger`) или элемент страницы, названный в `for`
(id или несколько через пробел):

```html
<sf-button-icon id="reader-settings" icon="tune" aria-label="Настройки чтения"></sf-button-icon>
<sf-settings for="reader-settings" look="drill">…</sf-settings>
```

Панель открывается под кнопкой, в верхнем слое страницы: её не обрезает
прокручиваемый блок. `Escape` и нажатие вне панели закрывают её, фокус
возвращается на кнопку. Кнопка получает `aria-haspopup="menu"` и
`aria-expanded`.

Без кнопки и без `for` панель стоит открытой в потоке страницы — в боковой
колонке или на странице настроек.

## Рамка входит в отступ

С 1.2.1 (решение владельца C105 H4) рамка панели `look="panel"` входит в её
отступ по горизонтали: шапка, поиск и тело стоят на `--sf-space-1/4` минус
рамка от её внутреннего края, и строки, заголовок и значок поиска на 1 px
ближе к внешнему краю (текст строки размера 1/2 — в 16 px, плотно и на
телефоне 12, а не 17 и 13). Ручка перетаскивания по-прежнему заходит в отступ
на свой шаг; промежутки по сторонам ползунка — весь отступ.

## Ширина и размер

Ширина панели постоянная в видах `drill` и `rows` — это ширина меню с
переходом внутрь: потолок ширины меню, 18rem (288 px), в компактной плотности
16rem (256 px); на телефоне — ширина шторки. Длинное название переносится на вторую строку, длинное
значение обрезается многоточием, а целиком видно в подсказке. Ширину меняет
публичная переменная меню `--sf-context-menu-inline-size`.

`size` — ступень лестницы размеров меню: `1` (по умолчанию с 1.4.0) даёт
строки 40 px и текст 16, `1/2` — строки 32 px и текст 14. Компактность
задаёт плотность области (`data-sf-density="compact"`), а не `size="1/2"`
(решение C22): сайты и документация — обычного размера, админки —
компактные.

## Изменение значения

Изменение, которое делает человек, сначала приходит запросом, а потом фактом:

| Событие | Когда |
| --- | --- |
| `sf-settings-change` | Человек просит изменить настройку; отменяемое, до записи. `{id, value, previous, item}` |
| `sf-settings-changed` | Значение записано в настройку, строка его показывает. `{id, value, previous, item}` |
| `sf-settings-reset` | Просят вернуть объявленные значения; отменяемое |
| `sf-settings-open` | Всплывающая панель `look="panel"` просит открыться; отменяемое, без данных |
| `sf-settings-opened` | Панель открыта и нарисована |
| `sf-settings-close` | Панель просит закрыться; отменяемое. `{reason, unsaved}`: `reason` — `escape`, `outside`, `close` (крестик или кнопка ещё раз), `api` («Применить», Tab наружу, скрипт); `unsaved` — в режиме `apply="button"` есть неприменённые изменения |
| `sf-settings-closed` | Панель закрыта. `{reason}` |
| `sf-settings-arrange` | Человек двигает или закрепляет вариант выбора с порядком; отменяемое, до записи. `{id, order, previous, value, item}` |
| `sf-settings-arranged` | Новый порядок записан в варианты. `{id, order, previous, value, item}` |

У видов `drill` и `rows` открытие и закрытие — события вложенного
`sf-menu-context` (`sf-menu-context-open`, `-opened`, `-close`, `-closed`) с
теми же данными.

Страница применяет настройку по `sf-settings-changed`. Если значение нужно
сначала сохранить на сервере, отмените `sf-settings-change` и ответьте
`setValue`, когда сервер согласится:

```js
settings.addEventListener('sf-settings-change', async (event) => {
  event.preventDefault();
  const {id, value} = event.detail;
  if (await save(id, value)) settings.setValue(id, value);
});
```

События самого меню (`sf-menu-context-select`, `-change`, `-changed`,
`-reset`) наружу не выходят.

| Метод | Что делает | Ответ |
| --- | --- | --- |
| `setValue(id, value)` | Записывает значение в настройку; событий не поднимает | `applied`; `refused` с `not-found` (нет такой настройки) или `invalid` (значение ей не подходит) |
| `setAll(values)` | Записывает карту `{id: значение}` сразу — панель, восстановленная из хранилища; событий не поднимает | `{outcome: 'applied', count}`; `refused` с `not-found`, если ни один id не подошёл |
| `show(id)` | Открывает всплывающую панель, в виде `drill` — уровни до нужной настройки, и ставит на неё фокус | `applied`; `refused` с `not-found`; `unavailable` с `no-trigger`; `cancelled`, если открытие отменили |
| `open({tab})` | Открывает всплывающую панель `look="panel"` у её кнопки, на вкладке с этим номером, если группы — вкладки; `tab` — какая вкладка сейчас | `applied`; `refused` с `not-popup`; `unavailable` с `no-trigger`; `cancelled` |
| `close()` | Закрывает открытую панель, как скрипт (`reason: api`) | `applied`; `refused` с `not-open`; `cancelled` |
| `reset()` | Спрашивает `sf-settings-reset`, возвращает объявленные значения и поднимает `sf-settings-changed` для каждой настройки, которая сдвинулась | `{outcome: 'applied', count}` или `cancelled` |

Объявленные значения — те, с которыми страница отдала `items`.

## Запомнить выбор

`remember="<имя>"` хранит значения как предпочтение человека:
`SF.Preferences`, ключ `sf-settings/<имя>`. Браузер держит их в
`localStorage` под `sf-pref:sf-settings/<имя>`, а хост, который хранит
предпочтения пользователя (`SF.Preferences.useHost`), получает их тоже.
Значения записываются после каждого изменения и возвращаются в настройки до
первой отрисовки, поэтому панель не показывает сначала одно, а потом другое.
Событий при этом нет: страница читает `values`, когда элемент определён.

```js
await customElements.whenDefined('sf-settings');
applyTheme(settings.values.theme);
```

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `↓` `↑`, `Home` `End` | Следующая, предыдущая, первая, последняя строка |
| `Enter`, `Space` | Переключает, выбирает вариант, открывает выбор в виде `drill` |
| `→` | Уходит на уровень вниз |
| `←`, `Escape` | Возвращает на уровень выше; на верхнем уровне `Escape` закрывает всплывающую панель |
| `←` `→` на ползунке | Меняют число на шаг |
| `Tab` | Уходит из панели и закрывает всплывающую |

Панель — меню, названное `label` («Настройки» / «Settings» по умолчанию).
Переключатель — `menuitemcheckbox`, варианты — `menuitemradio`, ползунок —
`slider`.

## Справка

| Атрибут | Тип | По умолчанию | |
|---|---|---|---|
| `items` | список (свойство, остров) | `[]` | Настройки. |
| `look` | `drill` `rows` `panel` | `drill` | Вид; `tiles` — старое имя `drill` до 2027-01-01. |
| `size` | `1/2` `1` | `1` | Ступень меню: строки 40 или 32 px. |
| `for` | строка | `""` | id кнопки на странице. |
| `remember` | строка | `""` | Имя, под которым хранить значения. |
| `label` | строка | «Настройки» / «Settings» | Доступное имя панели. |

Свойство `values` — карта значений, только для чтения; атрибут хоста
`data-look` — вид.

Своих CSS-переменных у компонента нет: он рисует через `sf-menu-context`,
публичные переменные меню доходят до панели.
