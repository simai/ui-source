# Smart Site Header

`<sf-header-site>` — верхняя полоса сайта SIMAI: бренд, разделы, ссылки и
инструменты в одну строку по ширине контейнера. На узком экране разделы и
ссылки уходят в боковую панель, которую открывает кнопка меню. Одна шапка для
всех сайтов SIMAI: каталога эффектов, сайтов документации на Docara и
портала simai.io.

Где какая шапка (решение C161 (1)): у сайта — эта полоса. В приложении с
левым меню (администрирование, SIMAI Pro, почта) верхней полосы нет: у
каждой страницы своя шапка страницы `sf-header-page` в рабочей области.

Шапка — рамка. Логотип, разделы, поиск, язык, тему и цвет передаёт сайт: это
его разметка в слотах, нарисованная компонентами SIMAI Framework.

```html
<sf-header-site>
  <a slot="brand" href="/"><svg …></svg><span>SIMAI</span></a>
  <nav aria-label="Разделы">
    <a href="/framework/">Framework</a>
    <a href="/docara/">Docara</a>
  </nav>
  <a slot="actions" href="https://github.com/simai">GitHub</a>
  <sf-segmented slot="tools" theme-switch size="1/2"></sf-segmented>
</sf-header-site>
```

## Слоты

| Слот | В широкой строке | На узком экране |
| --- | --- | --- |
| `brand` | в начале | остаётся в полосе |
| без имени (`nav`) | после бренда, занимает свободное место; с `navigation-align="center"` — по центру полосы | в панели, колонкой |
| `actions` | в конце, перед инструментами | в панели, под разделами |
| `tools` | в конце | поиск, профиль и прочие инструменты остаются в полосе; язык (`sf-language`) и тема (`theme-switch`) — в панели, в группе «Настройки» под разделами |
| `sheet` | не показан | в панели, последним |

Содержимое слотов — разметка страницы. Шапка ставит его на место один раз и
не копирует: в странице одна навигация, её обработчики и состояние
сохраняются. Навигация — `<nav aria-label>` страницы или
`<sf-menu orientation="horizontal" collapse="none">`; на узком экране шапка
переводит такое меню в колонку через его настройку `orientation`.

В `tools` кладут то, что нужно всегда: поиск, профиль, язык, тему
(`<sf-segmented theme-switch>`), цвет
(`<sf-input-color>`). На узком экране в полосе остаются кнопка меню, бренд,
поиск и профиль, а язык и тема переходят в панель — в группу «Настройки» под
разделами, каждая строкой «Язык» или «Тема» со своим переключателем
(решение C161 (8)). Это те же элементы страницы: шапка переставляет их, когда
полоса сворачивается или разворачивается, и не копирует. Менее важное — в
`actions`: на узком экране оно уйдёт в панель. Слот `sheet` — то, что бывает только в панели, например дерево
документации; сайт может заполнить его по событию `sf-header-site-opened`.

## Узкий экран

`collapse` — ступень ширины самой шапки, ниже которой полоса сворачивается:
`sm` (32rem), `md` (44rem), `lg` (60rem, по умолчанию), `xl` (72rem). `always`
— панель при любой ширине, `none` — никогда. Шапка считает свою ширину, а не
ширину окна (контейнерное условие, C181): в узкой колонке, карточке или рамке
примера при широком окне она сворачивается вместе со своим меню, и кнопка
«Меню» строки разделов не наезжает на язык и инструменты (C104). Отступы строки
от края до ступени `xl` тоже берутся по ширине шапки. Шапка во всю
ширину окна сворачивается там же, где раньше. Переход — правило в стилях
компонента, поэтому первая отрисовка верна и без скрипта; скрипт читает ответ
стилей и не может с ними разойтись.

Панель открывается поверх затемнения с той стороны, где стоит кнопка меню.
Она — слой общего стека слоёв Framework, как `sf-drawer` и `sf-modal`: Escape
и Tab получает только верхний слой, страница не прокручивается, пока панель
открыта. Открытая панель и затемнение — над всей строкой шапки. Кнопка
закрытия панели — `sf-button-close` размера полосы (решение C14); она стоит
на оси кнопки меню, и в широком окне с `collapse="always"` тоже.

На узком экране бренд уступает место инструментам: его слова обрезаются
многоточием, картинка сохраняет размер, а инструменты остаются целыми.

### Шапка сама решает, что уступить

`collapse="auto"` — шапка меряет свою строку при любой ширине и уступает в
одном порядке (решения C371, C372):

1. Сначала инструменты, которые умеют сжиматься: `sf-button shrink="icon"`
   (поиск «Поиск ⌘K») становится значком — квадратом высоты полосы, без
   подложки, с тем же именем, `aria-keyshortcuts` и подсказкой «Поиск ⌘K».
2. Потом разделы: `sf-menu` с `overflow="more"` переносит их с конца по
   одному в «Ещё»; текущий раздел остаётся в строке.
3. Последней — кнопка меню и боковая панель: только когда рядом с брендом и
   инструментами не помещается даже один раздел и «Ещё». Шапка
   разворачивается обратно, когда строка снова так широка.

Каждое изменение ширины шапка решает до отрисовки и за один шаг: при
перетаскивании края окна не видно ни наложений, ни промежуточных состояний.
До загрузки кода шапки (первая отрисовка до скрипта) `auto` рисуется как
`md`; с кодом шапка измеряет себя ещё до первой отрисовки. Хост сообщает состояние: `data-tools-compact` — инструменты
сжаты, `data-nav-overflow` — шапка свёрнута, `data-fitted` — шапка уже
измерила себя. Другие значения `collapse` инструменты не сжимают.

```html
<sf-header-site collapse="auto">
  <a slot="brand" href="/">SIMAI Framework</a>
  <sf-menu orientation="horizontal" appearance="navigation" overflow="more"
    current-from-location items='[…]'></sf-menu>
  <sf-button slot="tools" appearance="outline" scheme="on-surface" icon-start="search"
    text="Поиск" shortcut="mod+k" shrink="icon"></sf-button>
  <sf-language slot="tools" languages="ru en" trigger="icon"></sf-language>
  <sf-button-icon slot="tools" icon="settings" appearance="ghost" scheme="on-surface"
    aria-label="Настройки"></sf-button-icon>
</sf-header-site>
```

### Сторона кнопки меню

`menu-placement` — сторона кнопки меню и панели: `inline-start` (по умолчанию)
— кнопка первой в полосе, панель выезжает от начального края; `inline-end` —
кнопка последней, после инструментов (поиск, корзина), панель выезжает от
конечного края. Кнопка и панель всегда с одной стороны; на странице справа
налево обе отражаются.

```html
<sf-header-site collapse="md" menu-placement="inline-end">
  <a slot="brand" href="/">Технопром</a>
  <sf-menu orientation="horizontal" collapse="none" items='[…]'></sf-menu>
  <sf-button-icon slot="tools" icon="search" aria-label="Поиск"></sf-button-icon>
  <sf-button-icon slot="tools" icon="shopping_cart" aria-label="Корзина"></sf-button-icon>
</sf-header-site>
```

### Своя кнопка страницы

Панель открывает и кнопка самой страницы, как у `sf-drawer`:
`data-header-site="toggle"` (или `open`, `close`) и `aria-controls` с `id`
шапки. Шапка ставит такой кнопке `aria-expanded` и, пока она видна на
экране, не рисует свою кнопку меню; после закрытия фокус возвращается на неё.

```html
<sf-header-site id="site-header" collapse="md">
  <a slot="brand" href="/">Технопром</a>
  <sf-menu orientation="horizontal" collapse="none" items='[…]'></sf-menu>
  <sf-button slot="tools" icon-start="menu" text="Каталог"
    data-header-site="toggle" aria-controls="site-header"></sf-button>
</sf-header-site>
```

## Размер и место

- `size` — ступень элементов полосы: `1` (по умолчанию) или `1/2`. Высота
  полосы — высота элемента этой ступени, отступ `--sf-space-1` сверху и снизу
  и граница в 1px. Кнопкам в слотах сайт ставит тот же `size`.
- Отступы (стандарт C105): между группами строки — бренд, разделы, ссылки,
  инструменты — `--sf-space-1` (16, на телефоне 12); между соседями в
  `actions`, например ссылкой и кнопкой, — `--sf-space-1/3` (8, в плотном
  режиме 4).
- Первая отрисовка: пока у полосы нет кода и стилей, она уже занимает свою
  высоту (по `size` или `--sf-site-header-block-size`), содержимое слотов
  появляется вместе со стилями — страница под ней не прыгает.
- `sticky` — полоса остаётся вверху окна при прокрутке. По умолчанию выключено.
- `navigation-align` — `start` или `center`, см. «Навигация по центру».
- Боковые поля — поля `.container`: сайт задаёт `--sf-container-gutter` один
  раз для всей страницы, и полоса берёт их.
- Нижний край полосы: место навигации занимает всю высоту строки и сообщает
  переменной `--sf-site-header--edge`, насколько ниже его конца кончается
  нижняя граница полосы (отступ `--sf-space-1` и граница). По ней строка
  `sf-menu` кладёт линию текущего раздела прямо на границу полосы, как у
  вкладок (решение C30). Полоса без нижней линии
  (`--sf-site-header-border-color: transparent`) — меню с `indicator="fill"`.

## Навигация по центру

`navigation-align` — где стоят разделы в широкой полосе: `start` (по
умолчанию) — сразу после бренда, `center` — по центру полосы между брендом и
инструментами, как в шапке Docara. Пока обе стороны помещаются, разделы стоят
точно по центру полосы; если одна сторона шире, разделы сдвигаются, но не
заходят на бренд и инструменты. Со слотом `actions` разделы стоят по центру
места между брендом и ссылками. Это правило стилей, а не замер: первая
отрисовка уже по центру. На узком экране разделы, как и раньше, уходят в
панель. Одинаково при `size="1/2"` и `size="1"`.

Меню с `overflow="more"` по центру тоже работает: пока все разделы
помещаются, строка стоит по центру полосы; когда места не хватает, меню
занимает всё место между брендом и инструментами и уносит в «Ещё» только
те разделы, что не поместились, — так же, как при `start`. Ширину всей
строки меню сообщает само (`--sf-menu--row-size`); до первого замера
разделы занимают всё свободное место.

Вид разделов как в Docara даёт меню `appearance="navigation"`: без рамок,
текущая страница — серая плашка.

```html
<sf-header-site size="1/2" navigation-align="center">
  <a slot="brand" href="/"><svg …></svg><span>SIMAI Effects</span></a>
  <sf-menu orientation="horizontal" appearance="navigation" collapse="none" current-from-location>
    <nav aria-label="Разделы">
      <ul>
        <li><a href="https://simai.io/">simai.io</a></li>
        <li><a href="/">Галерея</a></li>
        <li><a href="/authors/">Авторам</a></li>
      </ul>
    </nav>
  </sf-menu>
  <sf-segmented slot="tools" theme-switch size="1/2"></sf-segmented>
</sf-header-site>
```

## Клавиатура и экранный диктор

Элемент рисует `<header>` — ориентир «баннер» страницы, если шапка стоит вне
`main`, `article`, `aside`, `nav` и `section`. Ориентир навигации — `<nav>`
страницы со своим `aria-label`; вторую обёртку шапка не добавляет. Кнопка
меню — `aria-haspopup="dialog"`, `aria-controls` и `aria-expanded`; открытая
панель — диалог, названный своим заголовком (`label`, по умолчанию «Меню»). Строки `sf-menu` в панели — высотой для касания: размер 2 лестницы, 44 px на телефоне.

| Клавиша | Результат |
| --- | --- |
| `Tab` | Бренд, разделы, ссылки и инструменты по порядку; в открытой панели — только по ней |
| `Enter` или `Пробел` на кнопке меню | Открывает панель; фокус — на ссылке текущей страницы, иначе на первой ссылке |
| `Escape` | Закрывает панель и возвращает фокус на кнопку меню |

Нажатие на затемнение, кнопка закрытия и выбор ссылки в панели тоже её
закрывают; панель закрывается и тогда, когда шапка стала шире `collapse`.

## Методы и события

| Метод | Что делает |
| --- | --- |
| `open()` | Открывает панель; отказ, если полоса не свёрнута или страница отменила `sf-header-site-open` |
| `close({reason})` | Закрывает панель |
| `toggle()` | Открывает или закрывает |

| Событие | Когда |
| --- | --- |
| `sf-header-site-open` | Панель вот-вот откроется; можно отменить |
| `sf-header-site-opened` | Панель открылась |
| `sf-header-site-close` | Панель вот-вот закроется, `detail.reason`: `close`, `escape`, `outside` или `api`; можно отменить |
| `sf-header-site-closed` | Панель закрылась, `detail.reason` |

Прежние имена `sf-site-header-*` приходят следом с теми же данными до 2027-01-01.

## Настройка

| Переменная | Что меняет |
| --- | --- |
| `--sf-site-header-background-color` | Фон полосы |
| `--sf-site-header-color` | Цвет текста полосы |
| `--sf-site-header-border-color` | Нижняя граница полосы и заголовка панели |
| `--sf-site-header-block-size` | Высота полосы |
| `--sf-site-header-gap` | Расстояние между группами строки |
| `--sf-site-header-tools-gap` | Шаг между инструментами; его же берёт выбор цвета между образцом и кнопкой сброса |
| `--sf-site-header-brand-size` | Высота картинки бренда |
| `--sf-site-header-sheet-inline-size` | Ширина открытой панели |
| `--sf-site-header-z-index` | Слой прилипшей полосы |

Сайты SIMAI не переопределяют значения Framework своими: переменные — для
уровней самого Framework (тема, область), а не для оформления отдельного
сайта.
