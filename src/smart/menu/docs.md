# Smart Menu

`<sf-menu>` — навигация по сайту, разделу или личному кабинету, собранная из
данных: вложенные разделы, текущая страница, группы, которые раскрываются и
сворачиваются. Элемент рисует разметку классового меню (`.sf-menu`), поэтому
выглядит и ведёт себя так же, как оно: те же строки, уровни, горизонтальная
строка с подменю, дерево документации и компактная колонка.

```html
<sf-menu label="Разделы" current-from-location items='[
  {"id": "about", "label": "О компании", "href": "/about/"},
  {"id": "catalog", "label": "Каталог", "children": [
    {"id": "solutions", "label": "Решения", "href": "/catalog/solutions/"},
    {"id": "products", "label": "Продукты", "href": "/catalog/products/", "badge": "3"}
  ]},
  {"id": "contacts", "label": "Контакты", "href": "/contacts/", "icon": "call"}
]'></sf-menu>
```

## Пункты

Пункты приходят в `items` — массивом в свойстве или тем же массивом как JSON
в атрибуте. У пункта:

| Поле | Что это |
| --- | --- |
| `id` | Имя пункта в `open(id)`, `close(id)`, `toggle(id)`, `current` и в событиях. Без него — место пункта: `item-1`, `item-1-2`… Повторный `id` пропускается вместе с вложенными пунктами. |
| `label` | Подпись. Это текст, а не разметка. |
| `href` | Адрес страницы. Пункт без адреса и без вложенных — просто подпись. |
| `icon` | Иконка перед подписью (имя из шрифта иконок). |
| `badge` | Счётчик после подписи: число — счётчик классового меню (больше 99 — `99+`, `0` скрыт, фраза счётчика завершает имя ссылки), другой текст — короткая метка. |
| `count` | То же число, что `badge`, под своим именем. |
| `status` | Цветная точка в конце строки, перед счётчиком: `success`, `warning`, `error`, `info` или `neutral`. Слово точки («внимание») завершает имя ссылки для экранного диктора. |
| `current` | Пункт — текущая страница. |
| `disabled` | Пункт недоступен: ссылка без адреса, ветка не раскрывается. Недоступную страницу лучше убрать из навигации. |
| `open` | Ветка открыта сначала (в колонке). |
| `children` | Вложенные пункты: пункт с ними — ветка. |
| `group` | Пункт первого уровня — группа: заголовок над своими пунктами (см. «Группы разделов»). |
| `collapsible` | Группу можно свернуть и развернуть. |
| `items` | Пункты группы — то же, что `children`. |

Меню можно написать и прямо в разметке — вложенным списком ссылок. Без
скрипта он остаётся рабочим списком; со скриптом элемент читает его один раз
как данные: `<li>` — пункт, его `<a>` — ссылка (`href`, `aria-current`,
подпись — слова ссылки), вложенный `<ul>` — подпункты. `data-id` (или `id`),
`data-icon`, `data-badge`, `data-status`, `data-open` и `data-disabled` на
`<li>` — как поля выше; `data-group` делает `<li>` группой, `data-collapsible`
— сворачиваемой, `data-open="false"` — свёрнутой сначала. Ветка без своей страницы — слова прямо в `<li>` перед вложенным
списком. `aria-label` у `<nav>` вокруг списка становится подписью меню. Если
задан `items`, список из разметки не используется.

```html
<sf-menu>
  <nav aria-label="Разделы">
    <ul>
      <li><a href="/about/">О компании</a></li>
      <li data-id="catalog">Каталог
        <ul>
          <li><a href="/catalog/solutions/">Решения</a></li>
        </ul>
      </li>
    </ul>
  </nav>
</sf-menu>
```

## Колонка и строка

- `orientation="vertical"` (по умолчанию) — колонка для боковой панели:
  ветка — группа, которая раскрывается на месте, под своей строкой. Ветки над
  текущей страницей открыты сразу, чтобы её было видно.
- `orientation="horizontal"` — строка для шапки: первый уровень в строку,
  ветка открывает панель — первая вниз, следующие в сторону; панель
  размещается общей геометрией Framework (`SF.Position`) и у края экрана
  переходит на свободную сторону. Открытие ветки закрывает соседнюю, щелчок
  вне меню и уход фокуса из меню закрывают панели, переход по ссылке — тоже.
- `appearance` — `default`, `documentation-tree` (дерево документации:
  без рамок, отступ по уровню, текущий пункт — плашка основного цвета, как у
  `navigation`), `rail` (узкая
  колонка разделов первого уровня: видна иконка, слова — в имени ссылки,
  счётчик — на иконке; ветки не раскрываются) или `navigation` (разделы
  сайта в шапке, см. ниже). Дерево и узкая колонка — всегда колонка;
  `navigation`, как и `default`, — строка или колонка по `orientation`.
  Прежнее значение `appearance="compact"` — псевдоним `rail` до 2027-01-01
  (запись в `SF.deprecations`): слово «compact» теперь означает только
  плотность (`data-sf-density`, решение C134).

## Навигация в шапке

`appearance="navigation"` — разделы сайта так, как их рисует шапка Docara:
у пункта нет рамки и заливки, под указателем появляется лёгкая заливка
состояния, текущая страница — плашка основного цвета. Высота, отступы, шрифт и
скругление — обычной строки меню: высота контрола размера 1 (40 px на
десктопе), `space-1` по бокам, текст размера 1, скругление `--sf-radius--ui`.
Фокус — общее кольцо фокуса.

| Состояние | Заливка |
| --- | --- |
| покой | прозрачная |
| наведение | `--sf-surface-transparent-hover` (4 %) |
| нажатие | `--sf-surface-transparent-active` (12 %) |
| открытая ветка | прозрачная — что ветка открыта, видно по её списку |
| текущая страница | `--sf-primary-container-active` (основной цвет: 20 % в светлой теме, 32 % в тёмной) |

Текущая страница (решение C23): плашка основного цвета из семьи заливок
шкалы прозрачности, слова и иконка — `--sf-on-primary-container`, подпись —
средней насыщенности (второй признак, кроме цвета), без полоски. Плашка
под указателем не меняется.

Путь к текущей странице (решение C30, дополнено 2026-11-09: R065, R072,
R084) отмечен одним знаком. У закрытой ветки колонки, внутри которой лежит
текущая страница, и у каждой строки пути в панелях строки сайта — подпись
средней насыщенности. Если у коробки, где стоит строка, есть своя рамка, —
у панелей строки она есть всегда, у колонки — с `bordered`, — на этой рамке
у строки лежит линия 2 px основного цвета: она закрывает пиксель рамки и
заходит внутрь на второй, высотой во всю строку, внутренние углы скруглены,
у первой и последней строки не заходит на скругление угла. Если коробка
прокручивается, линия стоит на пиксель внутри: область рамки обрезается.
Стрелка › остаётся нейтральной и значит только «есть подразделы». Узкая
колонка `rail` отмечает раздел, внутри которого текущая страница, той же
линией 2 px на своём левом крае, высотой во всю строку: у строки там одна
иконка, и насыщенность подписи не видна (полоска 3 × 16 снята). Строке пути,
у которой список не нарисован, меню ставит класс
`sf-menu-element--holds-current`. В режиме принудительных цветов текущая
страница обводится рамкой цвета текста, линия рисуется цветом выделения
системы.
Ветки, панели строки, кнопка «Меню» и клавиатура — те же, что у `default`.

```html
<sf-header-site navigation-align="center">
  <a slot="brand" href="/">SIMAI</a>
  <sf-menu orientation="horizontal" appearance="navigation" collapse="none" current-from-location>
    <nav aria-label="Разделы">
      <ul>
        <li><a href="/">Главная</a></li>
        <li><a href="/start/">Быстрый старт</a></li>
        <li><a href="/components/">Компоненты</a></li>
      </ul>
    </nav>
  </sf-menu>
</sf-header-site>
```

Та же навигация в боковой панели — колонкой:

```html
<sf-menu appearance="navigation" label="Разделы" current-from-location items='[
  {"id": "home", "label": "Главная", "href": "/"},
  {"id": "start", "label": "Быстрый старт", "href": "/start/"}
]'></sf-menu>
```

Меню различает четыре уровня, пятый и глубже рисуются как четвёртый
(решение C30; прежний предел в два уровня, C24, снят). В колонке каждый
следующий уровень сдвинут на один шаг `space-1`.

Колонка `navigation` (решения C05, C07, R083): плашка строки отступает от
края колонки на `space-1/4` с обеих сторон, слова — на `space-1/2` от края
плашки. Если колонка прокручивается и полоса прокрутки занимает место, правый
отступ отдаёт полосе её собственный зазор: от плашки до ползунка столько же,
сколько от края колонки до плашки слева. Это только когда прокручивается
собственный список меню (у меню есть высота, например с `search`). Если
прокручивается не меню — оно `sticky` и прокручивается целиком, или колонка
стоит в прокручиваемой области страницы, — правый отступ остаётся полным
`space-1/4`, а полоса прокрутки стоит за ним.

`bordered` рисует колонке свою рамку — тонкую линию `outline-variant`
со скруглением поверхности — и отступ `space-1/4` от неё со всех сторон; путь
к текущей странице тогда отмечен и линией 2 px на левой рамке (R072).
С `search` рамка обходит всё меню — поле вместе со строками, — и тонкой линии
под полем тогда нет: одна рамка, без второй верхней линии. Строки под полем
прокручиваются, поэтому линия пути стоит сразу внутри рамки, как в любой
прокручиваемой коробке.

```html
<sf-menu appearance="navigation" bordered label="Каталог" current="centrifugal" items='[
  {"id": "pumps", "label": "Насосное оборудование", "children": [
    {"id": "centrifugal", "label": "Центробежные насосы", "href": "/catalog/pumps/centrifugal/"}
  ]},
  {"id": "valves", "label": "Арматура", "href": "/catalog/valves/"}
]'></sf-menu>
```

## Поиск

`search` ставит над колонкой поле поиска (решение C30, R071): сам по себе
поиск не появляется ни при каком числе пунктов, отдельного «меню админки» нет.
Поле — `sf-input` (заливка, скругление), его лупа стоит над иконками строк
(C06); слова в поле и его имя — `search-placeholder`, по умолчанию «Поиск».
Поле стоит на месте, прокручиваются только строки, если у меню есть высота
(например, `style="block-size: 100%"` в боковой панели).

Пока в поле есть слова, меню показывает только подходящие пункты: без учёта
регистра, «ё» как «е», по словам пунктов и заголовкам групп. Найденный
пункт оставляет своих родителей, и они раскрыты; найденный раздел остаётся со
всеми подразделами, свёрнутым, если среди них нет найденного; найденный
заголовок группы оставляет всю группу. Найденные слова подсвечены цветом
пометки (`--sf-mark`) через `::highlight(sf-menu-match)` — разметка строк не
меняется. Сколько найдено, говорит вежливая живая область («Найдено: 2»);
если ничего — «Ничего не найдено».

Клавиши: `↓` из поля — к первому найденному, `↓`/`↑` — по найденным, `↑` с
первого — обратно в поле; `Esc` в поле очищает его, в найденном — возвращает
в поле. Событие `sf-menu-search` — `detail: {query, count}` при каждой смене
слов.

Пункт со ссылкой наружу — `target` (`_blank` — новая вкладка, ссылке
ставится `rel="noopener"`, а к её имени добавляется «откроется в новой
вкладке») или `external: true` — рисует ↗ в конце строки.

```html
<sf-menu appearance="navigation" search label="Настройки" style="block-size: 24rem" items='[
  {"id": "general", "label": "Общие", "group": true, "items": [
    {"id": "profile", "label": "Профиль", "href": "#profile", "icon": "person"},
    {"id": "password", "label": "Пароль", "href": "#password", "icon": "key"}
  ]},
  {"id": "help", "label": "Справка", "group": true, "items": [
    {"id": "docs", "label": "Документация", "href": "https://ui.simai.io/", "icon": "menu_book", "target": "_blank"}
  ]}
]'></sf-menu>
```

## Четыре вида простого меню

Один тег `sf-menu` — четыре вида (решение C30):

| Вид | Как задать | Что видно |
| --- | --- | --- |
| Строка сайта | `orientation="horizontal" appearance="navigation"` | Первый уровень в строку; второй — панель под разделом; третий и четвёртый — сбоку, у края экрана — на свободную сторону |
| Колонка сайта | `appearance="navigation"` | До четырёх уровней, текущая страница — плашка C23, открытые ветки без заливки, закрытая ветка с текущей страницей — подпись средней насыщенности; с `bordered` — ещё и линия 2 px на левой рамке |
| Простая админка | колонка `appearance="navigation"` внутри `data-sf-density="compact"`, иконки у первого уровня | Два уровня, слова второго уровня стоят под словами первого |
| Телефон | строка внутри `sf-header-site` | В выдвижной панели шапки «Меню» — то же дерево колонкой, строки высотой для касания (размер 2, 44 px на телефоне), путь к текущей странице открыт; без перехода «внутрь» |

### Строка сайта

Раздел, у которого есть своя страница и подразделы, — составной контрол
(шаблон APG «навигация с раскрытием и ссылками первого уровня»): название —
ссылка на страницу раздела, рядом — кнопка-стрелка, которая открывает панель;
её имя — «Каталог: подразделы». В панелях так же: строка с подразделами —
ссылка и кнопка ›. Строки «Весь каталог» нет: страница раздела — его название.
Раздел без своей страницы (без `href`) — одна кнопка.

| Состояние раздела в строке | Как выглядит |
| --- | --- |
| текущий (сам или внутри него текущая страница) | `indicator="line"` (по умолчанию): линия 2 px основного цвета под всем контролом **на нижней границе шапки** — она занимает место этого куска границы, как у вкладок, — и средняя насыщенность подписи; `indicator="fill"`: плашка C23 — для шапки без нижней линии (поверх фото, прозрачной) |
| открыт | нейтральная плашка выбора (`--sf-surface-transparent-select`) и стрелка ⌃ — никогда не основной цвет |

Линию кладёт на границу `sf-header-site`: он сообщает, где его нижний край
(`--sf-site-header--edge`). Вне шапки линия лежит у нижнего края строки.
Панель первого уровня и панель «Ещё» открываются на зазор ниже этого края,
а не ниже раздела: линия текущего раздела и граница шапки остаются видны.

Сам вид шапку не угадывает: у шапки без нижней линии (прозрачной, поверх
фото) линия по умолчанию тоже рисуется — на том месте, где была бы граница.
Для такой шапки автор ставит `indicator="fill"`.

В панелях путь к текущей странице: у строки, внутри которой лежит текущая
страница, — средняя насыщенность и линия 2 px основного цвета на левой
рамке панели (R084); стрелка › нейтральная. Открытая строка пути сохраняет
обе приметы на нейтральной плашке выбора.
Стрелка подраздела всегда ›, она не поворачивается. Сторону боковых панелей
выбирает первый боковой уровень — ту, где помещается вся цепочка под ним;
уровни глубже идут в ту же сторону и не открываются поверх своей цепочки.
Уже точки `md` (телефон) боковых панелей нет: третий и четвёртый уровни
раскрываются на месте внутри панели второго уровня, как в колонке, — со
ступенью отступа на уровень и линией пути на рамке этой панели (R179).

## Не помещается в строку

`overflow` решает, что делает строка, когда пункты не помещаются:

- `collapse` (по умолчанию) — шире точки `md` пункты, которые помещаются,
  остаются, остальные уходят в «Ещё», как при `more` (C30); уже `md`
  (телефон) вся строка становится кнопкой «Меню» (см. «Узкий экран»);
- `more` — пункты, которые не помещаются, уходят в последний пункт «Ещё»
  (`more-label`); раздел с текущей страницей остаётся в строке; если не
  помещается ни один пункт, «Ещё» называется «Меню» (`toggle-label`);
- `none` — строка не сворачивается.

Какие пункты ушли в «Ещё», говорит свойство `overflowHidden` (список `id`) и
событие `sf-menu-overflow` с `detail: {hidden}`. Пункт «Ещё» — ветка с `id`
`@more`: `open('@more')` открывает её.

```html
<sf-menu orientation="horizontal" appearance="navigation" overflow="more"
         more-label="Ещё" current-from-location>…</sf-menu>
```

## Широкая панель раздела

У пункта первого уровня строки может быть широкая панель на всю ширину шапки
(`region`, в разметке — `data-region`). Её содержимое — шаблон
`<template slot="region-<имя>">` внутри меню; без шаблона меню само рисует
подпункты колонками: заголовок колонки — пункт второго уровня, под ним —
его подпункты мелким текстом; подпункты без своих подпунктов — строкой
внизу. Ссылки на сам раздел в области нет: она — название раздела в строке.

```html
<sf-menu orientation="horizontal" appearance="navigation">
  <template slot="region-catalog">…своя разметка…</template>
  <nav aria-label="Разделы"><ul>
    <li data-region="catalog"><a href="/catalog/">Каталог</a><ul>…</ul></li>
  </ul></nav>
</sf-menu>
```

## Открытие наведением

`open-on="hover"` (по умолчанию) — мышью панель открывается и наведением:
через 300 мс, широкая область — через 500 мс; закрывается через 500 мс после
того, как мышь ушла с раздела и его панели. `open-on="click"` — только
нажатием на стрелку. Касание, перо и клавиатура всегда идут через стрелку:
касание названия открывает страницу раздела, касание стрелки — панель.

## Группы разделов

Навигация по разделам карточки — сайта, записи, настроек — это колонка
разделов, собранных в группы с заголовками. Пункт первого уровня с
`group: true` — группа: заголовок и её пункты (`items` или `children`). Пункты
группы — обычные строки первого уровня, без отступа; слова заголовка стоят на
той же оси, что слова строк. В колонке `navigation` заголовок — размер и
начертание пунктов, цвет `on-surface-variant`, высота строки (R070); в
остальных видах — на полступени ниже строки: высота контрола ступени 1/2,
текст размера 1/2. Между группами — `space-1/2`.

Группа открыта, если не сказано `open: false`. Группа с `collapsible: true`
сворачивается: её заголовок — кнопка с `aria-expanded`, `Enter` и `Пробел`
сворачивают и разворачивают её, событие — `sf-menu-toggle` с `id` группы.
Группу без `collapsible` свернуть нельзя: `toggle(id)` ответит
`{outcome: 'refused', reason: 'fixed'}`. Группа с текущим разделом
открывается сама.

У пункта может быть счётчик (`count`) и точка состояния (`status`) — например,
«Адрес» с предупреждением и «Журнал» с тремя новыми записями.

```html
<sf-menu label="Разделы сайта" appearance="navigation" sticky collapse="narrow"
         current-from-location items='[
  {"id": "site", "label": "Сайт", "group": true, "items": [
    {"id": "address", "label": "Адрес", "href": "#address", "icon": "language", "status": "warning"},
    {"id": "code", "label": "Код", "href": "#code", "icon": "code"},
    {"id": "data", "label": "Данные", "href": "#data", "icon": "database", "count": 12}
  ]},
  {"id": "watch", "label": "Наблюдение", "group": true, "collapsible": true, "items": [
    {"id": "health", "label": "Состояние", "href": "#health", "icon": "monitor_heart", "status": "success"},
    {"id": "journal", "label": "Журнал", "href": "#journal", "icon": "history", "count": 3}
  ]}
]'></sf-menu>
```

Разделы бывают отдельными страницами (`href="/sites/12/address/"`) и
панелями одной страницы (`href="#address"`). С `current-from-location`
ссылка на раздел страницы текущая, пока адрес страницы заканчивается этим
`#address`; меню следит за `hashchange`. Если панели переключает само
приложение, оно отменяет `sf-menu-navigate` и задаёт `current`.

`sticky` оставляет меню на виду, пока страница прокручивается; если меню выше
окна, оно прокручивается само. Отступ сверху — переменная
`--sf-menu-sticky-top` (например, высота шапки).

В строке (`orientation="horizontal"`) и в компактной колонке групп нет: их
пункты стоят на месте группы, без заголовка.

## Узкий экран

Строка не переносится на вторую строку. Шире точки `md` то, что не
помещается, уходит в «Ещё» (см. «Не помещается в строку»). Если на телефоне
(уже `md`) строка не помещается в отведённую ширину, меню становится кнопкой
«Меню», которая открывает те же пункты колонкой под собой
(`collapse="auto"`, по умолчанию); строкой меню возвращается, когда ширины
снова хватает. `collapse="always"` — кнопка всегда
(и для колонки), `collapse="none"` — никогда. Подпись кнопки — `toggle-label`,
по умолчанию «Меню» на языке страницы.

`collapse="narrow"` — кнопка только на узком экране (уже точки `md`, 704 px,
то есть на телефоне), и тогда это выбор раздела: на кнопке иконка и название
текущего раздела, имя кнопки — «Разделы сайта: Адрес». Нажатие открывает
все разделы колонкой под кнопкой, выбор раздела её закрывает. На широком
экране — обычная колонка.

Строка, которая на телефоне остаётся строкой (`sf-header-site collapse="none"`
или своё `overflow="more"` без шапки), не выносит уровни за край экрана:
второй уровень — панель под разделом, третий и четвёртый раскрываются на
месте внутри неё. Обычный путь для телефона — строка внутри `sf-header-site`:
шапка сама превращает её в дерево в выдвижной панели.

У составного контрола (раздел со своей страницей и подразделами) ссылка
занимает всю высоту строки, а при касании (`pointer: coarse`) кнопка-стрелка
колонки — квадрат высотой в строку: в панели шапки на телефоне 44 × 44.
В дереве документации (`appearance="documentation-tree"`) такая строка той же
высоты, что и остальные: 40, в компактной плотности 32, на телефоне 36.

## Текущая страница

Ссылке текущей страницы ставится `aria-current="page"`. Какая страница
текущая, говорит атрибут `current` (её `id`), иначе — при
`current-from-location` — пункт, чей адрес ведёт на `location.pathname`
(конечный `/` и `index.html` не важны), иначе — первый пункт с
`current: true`. С `current-from-location` меню следит и за переходами по
истории (`popstate`, `hashchange`).

## Клавиатура и экранный диктор

Это шаблон WAI-ARIA «навигация с раскрытием», а не меню приложения: никакого
`role="menu"`. Меню — `<nav>` с `aria-label` из `label` (или `aria-label`
элемента), пункты — обычные ссылки, ветка — кнопка с `aria-expanded` и
`aria-controls`. У ветки со своей страницей ссылка и кнопка раскрытия стоят
рядом в одной строке.

| Клавиша | Результат |
| --- | --- |
| `Tab` | Переходит по ссылкам и кнопкам веток по порядку |
| `Enter` или `Пробел` на ветке | Открывает или закрывает её |
| `Enter` на ссылке | Переходит по ней (см. событие `sf-menu-navigate`) |
| `Tab` в строке | Название раздела → его стрелка → следующий раздел |
| `Enter` / `Пробел` на стрелке | Открывает или закрывает панель; `Enter` на названии — переход на страницу раздела |
| `↓` / `↑` в строке | На названии или стрелке раздела — открывает панель и ставит фокус на её первый / последний пункт |
| `←` / `→` в строке | Переходит к соседнему пункту первого уровня (в RTL — наоборот) |
| `↓` / `↑` в панели | Следующий / предыдущий пункт панели |
| `→` в панели | На строке с подразделами — открывает боковую панель и ставит фокус на её первый пункт |
| `←` в панели | Закрывает боковую панель и возвращает фокус на стрелку, которая её открыла — как `Escape` в образце APG: фокус возвращается на кнопку раскрытия |
| `Home` / `End` | Первый / последний пункт строки или панели |
| Стрелки в широкой панели | `↓` / `↑` — по ссылкам панели, `←` / `→` — к первой ссылке соседней колонки |
| `Escape` | Закрывает только самую внутреннюю открытую панель — панель строки или панель кнопки «Меню» — и возвращает фокус на её кнопку. В колонке панелей нет: группы колонки на `Escape` не закрываются, клавиша остаётся странице |

Открытая панель строки (и панель кнопки, пока в ней фокус) поднимает общую
отметку открытой поверхности: выдвижная панель или модальное окно позади
меню на этот `Escape` не закрываются.

## Методы и события

- `open(id)`, `close(id)`, `toggle(id)` — открыть, закрыть, переключить
  ветку (можно и `open({id})`); `closeAll()` — закрыть панели строки и
  панель кнопки. Отвечают `{outcome: 'applied'}`, если что-то изменилось,
  иначе `{outcome: 'refused', reason}`: `unknown`, `compact` (узкая колонка
  `rail`: ветки не раскрываются), `disabled`,
  `already`, `fixed` (группа, которую нельзя свернуть).
- `isOpen(id)`, `openIds`, `currentId` — что открыто и что текущее сейчас.
- `items` — свойство: записать новый массив пунктов.

`sf-menu-navigate` — перед переходом по ссылке меню, `detail: {id, href,
item}`. Событие отменяемое: `preventDefault()` останавливает переход, и
приложение само меняет страницу (SPA). Щелчок с Ctrl, Cmd, Shift, средней
кнопкой и ссылка в другое окно остаются браузеру и события не дают.

`sf-menu-toggle` — ветка открылась или закрылась, `detail: {id, open,
source, item}`; `source` — `user` или `method`. Сначала приходит событие
ветки, которую открыли, потом — закрытых при этом, от внутренних к внешним.
Панель кнопки «Меню» присылает то же событие с `id: null`.

`sf-menu-overflow` — при `overflow="more"` изменился список пунктов,
ушедших в «Ещё», `detail: {hidden}` — их `id` по порядку.

`sf-menu-search` — при `search` изменились слова в поле, `detail: {query,
count}`: слова без пробелов по краям (пусто, когда поле очищено) и сколько
слов пунктов и заголовков найдено.

Старые имена `sf-menu:navigate` и `sf-menu:toggle` работают до 2026-12-01 с
тем же `detail` (отказ `preventDefault()` у навигации общий для обоих имён);
каждое их использование записывается в `SF.deprecations` с датами.

## Настройка

Переменные классового меню — их можно задать на элементе или на любом
предке:

| Переменная | Что меняет | По умолчанию |
| --- | --- | --- |
| `--sf-menu-background-color` | Заливка под всем списком | `transparent` |
| `--sf-menu-gap` | Расстояние между строками (у дерева документации — своё; у `navigation` по умолчанию `var(--sf-space-1/4)`) | `var(--sf-space-1/3)` |
| `--sf-menu-item-color` | Цвет слов и иконки строки | `var(--sf-on-surface)` |
| `--sf-menu-item-background-color` | Заливка строки | `var(--sf-transparent)` |
| `--sf-menu-item-border-color` | Цвет тонкой рамки строки | `var(--sf-surface-container)` |
| `--sf-menu-item-radius` | Скругление строки | `var(--sf-radius--ui)` |
| `--sf-menu-submenu-background-color` | Заливка панели строки | `var(--sf-elevation-2--surface)` |
| `--sf-menu-submenu-border-color` | Рамка панели строки | `var(--sf-outline-variant)` |
| `--sf-menu-submenu-radius` | Скругление панели строки | `var(--sf-radius--ui)` |
| `--sf-menu-sticky-top` | Отступ от верха окна у меню со `sticky` | `0` |

Наведение, открытая ветка, фокус и недоступный пункт рисуются своими цветами
и поверх настроенных.
