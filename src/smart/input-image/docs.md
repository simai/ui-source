# Smart Image Field

`<sf-input-image>` — поле формы для одного изображения: логотипа, обложки,
аватара, картинки в блоке или письме. Два вида (`layout`): строка — миниатюра,
имя и размер, кнопки — для форм, настроек и узких панелей; превью — сама
картинка в рамке и та же строка под ней — для обложки, аватара, логотипа,
фото товара. Файл можно выбрать, перетащить на поле или вставить из буфера,
пока поле в фокусе; картинку можно взять из библиотеки страницы или по
ссылке, если страница их включила.

```html
<sf-input-image label="Логотип" name="logo" hint="PNG или SVG, до 1 МБ"
  accept="image/png,image/svg+xml" max-size="1048576" fit="contain"
  value='{"value":"42","label":"logo.png","mime":"image/png","size":2048,"href":"/upload/logo.png"}'></sf-input-image>

<sf-input-image layout="preview" label="Обложка статьи" name="cover" aspect="16/9"
  min-width="1200" sources="device,library,url" edit="crop,focus" alt="field" required></sf-input-image>

<sf-input-image layout="preview" shape="circle" label="Фото профиля" edit="crop"></sf-input-image>
```

## Значение

`value` — изображение в той же форме, в какой Фреймворк везде описывает файл,
и то, что поле знает о самой картинке:

```js
{value: '42', label: 'logo.png', mime: 'image/png', size: 2048, href: '/upload/logo.png',
 width: 600, height: 200, alt: 'SIMAI', decorative: false,
 focus: {x: 0.5, y: 0.4}, crop: {aspect: '16/9', zoom: 1.2, x: 0.5, y: 0.5}}
```

- `value` — идентификатор файла у хоста;
- `label` — имя файла (у адреса `data:` и `blob:` имени нет — поле пишет
  «Изображение»);
- `mime` — тип файла; `size` — размер в байтах (число) или готовый текст;
- `href` — адрес, по которому изображение показывается;
- `width`, `height` — размеры в пикселях, когда известны;
- `alt` — описание картинки, `decorative: true` — декоративная, описание не
  нужно (тогда `alt=""`). Имя файла описанием не служит;
- `focus` — точка фокуса, `crop` — кадр: пропорция, масштаб (1–3) и центр.
  Оригинал не меняется: кадр и точку применяет сервер или CDN.

Новые поля есть, только когда известны, поэтому старое значение читается как
прежде. В атрибут можно передать эту форму как JSON или просто адрес картинки.
Свойство `value` принимает объект или `null` (пусто). Значение, заданное из
кода, событий не вызывает — как у обычного поля.

## Проверки

Проверки — общие с `sf-file-upload` (одно ядро загрузки): тип из `accept`,
пустой файл, `max-size` в байтах, а для картинки ещё `min-width` и
`min-height` в пикселях — картинка читается до того, как поле её покажет.
Неподошедший файл поле называет под собой, с именем и причиной:
`«scan.pdf» не подходит: можно PNG, JPG`, `«small.png» — 120×80 px, а нужно
от 800 px в ширину`. Если бросили несколько файлов, берётся первое изображение,
и поле говорит: «Взято первое изображение из 3: в этом поле одно».

Обязательное поле (`required`) без картинки говорит «Выберите изображение.»,
когда фокус уходит с поля или форма проверяется, а не только при отправке.
Кнопки «Убрать» у обязательного поля нет.

## Загрузка

Без `uploader` компонент сам ничего не загружает. Когда человек выбирает,
перетаскивает или вставляет файл, миниатюра сразу показывает его (через
временный адрес `blob:`), а хост получает сам `File` в событиях. Хост
загружает файл и записывает в `value` сохранённое значение с постоянным
`href`.

```js
field.addEventListener('sf-input-image-attach', async (event) => {
  field.value = await upload(event.detail.file); // {value, label, mime, size, href}
});
```

С `uploader` — тем же, что у `sf-file-upload`, — поле отправляет файл само и
показывает загрузку на картинке: кольцо с долей и «Отменить»; при ошибке —
причину под полем и «Повторить». Пока файл грузится, форма не отправится.

```js
field.uploader = async (file, {signal, onProgress}) => {
  const answer = await send(file, {signal, onProgress}); // onProgress(done, total)
  return {value: answer.id, href: answer.url};
};
```

Выбранный файл уходит и с обычной отправкой формы под именем `name`;
загруженный — своим идентификатором.

## Откуда картинка

`sources` — список через запятую: `device` (диалог файла, по умолчанию),
`library` (библиотека страницы), `url` (адрес). Один источник — обычная
кнопка «Выбрать…» / «Заменить…»; несколько — «Заменить ▾» с меню. Пункт
библиотеки шлёт событие `sf-input-image-library`; страница открывает свою
библиотеку (Larena «Файлы», картинки письма) и вызывает `setValue()`. Подпись
пункта — `library-label` («Из письма»).

## Кадр, точка фокуса и описание

`edit="crop,focus"` добавляет «Изменить»: кадр в пропорции `aspect` с
масштабом и сдвигом и точку фокуса — прямо в поле, мышью, пальцем или
стрелками (+ и − — масштаб, Enter — готово, Esc — отмена). «Готово» пишет
`crop` и `focus` в значение. Фильтров и поворота нет.

`alt="field"` показывает в поле «Описание изображения» и переключатель
«Декоративная — описание не нужно»; `alt="required"` ещё и не даёт отправить
форму без описания или отметки.

## Атрибуты

- `label` — подпись над полем, она же имя группы. Без неё группа называется
  «Изображение».
- `hint` — подсказка под полем; слот `hint` — разметкой.
- `error`, `invalid`, `error-message` — ошибка: рамка и текст красятся в цвет
  ошибки, текст ошибки встаёт вместо подсказки; слот `error` — разметкой.
  Метод `setError('…')` делает то же из кода, `setError()` снимает ошибку.
- `required` — без изображения форма не отправится; кнопки «Убрать» нет.
- `disabled` — поле видно без заливки, кнопки недоступны, файл не принимается.
- `readonly` — изображение видно, кнопок нет; рамка — как у `sf-input` только
  для чтения.
- `accept` — какие файлы предлагает диалог и принимают перетаскивание и
  вставка. По умолчанию `image/*`.
- `max-size`, `min-width`, `min-height` — пределы (байты, пиксели); 0 — нет.
- `layout` — `row` (по умолчанию) или `preview`.
- `shape` — `square` (по умолчанию) или `circle` (человек).
- `aspect` — пропорция рамки превью и кадра: `16/9`, `1/1`. Пусто — у круга
  1/1, иначе своя пропорция картинки.
- `fit` — `cover` (по умолчанию: заполнить, точка фокуса в кадре) или
  `contain` (вписать целиком — логотип).
- `sources`, `library-label` — см. «Откуда картинка».
- `edit` — `crop`, `focus` или оба через запятую.
- `alt` — `none` (по умолчанию), `field`, `required`.
- `size` — `1/2`, `1` (по умолчанию), `2`, как у всех полей формы.
- `meta` — своя строка под именем. По умолчанию — размеры картинки и размер
  файла: «450×300 · 2 КБ».
- `empty-text` — свой текст пустого поля.
- `aria-label` — имя группы для чтения с экрана, когда подпись нарисована
  снаружи (так поле ставят наборы полей Фреймворка): видимой подписи внутри
  нет, а имя у группы есть.

Свойство `uploader` — функция загрузки страницы (см. «Загрузка»).

## События

- `input`, затем `change` — один раз на каждое действие человека. `detail`:
  `{value, file, source, name}`, где `source` — `input`, `drop`, `paste`,
  `url`, `alt`, `edit` или `remove`. С `uploader` после загрузки приходит
  `change` с `source: 'upload'` (в значении — идентификатор), после отмены —
  `source: 'cancel'`.
- `sf-input-image-attach` — выбран файл: `{files, file, source, value, name}`.
- `sf-input-image-detach` — изображение убрано: `{value, name}` с прежним
  значением.
- `sf-input-image-rejected` — файлы, которые поле не взяло:
  `{files, rejected: [{file, name, reason, message}], accept, source}`; причина
  `type`, `empty`, `size`, `min-width`, `min-height`, `unreadable` или `count`.
- `sf-input-image-library` — выбран пункт библиотеки: `{value, name}`.

Старые имена `sf-image-field-*` и `sf-image-field:*` приходят следом до дат в
`aliases.json`.

Методы: `setValue(value)`, `clear()`, `setError({message})`, `choose()`
(открыть диалог), `removeImage()`, `takeFile({file, source})`.

## Клавиатура и чтение с экрана

Поле — группа с именем из подписи; подсказка или ошибка её описывают.
«Выбрать…», «Заменить…», «Изменить» и значок «Убрать» — настоящие кнопки с
понятными именами: «Заменить изображение «logo.png»». Сама область
перетаскивания фокус не берёт, поэтому Tab проходит по кнопкам и уходит
дальше; вставка срабатывает, пока фокус на любой из кнопок поля. После
«Убрать» фокус встаёт на «Выбрать…». Выбор, удаление, неподходящий файл и
конец загрузки вежливо объявляются. На телефоне поле не просит перетаскивать.

Размеры берутся из одной шкалы: миниатюра — высота поля на ступень крупнее
(у поля размера `1` это 48 px на компьютере и 44 px на телефоне), кнопки — на
ступень мельче поля. В узкой колонке (уже 24rem) кнопки уходят под имя файла.
У превью строка под картинкой не шире картинки (но не уже пяти высот крупного
поля); кнопки, которым не хватает места, встают под имя от начального края
картинки. Ширину рамки задаёт ширина поля; у круга — две высоты крупного
поля. Под картинкой, которая может быть прозрачной (PNG, SVG, WebP, GIF), —
шахматка.

## Настройка

Внешний вид меняют публичные переменные. Их задают на самом поле или на любом
его предке; без них поле выглядит как прежде. Цвета — для поля в покое:
у перетаскивания, ошибки и недоступного поля свои.

| Переменная | Что задаёт | По умолчанию |
|:---|:---|:---|
| `--sf-image-field-background-color` | Заливка поля в покое; у перетаскивания и недоступного поля — своя. | `var(--sf-transparent)` |
| `--sf-image-field-border-color` | Цвет рамки в покое (у пустого поля она пунктирная); у перетаскивания, ошибки и недоступного поля — свой. | `var(--sf-outline)` |
| `--sf-image-field-border-width` | Толщина рамки со всех сторон. | `var(--sf-px)` |
| `--sf-image-field-radius` | Скругление углов поля. | `var(--sf-radius--ui)` |
| `--sf-image-field-padding-inline` | Отступ внутри поля до миниатюры и после кнопок. | `calc(var(--sf-ui-1--space-y-tightness-default) - var(--sf-px))`; зависит от размера |
| `--sf-image-field-padding-block` | Отступ внутри поля сверху и снизу от миниатюры. | `calc(var(--sf-ui-1--space-y-tightness-default) - var(--sf-px))`; зависит от размера |
| `--sf-image-field-gap` | Промежуток между миниатюрой, именем и кнопками; строки узкого поля разделяет свой. | `calc(var(--sf-ui-1--space-y-tightness-default) - var(--sf-px))`; зависит от размера |
| `--sf-image-field-thumbnail-size` | Ширина и высота миниатюры: высота поля на ступень крупнее. | `var(--sf-ui-2--control-height)`; зависит от размера |
| `--sf-image-field-thumbnail-radius` | Скругление углов миниатюры. | `var(--sf-radius--ui)` |
| `--sf-image-field-thumbnail-background-color` | Заливка миниатюры за картинкой или значком пустого поля; цвет значка не меняется, поэтому заливка должна оставлять его читаемым. | `var(--sf-surface-container)` |

```css
.brand-form .sf-image-field {
  --sf-image-field-thumbnail-size: var(--sf-ui-3--control-height);
  --sf-image-field-thumbnail-radius: var(--sf-radius-circle);
}
```

Остальные переменные `--sf-image-field--*` (с двойным дефисом) — внутренняя
проводка поля: размеры и состояния задают их сами, имена могут меняться в любом
выпуске, поэтому проект их не задаёт.
