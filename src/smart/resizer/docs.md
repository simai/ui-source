# Smart Resizer

`<sf-resizer>` — ручка на краю панели, которая меняет ширину панели. Ширину
меняют перетаскиванием, клавиатурой или возвращают двойным щелчком. Подходит
для колонок меню, боковых панелей и областей списка с подробностями.

```html
<nav style="inline-size: var(--menu-width, 16rem)">
  …
  <sf-resizer min="13rem" max="24rem" property="--menu-width"
              storage-key="menu" label="Ширина меню"></sf-resizer>
</nav>
```

Ручка стоит на внутреннем конце (`inline-end`) своего родителя. Если панель —
не родитель, её задают селектором ближайшего предка в `target`. Для ручки у
начала панели задают `edge="inline-start"`. Если у панели `position: static`,
ручка делает её `relative`.

- `min` и `max` — пределы ширины в любых единицах CSS, токены тоже подходят.
  Проценты считаются от родителя панели. По умолчанию `12rem` и `40rem`.
- `property` — имя CSS-переменной, в которую записывается ширина. Без него
  ширина записывается в `inline-size` панели.
- `storage-key` — ширина запоминается в этом браузере и восстанавливается при
  следующем открытии. Двойной щелчок её забывает.
- `step` — шаг стрелок в пикселях, по умолчанию 16. С Shift шаг в четыре раза
  больше.
- `label` — доступное имя, по умолчанию «Изменить ширину».
- `value` — ширина в пикселях, которую хранит сайт, например в личных
  настройках человека. Она важнее памяти браузера: так ширина одна и та же на
  любом компьютере.
- `disabled` — ручка видна, но ширину не меняет.

Ручка — разделитель в смысле доступности: `role="separator"`, она в порядке
табуляции, а её значение — ширина в пикселях между `min` и `max`. Стрелки
меняют ширину на шаг, `Home` и `End` ставят предел, `Enter`, пробел и двойной
щелчок возвращают ширину из стилей страницы. Если окно стало уже, сохранённая
ширина возвращается в пределы.

Событие `sf-resizer-resize` приходит с `{width, phase}` (прежнее имя
`sf-resize` приходит следом с тем же `detail` до 2026-12-01). `phase` — это `move` при
перетаскивании, `end` после перетаскивания или нажатия клавиши, `reset` после
возврата. Компонент ничего не сохраняет на сервере. Если ширину нужно хранить в
профиле человека, хост сохраняет её по `end` и записывает при следующем
открытии в ту же переменную.

Публичные переменные: `--sf-resizer-hit-size`, `--sf-resizer-line-width`,
`--sf-resizer-line-color`, `--sf-resizer-hover-line-color`, `--sf-resizer-z-index`.

## Язык

Слова ручки — имя и подсказку — даёт общий язык страницы: ближайший `[lang]`,
иначе язык документа, иначе английский. Встроенных языков два:

| Язык | Имя | Подсказка |
| --- | --- | --- |
| ru | Изменить ширину | Тяните или нажимайте стрелки; двойной щелчок возвращает ширину. |
| en | Resize | Drag, or use the arrow keys; a double click restores the width. |

Эти два — не весь список. Язык страницы выбирают `SF.language.use('en')`, а
другой язык добавляют так:
`SF.language.register('sf-resizer', 'de', {label: 'Breite ändern', hint: 'Ziehen oder Pfeiltasten.'})`.
Когда язык объявлен, уже стоящая на странице ручка переименовывается сама —
перезагрузка не нужна. Имя, заданное в `label`, остаётся как есть при любом
языке: его выбрал сайт.

## Где хранится ширина

Компонент сам ничего не сохраняет на сервере. Есть три уровня памяти:

1. Без `storage-key` и `value` ширина живёт до перезагрузки страницы.
2. С `storage-key` она — персональный вид по стандарту `SF.Preferences`
   (ключ `sf-resizer/<storage-key>`): хранится в браузере, а если сайт
   подключил хранение настроек у пользователя (`SF.Preferences.useHost`) —
   ещё и у человека на сервере, и применяется до первой отрисовки.
3. Сайт может и сам хранить ширину: слушать `sf-resizer-resize` с `phase: 'end'` и
   `'reset'` и при следующем открытии передавать её в `value`.

## Тот же жест для других краёв: SF.Resizer.attach

Край, который не может быть элементом внутри панели, подключают к тому же
поведению функцией `SF.Resizer.attach(root, {handles, session})`. Так устроены
края столбцов `sf-table`. `handles` — селектор ручек внутри `root`: они могут
перерисовываться. `session(handle)` возвращает, что именно меняется:

```js
SF.Resizer.attach(table, {
  handles: '.column-edge',
  session: (edge) => ({
    measure: () => edge.closest('th').getBoundingClientRect().width,
    limits: () => ({min: 64, max: 480}),
    apply: (width) => { /* записать ширину столбца */ return width; },
    commit: (width) => { /* сохранить */ },
    reset: () => { /* вернуть ширину по умолчанию */ },
    direction: () => 1,
    step: 16,
  }),
});
```

Перетаскивание, клавиши, двойной щелчок, курсор и значение для доступности у
всех краёв одинаковые.
