# SIMAI Framework Smart

Этот репозиторий содержит автоматически собранные смарт-компоненты SIMAI Framework в каталоге `smart/`. Исходники и тесты находятся в `simai/ui-source`, сборка — в `simai/ui-builder`. Собранные файлы вручную не редактируют.

## Выбор поставки

Core и Smart выбирайте как проверенную пару по `compatibility_id` в реестре `contracts/generated/framework-contract-registry.json` репозитория `simai/ui`. Реестр содержит точные Git-ревизии, области архивов и SHA-256. Не смешивайте произвольные версии пакетов и не используйте `main` или `latest` вместо зафиксированной поставки.

Номер в `VERSION` не доказывает совместимость пары. Статус локального кандидата, результаты приёмки и публикации указаны в handoff владельца Framework. Наличие файлов в Git не означает внедрения в продукт.

## Подключение к проекту

Разместите проверенный Core в `/assets/framework/core`, а корень Smart-пакета — в `/assets/framework/smart-package`. Внутри последнего должен находиться каталог `smart/`.

```html
<script>
  window.sfPath = '/assets/framework/core/distr';
  window.sfSmartPath = '/assets/framework/smart-package';
</script>
<link rel="stylesheet" href="/assets/framework/core/distr/core/css/core.css">
<script src="/assets/framework/core/distr/core/js/core.js"></script>
<sf-button text="Сохранить"></sf-button>
```

Loader получает необходимые ресурсы компонентов. Например, JavaScript модального окна находится по адресу `/assets/framework/smart-package/smart/modal/js/modal.js`. Не добавляйте каталог `smart/` к `sfSmartPath`: Loader добавляет его сам.

Для CDN используйте те же пути, заменив локальные корни адресами точных принятых ревизий. Перед подключением проверьте доступность файлов и соответствие отпечаткам поставки.

## Каталог и контракты

Папки компонентов находятся в `smart/`. Публичные атрибуты, методы, события и ограничения описаны в соответствующем `smart.manifest.json` и общем реестре Framework. Полное руководство и наглядные примеры находятся в документации SIMAI Framework.

Исторические изменения сохранены в [CHANGELOG.md](CHANGELOG.md) и `docs/releases/`. Они не заменяют текущий контракт поставки.

## Разработка и обновление

Исправления вносите в `ui-source`, выполняйте контрактные, регрессионные и браузерные проверки и запускайте штатный builder. Новую пару проверяют отдельно; успешная проверка прежней пары не переносится автоматически. При обновлении сохраняйте предыдущие точные архивы и реестр для возврата.
