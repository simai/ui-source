# Клавиатурный ввод

Клавиша выделяет кнопку клавиатуры внутри инструкции и отличает её от
обычного текста и кода.

## Пример

:::example {label="Клавиша"}
```markdown
Нажмите :kbd[Esc], чтобы закрыть окно.
```
:::

## Разметка

```markdown
:kbd[Ctrl]
```

- В квадратных скобках — подпись клавиши, как на клавиатуре. Простой текст:
  HTML внутри не работает, знаки `<` и `>` выводятся как есть.
- Пустая клавиша `:kbd[]` останавливает сборку с ошибкой
  `CONTENT_COMPONENT_SLOT_REQUIRED`.

## Варианты

### Сочетания

Записывайте каждую клавишу отдельно, а между ними ставьте знак `+` обычным
текстом.

:::example {label="Сочетание клавиш"}
```markdown
Откройте поиск сочетанием :kbd[⌘] + :kbd[K], затем нажмите :kbd[Enter].
```
:::

## Доступность

- Клавиша выводится элементом `<kbd>`: программы экранного доступа узнают в
  ней клавиатурный ввод.
- Пишите подпись словами или знаком, как на клавиатуре: `Esc`, `Enter`, `⌘`.
- Для команды меню, имени файла или кода выбирайте обычный текст или
  обратные кавычки, а не клавишу.

## Параметры

<!-- docara:component-parameters:start -->

Параметров нет.

<!-- docara:component-parameters:end -->

Запись с параметрами, например `:kbd[Esc]{size=1}`, останавливает сборку с
ошибкой `CONTENT_COMPONENT_PROP_UNKNOWN`.
