# Бейдж

Бейдж — короткая метка внутри строки: статус, версия, категория. Выбирайте его
для одного-двух слов, которые читатель должен заметить сразу.

## Пример

:::example {label="Бейдж"}
```markdown
Компонент готов к работе :badge[Новое]{variant=tonal scheme=primary size=1}
```
:::

## Разметка

```markdown
:badge[Текст метки]{scheme=success}
```

- В квадратных скобках — текст метки, в фигурных — параметры. Все параметры
  необязательные.
- Бейдж ставится внутри строки: в абзаце, пункте списка, ячейке таблицы,
  заголовке.

Бейдж построен на бейдже SIMAI Framework (`sf-badge`).

## Варианты

### Вид

`variant` задаёт, насколько заметно бейдж выделяется.

:::example {label="Вид бейджа"}
```markdown
:badge[С заливкой]{variant=main size=1}
:badge[Мягкий фон]{variant=tonal size=1}
:badge[Рамка]{variant=outline size=1}
```
:::

### Цвет

`scheme` выбирает цвет из палитры SIMAI Framework: основной, дополнительные,
нейтральный или цвет статуса.

:::example {label="Цвета бейджа"}
```markdown
:badge[Основной]{scheme=primary size=1}
:badge[Вторичный]{scheme=secondary size=1}
:badge[Третичный]{scheme=tertiary size=1}
:badge[Нейтральный]{scheme=neutral size=1}
:badge[Информация]{scheme=info size=1}
:badge[Успех]{scheme=success size=1}
:badge[Предупреждение]{scheme=warning size=1}
:badge[Ошибка]{scheme=danger size=1}
:badge[На поверхности]{variant=main scheme=on-surface size=1}
```
:::

### Размер

`size` выбирает ступень из шкалы SIMAI Framework. По умолчанию бейдж
маленький, чтобы не выбиваться из строки текста.

:::example {label="Размеры бейджа"}
```markdown
:badge[1/3]{size=1/3}
:badge[1/2]{size=1/2}
:badge[1]{size=1}
```
:::

## Доступность

- Бейдж — обычный текст: программы экранного доступа читают его вместе со
  строкой. Пишите метку так, чтобы она была понятна и без цвета.
- Цвет дополняет смысл, но не заменяет его: «Ошибка» на красном фоне, а не
  просто красная точка.
- Бейдж не кликается. Для перехода используйте [кнопку-ссылку](../button/).

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `variant` | `main`, `tonal`, `outline` | `tonal` | Вид: `main` — заливка основным цветом, `tonal` — мягкий фон, `outline` — только рамка. Старое имя `type` принимается с предупреждением. |
| `scheme` | `primary`, `secondary`, `tertiary`, `neutral`, `info`, `success`, `warning`, `danger`, `on-surface` | `primary` | Цвет из палитры SIMAI Framework: основной, дополнительные, нейтральный или цвет статуса. |
| `size` | `1/3`, `1/2`, `1` | `1/3` | Ступень размера бейджа. |
