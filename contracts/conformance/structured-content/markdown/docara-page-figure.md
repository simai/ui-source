# Иллюстрация

Иллюстрация показывает одно изображение с подписью и закреплёнными
пропорциями. Выбирайте её, когда картинка объясняет текст и ей нужна подпись
или ровная рамка.

## Пример

:::example {label="Иллюстрация"}
```markdown
:::figure {ratio=16/9 fit=cover}
![Панель проекта с графиком и карточкой](../../assets/figure-scene.webp)

Широкая иллюстрация заполняет область 16:9.
:::
```
:::

## Разметка

```markdown
:::figure {ratio=4/3}
![Описание изображения](../../assets/scheme.webp)

Подпись под изображением.
:::
```

- Первая строка — изображение Markdown. Блок без изображения останавливает
  сборку.
- Строка после изображения становится подписью. Подпись необязательна.
- Одно изображение на блок.

## Варианты

### Пропорции

`ratio` закрепляет соотношение сторон рамки, не искажая файл. По умолчанию
изображение показывается в своих пропорциях.

:::example {label="Квадрат и панорама"}
```markdown
:::figure {ratio=1/1 fit=contain}
![Знак Docara](../../assets/docara-mark.svg)

Квадратная рамка.
:::

:::figure {ratio=21/9 fit=cover}
![Панель проекта с графиком и карточкой](../../assets/figure-scene.webp)

Панорама 21:9.
:::
```
:::

### Заполнение

`fit=cover` заполняет рамку и обрезает края; подходит для фотографий и сцен.
`fit=contain` показывает изображение целиком; подходит для знаков и схем.

:::example {label="Обрезать или показать целиком"}
```markdown
:::figure {ratio=16/9 fit=cover}
![Телефон со страницей документации](../../assets/figure-tall.webp)

`cover` обрезает высокий снимок сверху и снизу.
:::

:::figure {ratio=16/9 fit=contain}
![Телефон со страницей документации](../../assets/figure-tall.webp)

`contain` показывает тот же снимок целиком.
:::
```
:::

## Доступность

- Текст в квадратных скобках — описание изображения (`alt`) для программ
  экранного доступа. Описывайте смысл: «Схема сборки: Markdown → HTML», а не
  «картинка».
- Пустое описание `![](…)` делает изображение украшением: программы экранного
  доступа его пропускают. Так делайте, только если картинка ничего не
  добавляет к тексту.
- Подпись видна всем, но не заменяет описание.
- Изображение загружается, когда читатель до него доходит, и не замедляет
  открытие страницы.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `ratio` | `auto`, `1/1`, `4/3`, `3/2`, `16/9`, `21/9` | `auto` | Соотношение сторон рамки изображения. |
| `fit` | `cover`, `contain` | `cover` | `cover` — изображение заполняет рамку и обрезается по краям, `contain` — помещается целиком. |

<!-- docara:component-parameters:end -->
