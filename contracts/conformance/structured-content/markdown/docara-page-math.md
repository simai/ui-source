# Математическая формула

Блок показывает формулу, записанную в TeX. Выбирайте его для коротких
выражений и самостоятельных формул; длинные выводы лучше разбивать на
несколько блоков с пояснениями между ними.

## Пример

:::example {label="Формула"}
```markdown
:::math {label="Теорема Пифагора"}
a^2 + b^2 = c^2
:::
```
:::

## Разметка

```markdown
:::math {label="Площадь круга"}
S = \pi r^2
:::
```

- Внутри — только формула TeX, без ограждающих `$`.
- Пустой блок останавливает сборку с ошибкой `MARKDOWN_MATH_SOURCE_REQUIRED`.

Сборка не разбирает TeX: она сохраняет исходный текст формулы в странице. В
браузере формулу рисует библиотека KaTeX. Она входит в пакет Docara и
подключается только к страницам с формулами, поэтому сеть не нужна.

## Варианты

### Отображение

`display=block` показывает формулу отдельной строкой, `display=inline` —
компактно, как часть текста.

:::example {label="Строчная и блочная формулы"}
```markdown
:::math {display=inline label="Теорема Пифагора"}
a^2 + b^2 = c^2
:::

:::math {display=block label="Интеграл от нуля до бесконечности"}
\int_0^\infty e^{-x}\,dx = 1
:::
```
:::

## Состояния

### Без JavaScript

Если скрипты выключены, читатель видит исходный текст TeX моноширинным
шрифтом.

## Доступность

- Формула — элемент с ролью `math` и подписью из `label`: программа
  экранного доступа читает подпись.
- Подпись называет смысл выражения: «Теорема Пифагора», а не «a в квадрате
  плюс b в квадрате».
- Без `label` подпись общая: «Математическая формула» на русской странице,
  «Mathematical formula» на странице на другом языке. Задавайте свою подпись
  у каждой формулы.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `display` | `inline`, `block` | `block` | `block` — формула отдельной строкой, `inline` — внутри текста. |
| `label` | строка | `Mathematical formula` | Описание формулы для программ экранного доступа. |

<!-- docara:component-parameters:end -->
