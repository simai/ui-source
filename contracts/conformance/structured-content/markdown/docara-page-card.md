# Карточка

Карточка объединяет заголовок и связанный с ним текст на отдельной поверхности.
Выбирайте её для коротких пояснений, вариантов выбора и небольших групп ссылок;
несколько карточек ставьте в [сетку](../grid/).

## Пример

:::example {label="Карточка"}
```markdown
:::card
### Переносимый проект

Markdown и JSON можно хранить рядом с кодом и проверять через Git.
:::
```
:::

## Разметка

```markdown
:::card
### Понятный заголовок

Короткое связанное содержимое.
:::
```

- Начинайте карточку с заголовка: он называет её содержимое.
- Внутри — обычный Markdown. Блоки Docara (`:::`) внутрь карточки не
  вкладываются.

## Варианты

### Вид

`variant=plain` убирает рамку, фон и отступы: так карточка встраивается в
другую поверхность, например в полосу или сетку с общим фоном.

:::example {label="Вид карточки"}
```markdown
:::card
### С оформлением

Поверхность, рамка и внутренние отступы.
:::

:::card {variant=plain}
### Без оформления

Только содержимое, без своей поверхности.
:::
```
:::

## Доступность

- Карточка — смысловая область (`section`) со своим заголовком: программы
  экранного доступа переходят по ней как по разделу страницы.
- Выбирайте уровень заголовка по месту на странице: `###` для карточки
  внутри раздела `##`.
- Не делайте карточку только ради рамки вокруг длинного текста: длинная
  статья читается лучше без неё.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `variant` | `default`, `plain` | `default` | Вид: `default` — карточка с рамкой и фоном, `plain` — без них. |
