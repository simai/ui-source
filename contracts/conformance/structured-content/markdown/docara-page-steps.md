# Шаги

Шаги показывают короткую последовательность действий. Временная линия
отмечает выполненные, текущий и будущие шаги; простой список подходит для
инструкции без состояния.

## Пример

:::example {label="Шаги"}
```markdown
:::steps {current=2}
1. Создайте проект.
2. Добавьте страницы.
3. Опубликуйте сайт.
:::
```
:::

## Разметка

```markdown
:::steps
1. Короткое действие.
2. Следующее действие.
3. Последнее действие.
:::
```

- Внутри — ровно один нумерованный список. Другой список или его отсутствие
  останавливает сборку.
- Пишите шаги коротко и в одном стиле: «Создайте…», «Добавьте…». Заголовок
  внутри шага оформляйте **жирным**, а не заголовком `###`.
- Шаги можно поставить внутрь [оформленной полосы](../surface/), чтобы
  отделить их от основного текста.

## Варианты

### Вид

`layout=timeline` — шаги на вертикальной линии с отметками состояния.
`layout=list` — компактный нумерованный список без отметок.

:::example {label="Список без отметок"}
```markdown
:::steps {layout=list}
1. Подготовьте Markdown.
2. Проверьте JSON.
3. Соберите статический сайт.
:::
```
:::

## Состояния

### Текущий шаг

`current` — номер текущего шага, начиная с `1`. Шаги до него отмечаются
галочкой как выполненные, шаги после него — как будущие.

:::example {label="Третий шаг текущий"}
```markdown
:::steps {current=3}
1. Структура готова.
2. Страницы добавлены.
3. Проверьте результат.
:::
```
:::

## Доступность

- Шаги — обычный нумерованный список: программы экранного доступа читают
  номер и текст каждого шага.
- Если задан `current`, текущий шаг отмечен для программ экранного доступа
  (`aria-current="step"`): читатель услышит, где он находится. Галочка
  «выполнено» видна только глазами — если это важно, скажите об этом в тексте
  шага.
- Маркер и текст стоят в отдельных колонках, поэтому крупный шрифт не
  наслаивает их друг на друга.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `layout` | `timeline`, `list` | `timeline` | `timeline` — шаги на линии с отметкой состояния, `list` — простой нумерованный список. Старое имя `view` принимается с предупреждением. |
| `current` | целое число | `1` | Номер текущего шага: предыдущие отмечаются выполненными. |

<!-- docara:component-parameters:end -->
