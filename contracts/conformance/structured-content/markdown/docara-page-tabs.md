# Вкладки

Вкладки помещают несколько равноценных вариантов в один блок: команды для
разных систем, способы установки, код на разных языках. Читатель переключается
между ними, не покидая страницу.

## Пример

:::example {label="Вкладки"}
````markdown
:::tabs {sync=install default="Архив"}
### Composer

```bash
composer create-project simai/docara my-docs
```

### Архив

Скачайте архив и распакуйте его в пустой каталог.

### Результат

Готовый сайт появится в каталоге сборки.
:::
````
:::

## Разметка

```markdown
:::tabs
### Подпись первой вкладки

Содержимое первой вкладки.

### Подпись второй вкладки

Содержимое второй вкладки.
:::
```

- Каждая вкладка начинается с заголовка `###`: он становится подписью
  вкладки. Делайте подписи короткими, в одно-два слова.
- Нужно не меньше двух вкладок, и у каждой должно быть содержимое: обычный
  Markdown — текст, списки, ссылки, код.

Блок построен на вкладках SIMAI Framework (`sf-tabs`, вид с подчёркиванием).

## Какая вкладка открыта

По умолчанию открыта первая вкладка. Параметр `default` открывает другую —
укажите её подпись или имя (подпись строчными буквами, пробелы и знаки
заменены на дефис):

```markdown
:::tabs {default=linux}
### macOS

brew install docara

### Linux

apt install docara
:::
```

Если вкладки с таким именем нет, сборка останавливается с
`MARKDOWN_TABS_DEFAULT_NOT_FOUND` и перечисляет имена вкладок блока.

## Связанные вкладки

Параметр `sync` даёт блоку имя. Блоки с одним именем переключаются вместе, и
выбор читателя сохраняется для следующих страниц: выбрав Linux в начале
руководства, он видит Linux и дальше.

```markdown
:::tabs {sync=os}
### macOS

brew install docara

### Linux

apt install docara
:::
```

- Имя — строчные латинские буквы, цифры и дефис, до 32 знаков.
- Вкладки сопоставляются по имени, а не по порядку: блок может перечислять
  другой набор вкладок, и совпадающие переключатся вместе.
- Выбор хранится в браузере читателя (`localStorage`). Без скриптов и без
  сохранённого выбора открыта вкладка из разметки.

## Варианты

По умолчанию вкладки подчёркнуты (`variant=underline`). `variant=pills` —
скруглённый переключатель SIMAI Framework: так на главной странице или в
лендинге над живыми примерами выбирают, какой показать.

Во вкладку можно положить пример, код, рисунок или предупреждение. Тогда блок
вкладок открывается четырьмя двоеточиями `::::tabs` и закрывается `::::`,
чтобы `:::` вложенного блока его не закрывало. Пример в скрытой вкладке
загружается, когда её открывают.

::::tabs {variant=pills}
### Кнопка

:::example {label=Кнопка}
```html
<button type="button" class="sf-button sf-button--default sf-button--primary sf-button--size-1"><span class="sf-button-text-container">Сохранить</span></button>
```
:::

### Текст

:::example {label=Текст}
```markdown
**Готово.** Сайт собран и проверен.
```
:::
::::

Исходник этого блока:

~~~markdown
::::tabs {variant=pills}
### Кнопка

:::example {label=Кнопка}
```html
<button type="button" class="sf-button sf-button--default sf-button--primary sf-button--size-1"><span class="sf-button-text-container">Сохранить</span></button>
```
:::

### Текст

:::example {label=Текст}
```markdown

```
:::
::::
~~~

## Состояния

### Выбранная вкладка

При открытии страницы выбрана первая вкладка или вкладка из `default`, а в
связанных вкладках — сохранённый выбор читателя. Содержимое выбранной вкладки
видно и до загрузки скриптов, поэтому важное ставьте первым.

## Доступность

- Вкладки — список вкладок (`tablist`): Tab переводит фокус на выбранную
  вкладку, стрелки влево и вправо переключают вкладки, Home и End выбирают
  первую и последнюю.
- Каждая вкладка связана со своим содержимым, а программы экранного доступа
  слышат, какая вкладка выбрана.
- Не кладите во вкладки шаги одного процесса: читатель увидит только один шаг.
  Для последовательности используйте [шаги](../steps/).

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `sync` | строка | — | Имя группы: блоки с одним именем переключаются вместе, а выбор читателя сохраняется для следующих страниц. |
| `default` | строка | — | Какая вкладка открыта при загрузке: подпись вкладки или её имя (подпись строчными буквами, знаки заменены на дефис). |
| `variant` | `underline`, `pills` | `underline` | Вид вкладок: подчёркнутые вкладки или скруглённый переключатель. |

<!-- docara:component-parameters:end -->
