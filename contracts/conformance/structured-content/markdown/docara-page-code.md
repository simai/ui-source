# Код

Любой фрагмент между тремя обратными кавычками Docara оформляет как блок кода:
HTML, PHP, JSON, команду терминала, конфигурацию или обычный текст. Блок
ничего не выполняет: он сохраняет пробелы и переносы, подсвечивает синтаксис
и даёт скопировать содержимое.

## Пример

:::example {label="Блок кода"}
````markdown
```php {title="config/app.php"}
return [
    'name' => 'Docara',
];
```
````
:::

## Разметка

~~~markdown
```php {title="install.php" highlight=2 numbers}
<?php
echo 'Готово';
```
~~~

- Язык пишется сразу после открывающих кавычек: он выбирает подсветку и
  появляется в заголовке. Без языка в заголовке стоит нейтральное `Code`.
- Параметры — в фигурных скобках после языка, в любом порядке. Параметр без
  значения, например `numbers`, означает «включить».
- Строки считаются от первой строки блока, с единицы. Номер больше числа
  строк или диапазон наоборот останавливают сборку с кодом
  `MARKDOWN_CODE_RANGE_INVALID`.

Запись совместима с привычными инструментами. Как в MkDocs Material,
параметры пишутся словами после языка, только в фигурных скобках. Как в
VitePress, метки изменений пишутся комментарием `[!code ++]`, а короткая
запись `` ```js{1,4-6} `` выделяет строки.

Блок построен на подсветке кода SIMAI Framework (`sf-highlight`).

## Варианты

### Выделение и номера строк

`highlight` выделяет строки, `numbers` нумерует их. Счёт можно начать с любого
числа, например с номера строки в файле: `numbers=42`.

:::example {label="Выделенные строки с номерами"}
````markdown
```php {highlight="2-3" numbers}
$site = new Site('docs');
$site->theme('light');
$site->build();
echo 'Готово';
```
````
:::

### Изменения в коде

Чтобы показать добавленное и удалённое, допишите в конце строки
комментарий-метку так, как в языке пишутся комментарии: `// [!code ++]`,
`# [!code --]` или `<!-- [!code ++] -->`. Docara убирает метку из
показанного кода.

| Метка | Что означает |
| --- | --- |
| `[!code ++]` | Строка добавлена |
| `[!code --]` | Строка удалена |
| `[!code focus]` | Строка в фокусе |
| `[!code highlight]` | Строка выделена |

:::example {label="Добавленная и удалённая строка"}
````markdown
```js
const site = createSite();
site.build(); // [!code --]
await site.build(); // [!code ++]
```
````
:::

Чтобы показать саму метку как текст, напишите два восклицательных знака:
`[!!code ++]` выводится как `[!code ++]`. В блоках `markdown` метки не
обрабатываются, чтобы пример разметки показывался как есть.

### Фокус

`focus` оставляет в фокусе указанные строки, остальные приглушает. Наведите
указатель на блок или перейдите в него клавиатурой — все строки снова видны.

:::example {label="Фокус на одной строке"}
````markdown
```js {focus=2}
const site = createSite();
site.theme('dark');
site.build();
```
````
:::

### Терминал

`layout=terminal` оформляет блок как окно терминала. Строка, которая
начинается с `$ `, — команда: знак `$` показан отдельно и не копируется.
Остальные строки — вывод команды.

:::example {label="Команды и вывод в терминале"}
````markdown
```bash {layout=terminal}
$ composer require simai/docara
Using version ^3.9 for simai/docara
$ php vendor/bin/docara build
Built 12 page(s) into build_local.
```
````
:::

## Состояния

### Перенос длинных строк

По умолчанию длинная строка прокручивается внутри блока и не растягивает
страницу. Кнопка «Переносить длинные строки» включает визуальный перенос;
исходный текст, отступы и копирование не меняются. Выбор сохраняется в
браузере и применяется ко всем блокам кода на странице.

Кнопку можно отключить для сайта, раздела или страницы настройкой `code.wrap`:

```json
{
  "code": {
    "wrap": false
  }
}
```

### Копирование

Кнопка «Скопировать» копирует только код, который нужно перенести к себе:

- без номеров строк, знаков «+» и «−» и меток `[!code …]`;
- без удалённых строк — копируется код после изменения;
- в терминале — только команды, без знака `$` и без вывода.

## Доступность

- Кнопки копирования и переноса получают фокус клавишей Tab; рамка фокуса
  видна при работе с клавиатуры.
- Добавленные строки отмечены знаком «+» и зелёным фоном, удалённые — знаком
  «−» и красным, поэтому разница видна не только по цвету. Программа
  экранного доступа перед такой строкой произносит «добавлено» или
  «удалено»; слова меняются в `lang.json` ключами `code.added` и
  `code.removed`.
- Не помещайте в пример пароли, токены и другие секреты. Если код нужно
  запустить, отдельно объясните окружение и ожидаемый результат.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `title` | строка | — | Подпись над кодом, например имя файла. Без неё показывается язык. |
| `highlight` | строка | — | Строки, которые нужно выделить: номера и диапазоны через запятую, например `1,4-6`. |
| `numbers` | строка | `false` | Показывать номера строк: `true` или номер первой строки. |
| `focus` | строка | — | Строки в фокусе: остальные приглушаются. Запись как у `highlight`. |
| `layout` | `default`, `terminal` | `default` | `terminal` оформляет блок как окно терминала с приглашением `$` перед командами. |

<!-- docara:component-parameters:end -->
