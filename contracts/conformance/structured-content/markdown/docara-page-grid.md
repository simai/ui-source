# Сетка

Сетка ставит самостоятельные блоки — чаще всего [карточки](../card/) — в
колонки. На телефоне блоки встают в одну колонку, на планшете — в две, на
широком экране — в заданное число.

## Пример

:::example {label="Сетка"}
```markdown
::::grid {columns=3 gap=2}
:::card
#### Markdown

Понятный исходный формат.
:::
:::card
#### JSON

Проверяемые настройки.
:::
:::card
#### HTML

Готовый статический результат.
:::
::::
```
:::

## Разметка

```markdown
::::grid {columns=3}
:::card
#### Первый блок

Содержимое.
:::
:::card
#### Второй блок

Содержимое.
:::
::::
```

- Сетка — внешний блок, поэтому у неё на одно двоеточие больше, чем у
  вложенных: `::::grid` вокруг `:::card`.
- Внутри — блоки Docara, обычно карточки. Число блоков может не совпадать с
  числом колонок: лишние переходят на следующую строку.

## Варианты

### Колонки

`columns` — сколько колонок на широком экране, от одной до четырёх.

:::example {label="Две колонки"}
```markdown
::::grid {columns=2 gap=2}
:::card
#### Содержание

Первый самостоятельный блок.
:::
:::card
#### Композиция

Второй самостоятельный блок.
:::
::::
```
:::

### Расстояние

`gap` — расстояние между блоками по шкале отступов SIMAI Framework, от `0` до
`4`. Держите один шаг для всей группы, чтобы ритм был ровным.

:::example {label="Расстояние 4"}
```markdown
::::grid {columns=2 gap=4}
:::card
#### Шире

Расстояние между карточками больше.
:::
:::card
#### Воздух

Удобно для крупных блоков.
:::
::::
```
:::

## Доступность

- Сетка отвечает только за расположение. Читатель и программы экранного
  доступа проходят блоки в исходном порядке: слева направо, сверху вниз.
- Не меняйте порядок блоков ради внешнего вида: на телефоне они встанут
  столбиком именно в этом порядке.
- Заголовки и смысл задают вложенные блоки, а не сетка.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `columns` | `1`, `2`, `3`, `4` | `3` | Сколько колонок на широком экране. На телефоне сетка в одну колонку. |
| `gap` | `0`, `1`, `2`, `3`, `4` | `2` | Расстояние между ячейками по шкале отступов. |

<!-- docara:component-parameters:end -->
