# Раскрывающийся блок

Раскрывающийся блок прячет дополнительное пояснение, пока читатель не решит
его открыть. Выбирайте его для подробностей и ответов на частые вопросы;
основная инструкция остаётся видимой на странице.

## Пример

:::example {label="Раскрывающийся блок"}
```markdown
:::details
## Что произойдёт после сборки?

Docara создаст статический сайт, который можно открыть без серверного runtime.
:::
```
:::

## Разметка

```markdown
:::details
## Короткий вопрос

Ответ или пояснение: абзацы, списки, код.
:::
```

- Первая строка внутри блока — заголовок `##`, `###` или `####`. Он
  становится надписью на кнопке блока и в оглавление страницы не попадает.
- После заголовка нужно хотя бы одно содержимое. Блок без заголовка или без
  содержимого останавливает сборку.

Блок построен на аккордеоне SIMAI Framework (`sf-accordion`).

## Варианты

### Вид

`layout` выбирает оформление. Смысл блока от него не меняется.

:::example {label="Вид блока"}
```markdown
:::details
## В тонкой рамке

Вид по умолчанию: подходит почти везде.
:::

:::details {layout=surface}
## На заливке

Для блока, который стоит отдельно и должен быть заметен.
:::

:::details {layout=lines}
## Между линиями

Для нескольких вопросов подряд.
:::

:::details {layout=lines}
## Ещё один вопрос

Линии разделяют соседние блоки.
:::
```
:::

## Состояния

### Открыт сразу

Обычно блок закрыт. `open=true` открывает его при загрузке страницы: так
делайте, только когда пояснение важно увидеть сразу, но оно всё ещё остаётся
дополнительным.

:::example {label="Открытый блок"}
```markdown
:::details {open=true}
## Открыто изначально

Содержимое видно сразу, а читатель при желании может его свернуть.
:::
```
:::

## Доступность

- Надпись блока — кнопка. Она получает фокус клавишей Tab, а Enter или
  пробел открывают и закрывают блок.
- Кнопка сообщает программам экранного доступа, открыт блок или закрыт
  (`aria-expanded`), и связана с содержимым.
- Поиск по странице в браузере находит текст и в закрытом блоке и сам
  открывает его.
- Не прячьте в блок обязательные действия, ошибки и предупреждения: их должен
  увидеть каждый читатель.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `open` | `true`, `false` | `false` | Блок открыт сразу после загрузки страницы. |
| `layout` | `outline`, `surface`, `lines` | `outline` | Вид: `outline` — в тонкой рамке, `surface` — на заливке, `lines` — раздел между линиями. Старое имя `view` принимается с предупреждением. |

<!-- docara:component-parameters:end -->
