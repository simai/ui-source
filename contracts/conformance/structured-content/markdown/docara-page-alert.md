# Уведомление

Уведомление выделяет в тексте то, что читатель не должен пропустить:
подсказку, результат, предупреждение или ошибку.

## Пример

:::example {label="Уведомление"}
```markdown
:::alert {type=info}
#### Полезная информация

Продолжайте работу в обычном порядке.
:::
```
:::

## Разметка

```markdown
:::alert {type=warning}
#### Короткий заголовок ситуации

Что произошло и что делать дальше.
:::
```

- Первая строка — заголовок `##`–`#####`: он кратко называет ситуацию.
- После него — пояснение или следующее действие. Уведомление без заголовка
  или без пояснения останавливает сборку.

Уведомление построено на уведомлении SIMAI Framework (`sf-alert`).

## Варианты

### Тип

`type` передаёт смысл сообщения: от него зависят цвет и значок.

:::example {label="Типы уведомлений"}
```markdown
:::alert {type=clear}
#### К сведению

Это сообщение не требует действия.
:::

:::alert {type=info}
#### Полезная информация

Продолжайте работу в обычном порядке.
:::

:::alert {type=success}
#### Готово

Сборка успешно прошла проверку.
:::

:::alert {type=warning}
#### Обратите внимание

Проверьте параметры перед публикацией.
:::

:::alert {type=danger}
#### Требуется исправление

Конфигурация не прошла проверку.
:::
```
:::

### Вид

`variant` меняет плотность оформления, но не смысл.

:::example {label="Вид уведомления"}
```markdown
:::alert {type=info variant=default}
#### С заливкой

Подходит для большинства уведомлений.
:::

:::alert {type=info variant=flat}
#### Без тени

Для спокойного сообщения.
:::

:::alert {type=info variant=outlined}
#### В рамке

Когда нужен менее плотный акцент.
:::
```
:::

## Доступность

- Уведомление — область `status` с названием из заголовка: программы
  экранного доступа объявляют его как отдельный блок.
- Цвет не единственный носитель смысла: тип передают и значок, и заголовок.
  Называйте ситуацию словами: «Обратите внимание», «Требуется исправление».
- Не ставьте несколько уведомлений подряд: читатель перестаёт их замечать.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `type` | `clear`, `info`, `success`, `warning`, `danger` | `info` | Смысл сообщения: `clear` — нейтральное, `info` — сведения, `success` — успех, `warning` — предупреждение, `danger` — опасность или ошибка. |
| `variant` | `default`, `flat`, `outlined` | `default` | Вид: `default` — с заливкой, `flat` — без тени, `outlined` — рамка. |

<!-- docara:component-parameters:end -->
